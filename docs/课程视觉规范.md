# 课程视觉规范

## 数学课程浅色主题

数学课程的“看例题、看演示、记要点、去练习”使用同一套浅色教学层级：白色纸张卡为内容主体，淡紫边框表示学习流程，暖黄仅用于例题与问题提示，绿色与红色分别表示答对与答错。

- 看例题：暖黄场景标题 + 白色例题解题卡。
- 看演示：浅紫讲解卡、清晰进度点、白色导航按钮。
- 记要点：淡紫/浅蓝口诀卡、编号要点卡、浅紫关键词标签。
- 去练习：暖白题面、白色选项，答对为薄荷绿、答错为浅红。

所有浅色文本至少使用深靛色 `#2d2a45` 或具备等效对比度的强调色，禁止沿用深色主题的浅字与深玻璃背景。

## 全局深色卡片规则与浅色覆盖

`index.css` 中 `.app :is([class*="-card"], …)` 会给**所有类名含 "-card" 的元素**加 `!important` 深色渐变（目的是根治深色主题下半透明玻璃的灰白拼接带），它不分主题、优先级最高。因此：

- 浅色主题下要覆盖这类卡片（背景/边框/阴影），对应规则的 `:root[data-theme="light"]` 选择器必须同样加 `!important`（如英语目录卡 `.en-lesson-card`、地图页 `.subject-card`），否则浅色样式被压、卡片在浅色主题下仍是深色板。
- 新增类名含 "-card" 的组件时，若提供浅色主题样式，记得带上 `!important` 并在两种主题下分别目检。
