# 语文教材训练去重

2026-10-10：教材训练页的题目、材料各展示一次。作答区只保留孩子的输入或录音入口及检查反馈，删除重复题干、“本课材料”拼接文本和重复朗读按钮。

## 排查范围与原因

检查全册 45 课使用的教材练习入口：18 个课文练习包（38 项任务）、14 个拼音学习包、3 个园地包（15 项任务），以及共用作答组件的全部调用。

课文任务已经在标题中显示题目、在点读卡片中显示材料，但共用 ObservedPractice 默认又把完整检查提示显示在作答区，造成重复。18 课的 31 项非选择、非场景任务受影响：9 项说话、9 项背诵、8 项朗读、2 项读音和 3 项实践。其中 20 项重复题目与材料，11 项无材料仍重复题目并显示空的“本课材料”。

拼音的“我来拼读”弹窗和“拼音表达”使用同一组件，也会重复已展示的目标音节或操作要求，一并去重；课内与复习共用入口均生效。园地题目与联系材料的问题是不同要求，材料数组没有重复条目；选择题、田字格及象形字场景没有重复作答提示。真实表达已经使用“题目、示范、孩子输入”格式。

## 展示约定

- 题目只在任务标题显示一次，保留标题旁的题目点读入口。
- 材料只在材料卡片显示一次，保留每张卡片的点读。
- 作答区不重复题目和材料。使用 showPrompt={false} 关闭共用组件的重复展示；完整 prompt 仍传入检查，判题条件、录音、证据与自动推进保持原有逻辑。
- 没有材料的任务直接显示题目和作答入口，不补空材料段落。
- 保留 Pad 横屏一屏展示，不新增滚动、分页或完成确认。
