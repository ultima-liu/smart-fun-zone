# 卷星外观主题

更新：2026-10-04。岩态、气态、冰态、恒星四套卷星外观已实施；按用户最新要求，所有建筑与设施只保留各自原始外观。

## 选择与保存

首页右上角「星球外观」打开四张预览卡，点击立即切换，可连续对比；「完成选择」、Escape 或点击面板外关闭。键盘焦点可操作，选中卡有明确状态，支持中英文。

默认岩态；用 `sfz-world-appearance-v1:<childId>` 按孩子在本机保存选择。刷新、离开首页再返回、切换孩子后均恢复。未知 ID 或读取失败恢复岩态；不增加云端字段，不与课程星、金币、学习进度或奖励绑定。

切换保留当前视角、各设施目的地、来信与远征状态，复用同一画布。正常情况下约 700ms 平滑混合，连续选择从当前混合状态转向最新外观；阅读来信或系统减少动态效果时立即切换。全站深／浅主题独立于卷星外观，首页保持深色宇宙背景。

## 四套形象

| 外观 | 星球 | 星环与环境 |
| --- | --- | --- |
| 岩态 | 精细地层、侵蚀沟壑、陨坑与少量紫色矿脉 | 紫灰细尘分层、三道窄暗缝、260 块立体岩屑 |
| 气态 | 铜橙／奶油色细密云带、层叠旋涡风暴、微起伏与昼夜分界 | 铜金细尘带、极薄低透明云尘与少量细粒 |
| 冰态 | 蓝宝石深沟、冰川层理、霜脊与细密压力裂隙 | 青蓝薄尘带、320 块尖棱薄冰晶 |
| 恒星 | 对流颗粒、磁流细丝、带半影的星斑、低幅流动与边缘渐暗 | 水平向外弯曲的等离子细丝、衰减火星与薄日冕 |

恒星为科幻视觉模式。四套球面均采用 ImageGen 精细图集与真实三维材质；星环正常参与深度遮挡，按共享时钟运动。阅读冻结、减少动态效果静止、后台停绘。气态保留两层薄天气层；恒星火丝沿半径 3.8～5.05 的环面延伸。完整资源、提示词、设施精修与实际预览见[卷星全场景精修](卷星全场景精修.md)。

## 所有建筑固定原始外观（2026-10-04）

用户最新确认：所有建筑不需要随着卷星主题变化，只留一个本来的样子。该要求覆盖此前「建筑随星球协调变化」约定。

学校、总部、档案库、船坞、补给站、空中乐园、雷达收件站，以及船坞维修飞船，均直接使用各自模型定义的唯一配色、玻璃、装甲、粗糙度、金属度与清漆。主题不额外添加晶纹、霜粒或陶瓷纹理，也不覆盖各自的程序面板纹理。

当前模型以[首页学校与档案库图标](首页学校与档案库图标.md)、[乐园游戏机模型](卷星乐园游戏机模型.md)和[首页建筑布局](首页建筑布局.md)为准，覆盖此前学校正北极和摩天轮的旧方案。

- 学校保留最新参考图 ImageGen 金色展开魔法书、厚棕金书页、发光炼金符文与暖金环绕流光；见[学校金色魔法书](学校金色魔法书.md)。
- 总部保留最新参考图 ImageGen 透明插画中的钴蓝高塔、橙色球舱、紫蓝飞碟与秋色庭院，等比显示、不被四主题重新染色；见[总部模型](卷星总部模型.md)。
- 档案库保留金黄／红／蓝三张天体纹样卡背、雕花边框与对应色底光，见[三色环绕卡牌](档案库三色环绕卡牌.md)。
- 船坞保留浅银灰金属、金色薄透明罩、黄黑警示与绿色充电；补给站保留蓝灰钛合金、青蓝观景窗和青绿港口灯。
- 空中乐园保留青蓝／珊瑚红掌机与原游戏屏幕；收件站保留深蓝、青蓝与银白雷达。
- 现有维修／投递飞船保留原装甲、窗舱和蓝色尾焰；不恢复已移除的首页远征战舰。

本轮所有设施补充各自的精细微材质、机械或印刷细节，但仍各只有一套外观。功能灯光、投影、符文和动态均独立于主题；基准位置、尺寸及 Web／Pad 横竖屏布局也独立于主题。场景主光、轮廓光颜色和强度固定，正常阴影、遮挡、反射和局部功能灯光继续作用。

## 实现与性能

- `appearances.ts`：外观清单、中英文名称、回退图与本机偏好。
- `WorldAppearancePicker.tsx`：Web／Pad 共用四张预览卡，主开关与完成按钮至少 48px 高，横竖屏面板收在视口内。
- `planet.ts` / `gasPlanet.ts` / `planetAtlases.ts`：混合四套精细图集球面、大气、云层与尘环，详见[全场景精修](卷星全场景精修.md)。不输出建筑用的主题光色或权重。
- `ringEffects.ts`：实例化岩块／碎冰、共享时钟的水平火焰与云雾。
- `models.ts` / `facilityMaterials.ts`：创建各设施唯一原始外观；已删除停用的 `facilityAppearance.ts` 主题混色模块。
- `runtime.ts`：移除设施主题绑定、主题升降和主题全局光照混合；仍共用场景 RAF、渲染像素预算和生命周期。
- 四套回退海报由真实 3D 默认视角导出，建筑使用同一原始外观；`posterAnchors.ts` 同步落点，所有设施及课程奖励星位置独立于主题。WebGL 不可用时，地点和收件／补给入口仍保留。

几何、材质与纹理只在初始化创建，切换时不复制场景或逐帧上传纹理。曝光保持 0.98，Bloom 强度 0.14、半径 0.16、阈值 2.4。
