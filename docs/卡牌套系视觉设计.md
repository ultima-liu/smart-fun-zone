# 卡牌套系视觉设计

## 范围与约定（2026-10-02）

除《西游记》《葫芦娃》保留现有专属卡面外，其余已收录的六套、36 张卡牌按题材重新设计。卡面以立绘为主体，取消外置名称板；人物与背景铺到边框内，名称叠放在底部渐变上，编号和稀有度收进顶部角标。汉字卡以大字和田字格作为主体。

## 各套系表现

| 套系 | 张数 | 主体与背景 | 边框特征 |
| --- | ---: | --- | --- |
| 卷星人 | 6 | 原有全身人物，星轨与角色配色；小卷、晶晶复用现有角色组件 | 淡紫细框、金色四角、星章与环轨 |
| 星航协作队 | 4 | 队长透明立绘，其他三人原有独立背景画作铺满 | 青金切角、航线刻度、顶部罗盘 |
| 布鲁克战队 | 11 | 放大的独立机甲立绘，机械环线背景 | 钢灰装甲切角、螺钉、黄色警示条与闪电徽记 |
| 汪汪队立大功 | 7 | 大幅人物，天空与救援城市剪影 | 蓝白救援框、红色侧条、爪印盾徽 |
| 乌乌怪 | 5 | 放大的原有怪物绘形，薄雾与软云背景 | 不规则软云轮廓、浅绿涂鸦和侧边波浪 |
| 汉字 | 3 | 宣纸底、拼音、大字与田字格，保留部首、笔画、结构 | 朱红方框、双线四角、篆印式「字」章 |

角色图片仍由 `src/content/characterAssets.ts` 统一引用独立 WebP。仅按透明边界调整显示范围，保持人物比例；不修改源图片，不拆分合图、不生成另一份人物资产。较宽的机甲按卡面宽度放大，边缘配件允许进入边框之下。背景画作使用等比铺满。SVG 裁切、渐变及滤镜使用实例独立 ID，避免列表和放大卡面互相引用。

当前尚无卡牌内容的舰船、神秘物品、装扮、徽章、游戏套系预留雷达切角、符文、缝线、勋章、像素边角样式，不新增卡牌数据。

## 状态与响应式布局

- 所有套系严格按当前孩子的 `archivedCards[childId]` 实际获得记录区分解锁状态。未获得卡统一显示灰暗立绘和「🔒 未解锁」角标，移除彩色高亮与光晕；已获得卡保留套系彩色卡面。游客卡牌全部为未解锁。
- 未解锁卡仍可打开详情和翻转，但正反面均保持灰暗、无光晕，详情显示「尚未解锁」。预览、切换套系或稀有度均不授予卡牌；汉字卡已有的课程奖励获取方式保留。
- 列表卡面比例统一为 200:280。Web 宽屏五列；1100px 以下四列、850px 以下三列、600px 以下两列。
- 放大预览采用相应套系的框色、背景和文字色。Web 卡面宽 330px，资料并排；Pad 竖屏卡面宽最多 280px，资料改为上下排列，弹窗可滚动。关闭与翻转按钮触控尺寸为 44px。
- 深浅主题均保持卡面题材色；外部页面沿用系统主题。减少动态效果偏好下取消卡片过渡。
- 统一卡面组件也供召唤展示使用；《西游记》《葫芦娃》继续由各自的组件与样式呈现。

## 实现与检查

`CardPortrait.tsx` 分发专属与通用套系卡面；`CardArtwork.tsx` 管理原有角色绘形和立绘显示；`ThemedCardPortrait.tsx` 绘制各套系背景、边框与卡面文字；`cardThemes.ts` 管理配色；`themed-cards.css` 管理档案库列表和预览布局；`archive-card-state.css` 统一所有套系的未解锁展示，优先于套系装饰样式，覆盖 Web 与 Pad、深浅主题。

本轮属于纯 UI 修改，按项目约定不运行测试用例。检查类型、相关文件 ESLint 和生产构建；用独立浏览器预览六套卡面及详情，覆盖 Web 1440×1000、Pad 820×1180、Pad 横屏 1180×820，确认无页面错误和横向溢出。
