## 1. 产品内容模型总述

**一句话定义**：一个"学习世界"，孩子在地图上从一个地点走向下一个地点，每个地点里的知识以
"**先看可视化演示，再玩练习游戏**"的方式学习，学完即点亮知识点、推进地图，家长看到孩子的知识掌握图谱。

```
┌─ 顶层：学习世界（可视化地图）
│   入口 → 6 大地点（数字农场/字母城/逻辑森林/记忆星空/自然花园/安全小镇）
│   完成知识点 → 点亮地图点位 → 地点通关徽章 → 下一年龄段地图扩展
│
├─ 中层：知识点体系（学习单位 = 知识点，而非游戏）
│   每个知识点 = ① 可视化演示（5–10 秒动画+语音，先教）
│                ② 游戏练习（1–2 个玩法变体，再玩）
│                ③ 掌握度判定（正确率≥80% 点亮，连续巩固变金色）
│
└─ 底层：掌握度可视化（学习成果）
    知识图谱点亮 · 学习花园成长 · 每日任务 · 家长报告（掌握清单+下一步建议）
```

## 2. 课程知识点体系（学科 → 年级 → 单元 → 课程）

**交互层级**：学科（入口）→ 年级（一年级起）→ 单元 → 课程课时

- **学科（6 门）**：数学 / 语文 / 英语 / 思维 / 科学 / 生活
  - 原"语言认知"拆分为**语文**（拼音、汉字）与**英语**（单词）
  - 原"逻辑"与"专注"合并为**思维**；原"自然"更名**科学**；"生活安全"简称**生活**
- **年级（2 档，从一年级开始）**：一年级（6–7 岁）· 二年级（7–8 岁）
- **课程课时**：按真实小学课标章节编排（不绑定具体教材版本），
  一年级数学（准备课·数一数、比多少、1~5 加减法、6~10、认识图形、认识钟表…）、
  一年级语文（汉语拼音 a o e / b p m f、识字·天地人 / 金木水火土、课文·秋天…）等

### 2.2 5–6 岁（基础期 · 18 个知识点）概要
- **数学**：数 1–10、数字字形 1–10、10 以内比较、图形组合拼图、5 以内合成分解（加减启蒙）
- **语言**：声母听辨（b/p/m/f…）、汉字 20 个、英文 10 词、听音选词
- **逻辑**：规律 ABAB/AABB、多标准分类、简单迷宫、大小长短排序
- **专注**：记忆配对 4–6 对、找不同 3–5 处、点线连线
- **自然**：动物吃什么/住哪里、植物结构（花/茎/叶）、天气（晴/雨/雪）可视化
- **生活**：三色灯全规则、垃圾分类 2–3 类、安全常识（火/电/陌生人）

### 2.3 6–8 岁（衔接期 · 20 个知识点）概要
- **数学**：20 以内数数、10 以内加减、比较与排序、方位（上下左右）、认识整点时钟
- **语言**：拼音拼读（声母+韵母）、汉字 50 个、常用词句、英文短句跟读
- **逻辑**：规律 ABC、简单推理、七巧板、分类多标准
- **专注**：更长记忆配对、规律接龙、舒尔特方格（专注力可视化计时）
- **自然**：动物分类（哺乳/鸟/鱼）、植物生长过程时间轴可视化、四季变化
- **生活**：垃圾分类 4 类、交通安全、情绪认知（表情可视化）

### 2.4 6–8 岁（进阶期 · 20 个知识点）概要
- **数学**：100 以内数、20 以内加减、乘法启蒙、图形周长/面积启蒙、人民币
- **语言**：拼音全拼读、汉字 100+、阅读理解启蒙、英语 50 词/简单句型
- **逻辑**：复杂规律、数独启蒙、逻辑推理题、策略对抗小游戏
- **专注**：长时间专注训练、双任务切换
- **自然**：水循环可视化、生态系统、趣味科学小实验（可视化模拟）
- **生活**：时间管理、健康饮食、零花钱理财启蒙、校园安全

## 3. 学习世界地图结构

- **入口大厅**：吉祥物 Dino + "今天去哪里？"推荐路线（按年龄段未完成知识点优先）
- **6 个地点**：复用现有场景插画；每个地点展示"知识点链"（如数字农场=数数链 4 关）
- **推进规则**：
  - 完成一个知识点（点亮）→ 该点位从灰色变彩色
  - 完成当前年龄段某地点 60% 知识点 → 地点徽章
  - 6 地点全部通关 → 解锁下一年龄段地图扩展（同一地图新增地点层级，避免另起地图）
- **保留"自由玩"**：地图角落放"自由乐园"入口，跳过知识点路径直接玩所有游戏（家长可关闭）
