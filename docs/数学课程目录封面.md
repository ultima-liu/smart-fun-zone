# 数学课程目录封面

数学一年级上册目录中的每一张课程卡均使用独立的 SVG 封面配置，配置位于 `src/components/MathLessonArtwork.tsx` 的 `MATH_LESSON_COVERS`。

- 每个课程 ID 必须明确设置短标签、配色和图形主题；不以单元公共插画作为封面。
- 短标签由目录页以 HTML 角标渲染在插画左下角（`.ct-art-source`，与语文目录同款）：不要画进 SVG 里——插画区比 SVG 视窗窄时 `slice` 会把左上角内容裁切到卡片外，还会压住课卡编号徽章（2026-09-20 修复）。
- 图形主题围绕课程概念选择：数数、比较、位置、分合、加减、十格框、立体图形、小棒捆扎、数轴、应用问题、加法表和复习。
- 新增数学课程时需要同步补上封面配置；目录覆盖测试会检查课程 ID 与封面 ID 一一对应。
