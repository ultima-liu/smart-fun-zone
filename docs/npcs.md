# NPC 人物档案

> 卷星世界 NPC 细化设定。数据源：`src/content/npc.ts`（`NpcMeta` 已含 性别/年龄/性格/角色/背景故事 字段，供剧情与展示使用）。

## 图鉴卡视觉规范

- 卷星人图鉴采用精绘全身立绘，统一使用柔和赛璐璐与轻厚涂结合的儿童太空冒险风格；人形 NPC 必须由一次独立生成得到一张原生透明 PNG，禁止使用多人合图裁切。缩略卡、放大预览和其他页面共用同一份高清资源，避免形象漂移；非人形 NPC 可复用其场景中的 SVG 组件。
- 阿光突出“猫头鹰学者、星际航行者、校长”：奶油金学者长袍、圆眼镜、发光知识书与星盘。
- 铁砣突出“退役舰长、可靠守护者”：靛蓝礼服、舰长帽、勋章与克制挺拔的站姿。
- 铛铛突出“星港商人、热情店主”：青珊瑚配色围裙外套、头巾与装满星际好物的编织篮。
- 泡泡突出“活力乐园主、孩子王”：气球感双马尾、轻快短外套和裙装、发光游乐园彩球与跳跃姿态。
- 小卷直接复用全局学习助手 `Mascot` 的卷卷星精灵 SVG：紫色圆形星体、星环、卷卷呆毛与表情。禁止维护另一份卡牌立绘，也禁止使用人类身体、头发、服装、肢体或任何性别特征。
- 晶晶直接复用档案库 NPC 的 `JingJingFigure` 晶簇档案员 SVG：棱镜档案核、书页光环与星卡碎片；其 SR 图鉴卡使用同一组件，不维护额外贴图。
- 卡框以立绘为视觉中心；双层标题牌承担人物名称与套系信息，卡面不展示编号。SSR/SP 仅使用低强度旋转辉光强调稀有度，不遮挡人物；深色主题下标题牌使用深靛底与高对比浅色文字。
- 公共资源映射维护在 `src/content/characterAssets.ts`。需要人物立绘的组件应调用 `characterPortrait(id)`，不要硬编码路径；当前正式资源使用 `public/assets/npc-*-v3.png`。小卷直接渲染 `Mascot`，晶晶直接渲染 `JingJingFigure`，均与场景 NPC 保持一致。
- 学校（阿光）、总部（铁砣）、补给站（铛铛）与空中乐园（泡泡）的场景 NPC 贴图统一通过 `npcPortrait(name)` 获取同一套图鉴立绘；未知 NPC 才保留 SVG 兜底形象。

## 阿光 · 星校长

- **性别**：男　**年龄**：48
- **性格**：温和博学、慈祥爱鼓励，有点爱唠叨，坚信每个孩子都能发光。
- **角色**：卷星星际小学校长 · 课程管理员（学校技能向导）
- **背景**：年轻时是星际航行者，走遍各星球收集“知识星光”；退休后创办卷星小学，把毕生所学教给孩子。口头禅：“认真，是点亮星光最强的能量。”

## 泡泡 · 乐园主

- **性别**：女　**年龄**：16
- **性格**：活泼开朗、爱笑爱玩，好胜心强、偶尔撒娇，卷星最会玩的孩子王。
- **角色**：卷星乐园管理员 · 游戏向导（休闲区入口）
- **背景**：把废弃星尘矿场改造成欢乐乐园。她的笑声有魔力，能让乐园的灯一盏盏亮起——“笑一笑，灯就亮了”。

## 铛铛 · 补给站老板

- **性别**：女　**年龄**：35
- **性格**：精明热情、爱分享、会算账，嘴上说不送、心里最软。
- **角色**：补给站老板 · 装扮/道具/奖励兑换管理员（商店入口；徽章由剧情授勋，不在商店出售）
- **背景**：早年跑遍各大星港的星际商人，因被孩子的笑容打动而留在卷星开补给站，进货永远先想孩子喜欢什么。

## 铁砣 · 总指挥官

- **性别**：男　**年龄**：45
- **性格**：严肃可靠、纪律严明，外冷内热、爱护孩子，常在无人时偷偷关心。
- **角色**：卷星总指挥官 · 远征/飞船/勋章档案管理员（总部入口）
- **背景**：卷星防卫军退役舰长，曾在抵御乌乌怪入侵时立下大功；如今坐镇总部，负责孩子成长档案与远征安全，夜里常悄悄为孩子们的勋章擦拭灰尘。

## 小卷 · 守护星灵

- **种族**：星灵　**性别**：无　**年龄**：无固定年岁
- **性格**：天真好奇、乐观开朗，最爱问“为什么”，像一颗会发光的问号。
- **角色**：新手向导 · 卷星守护星灵（任务与成长跟随）
- **背景**：由卷星上空一枚星核苏醒而成，外形是会发光的星核、彗光与星尘，不属于任何性别或人类年龄。专门引导初来卷星的小宇航员，总把“一步一步来”挂在嘴边。

## 晶晶 · 档案员

- **种族**：晶簇精灵　**性别**：无　**年龄**：与星核档案库同岁
- **性格**：细心安静、记忆力惊人，喜欢把每一次努力都好好收进档案。
- **角色**：星核档案库档案员 · 图鉴与收藏向导（档案库入口）
- **背景**：由档案库最早的一枚星核碎片凝成，外形是悬浮的棱镜档案核、书页光环与星卡碎片。晶晶会保存孩子在卷星留下的成长闪光，也会指引大家找回散落的图鉴卡。
- **图鉴卡**：SR「档案员·晶晶」，与档案库中的晶簇立绘复用同一份 `JingJingFigure` 组件。
