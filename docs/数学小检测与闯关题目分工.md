# 数学小检测与闯关题目分工

2026-10-09 确定并实施：小检测和智能闯关不再先取同一组的两题、随后完整重复同组五题。覆盖一年级上册全部47课。

## 两阶段内容

- 小检测：保留两道基础题，快速核对本课基本概念、读数或运算关系。
- 智能闯关：使用独立的三道情景应用题，每题对应本课的一项教学目标，完整覆盖三个目标。
- 两阶段可以考查相同知识，但闯关要改变任务用途、材料或情景，不能直接重放小检测题或只给原题加前缀。例如捆十用于整盒彩笔和袋装贴纸；凑十用于水果总数、装满蛋盒后的剩余和反向检查。
- 保持本课数域，支持填数、算式或选择题；没有增加学习阶段。完成与奖励仍按独立表现计算，最后一题继续自动结算。

2026-10-09 题目情景补充：不把「旁边0颗」「另有0张散装」作为凑数的已知条件。0只在空数量、全部拿走、个位没有散装等有实际含义的知识点中出现。「10的再认识」拆十题改为判断小熊的说法：把一袋10颗糖倒进盘子，是否就变多了？孩子选择「不同意，还是10颗」，检查拆开包装不改变数量。「11～20」的对应题比较拆袋后的计数单位，从一个十和若干个一转成全部的个一；此处散装数量必须为正。复习中的袋装加散装也保持真实存在的散装数量。

基础评价蓝图和复习题在 `src/content/mathTeaching.ts`，独立闯关题在 `src/content/mathArenaQuestions.ts`。小检测仍取前两项基础目标；课程表复习、先备来源、自选挑战及明确传入题目的练习保留各自路径。

## 断点、换题和错题

新进入闯关使用 `arena-v1` 题库并保存题库标识。刷新、重做原组、换新一组及错后换题均保留正确题库和目标。旧五题组已经做过至少一题的断点标为 `core-v1`，先完成原组，避免丢掉已完成表现；选择换新一组后改用三道情景题。尚未作答的旧断点直接进入新题库。

新情景错题保存 `mathQuestionBank: arena-v1`，错题本按该题库换材料重练，不误换成基础题。未带题库标识的历史错题继续走基础题库。历史星级、奖励、学习阶段和旧完成证据保留。
