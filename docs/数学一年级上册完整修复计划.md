# 数学一年级上册完整修复计划

> 制定日期：2026-09-19  
> 依据：人教版《义务教育教科书·数学一年级上册》（根据 2022 年版课程标准修订）印刷页 P1-P111 及《数学一年级上册教材还原度分析》。  
> 本文是完整修复范围，不是优先事项摘要。只有本文列出的架构、内容、交互、练习、评价、视觉、数据迁移和验收项全部完成，才能宣称整册修复完成。

## 一、修复目标

修复后的数字课程应做到：

1. 教材 P1-P111 每个教学任务都有明确去向，不再只登记标题和核心概念。
2. 保留教材的数学动作和认知顺序：观察、操作、表示、计算、表达、变式、检查、整理和评价。
3. 可以使用原创插画和数字交互替代教材原图，但必须保持原任务中的数量、位置、结构、未知量和问题关系，不能只保留结论。
4. 教材的“做一做、练一练、数学游戏、你知道吗、思考题、成长小档案、自我评价”均进入课程结构；确实不适合数字化的纸笔任务，提供等价书写、画图、口述或线下操作指引，并记录完成证据。
5. 智能闯关只承担迁移练习，不能继续代替教材主任务和基本练习。
6. 原有学习记录、星级和奖励不丢失；新增教材任务单独记录，不回收用户已经获得的奖励。

## 二、完成定义

整册修复完成必须同时满足以下条件：

- 建立 P1-P111 的逐项覆盖台账，每一个例题、试一试、做一做、练一练、数学游戏、思考题、整理活动和评价项都有唯一编号及实现状态。
- 最终目录由 42 课调整为 **47 课**：保留原有 42 个课时 ID，新增 5 个因压缩而缺失的独立课时。
- 每课至少包含“教材情境或等价情境、核心操作、表征转换、教材基本练习、表达/解释、检查或回顾”六类学习证据；不适用的类型要在覆盖台账中说明原因。
- 不再以一个 `activity` 代表整课；一课可以包含多个有顺序、有完成条件的教材任务。
- 所有必做任务均支持断点续学、触摸操作、键盘操作、深浅主题和窄屏布局。
- 教材页码、课时内容、目录、前后导航、知识延伸、智能题库和文档一致。
- 新增单元测试通过；每个实施批次只运行本批修改相关的 E2E 用例，最终再运行数学整册相关用例与构建。

## 四、课程架构修复

### 4.1 数据模型

把当前“一课一个 `activity`”升级为“一课多个教材任务块”。建议数据结构至少包含：

```ts
type MathTextbookLesson = {
  id: string;
  title: string;
  textbookPages: number[];
  objectives: MathObjective[];
  representations: MathRepresentation[];
  tasks: MathTask[];
  practiceGroups: MathPracticeGroup[];
  discussion?: MathDiscussion[];
  cultureNotes?: MathCultureNote[];
  reflection?: MathReflection;
  coverageIds: string[];
};
```

其中：

- `tasks` 支持多个必做任务及顺序关系，不再只有一个主操作。
- `practiceGroups` 区分教材基本题、变式题、开放题和思考题。
- `representations` 明确实物、点子图、数线、算式、分合图、数位表、表格、路线图等表征。
- `coverageIds` 关联教材覆盖台账，构建时自动检查遗漏。
- 旧 `ExtendedMathLesson` 在全部课程迁移完成后删除；迁移期间只作为兼容层，禁止继续新增内容。

### 4.2 教材覆盖台账

新增独立内容台账，逐项记录：

- 编号，例如 `MATH-G1-U2-P45-EX2-REVIEW`；
- 教材页码和区域类型；
- 原任务的数学目标、已知量、未知量、表征与动作；
- 对应课程 ID、任务 ID 和实现组件；
- 状态：未实现、已实现、原创等价替换、纸笔/线下等价活动；
- 验收用例和必要截图。

增加自动检查：P1-P111 不能出现未归属项，课程也不能引用不存在的覆盖编号。

### 4.3 学习流程

保留“先猜—动手试—说理由—小检测—智能闯关”五个顶层阶段，但调整内部职责：

1. **先猜**：呈现教材主题情境，让学生观察并提出初始判断；不提前给出结论。
2. **动手试**：按教材页设置 1-N 个任务站，每站只有一个明确动作，但整课可以有多个任务站。
3. **说理由**：完成图、物、数、式之间的转换，口述或选择理由；问题解决课在这里完成“分析解答—回顾反思”。
4. **小检测**：承载教材“做一做”和最基本的“练一练”，题型不能全部是单选。
5. **智能闯关**：只做换情境、逆向、错误辨析和综合迁移，不复问教材原题。

页面上显示“教材任务 2/4”和印刷页范围，防止学生误以为做完一次点击就完成了整页内容。

## 六、练习、表达与评价修复

### 6.1 题型覆盖

每个单元必须同时具备：

- 点数、圈选、涂色；
- 拖拽、摆放、分组、配对；
- 数字/符号输入和数字书写；
- 画图、补图、数线或部分整体图；
- 看图列式、看式讲故事；
- 选择信息、提出问题、解释方法、检查答案；
- 规律发现、开放答案和思考题。

不能用单选题替代上述操作型、表达型任务。语音识别不可用时，表达任务降级为“录音/跟读不可用提示 + 家长确认或文字/选项辅助”，但不能自动判完成。

### 6.2 必做与选做

- 教材例题、试一试、做一做：必做。
- 练一练：每种能力至少一题必做，其余作为可继续练习题；整组题均保留在课程中。
- 数学游戏、开放交流、你知道吗：不影响概念通关星级，但有独立完成记录。
- 思考题：选做挑战，不阻塞下一课。
- 成长小档案、自我评价：单元结束必显示，允许如实选择，不设“正确答案”。

### 6.3 错误反馈

按错误类型给策略提示：漏数/重复数、起点方向错误、整体与部分混淆、符号方向错误、分法遗漏、位值错位、凑十拆数错误、把关键词当运算规则、包含端点错误、立体图形旋转重复等。反馈只指出下一步检查动作，不直接暴露答案。

## 七、原创视觉和教材情境修复

1. 为每个教材主题页制作原创等价场景，不直接截取或重绘教材原图。
2. 场景资产必须有内容标注文件，写清对象数量、位置、颜色、层级和可交互热点，避免插画改动破坏数学答案。
3. 情境图同时提供无障碍文本；数量信息不能只靠颜色区分。
4. 数学物件优先使用清晰矢量/HTML/SVG：小棒、珠子、圆片、积木、旗子、车厢、十格框、数位板和表格不使用语义模糊 emoji。
5. 深色/浅色只改变界面容器，数学图示的数量、线条、符号和状态颜色保持高对比且含形状/文字辅助。

## 八、进度和数据迁移

1. 保留 `math-lab-<id>` 的旧星级、奖励、错题和复习计划。
2. 新增 `contentVersion: 2` 和逐任务完成记录，不覆盖旧数据。
