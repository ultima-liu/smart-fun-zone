# 乐园小游戏品质升级计划

> **首轮完成（2026-09-30）**：空中乐园十四款游戏已完成一次统一品质升级与核对，覆盖素材、音乐、音效、动效、可玩性与玩法深度；全部保留 Web 与 Pad 适配。云端黄金矿工完成角色 / 道具素材与层间商店，其余十三款补齐局内图块、星雷、角色 / 道具主题图章，并复核原有音乐、动效与深度玩法链路。

## 统一质量线

- **素材**：每款游戏建立一致的主题美术，关键角色、棋子、卡牌、道具、场景和结算画面不再依赖单一 emoji 或简单几何占位；图片控制尺寸并使用透明素材或代码原生矢量，避免无意义的大图。
- **音乐与音效**：每款游戏至少有一套可循环背景音乐，以及开始、操作成功、操作失败、阶段推进和结算音效；统一服从全局声音开关，游戏卸载后立即停止。
- **动效**：关键动作需要有可读的起势、命中与收束反馈；暂停时冻结玩法动画；支持 `prefers-reduced-motion`，不让装饰动效影响操作判断。
- **可玩性**：首局能快速理解，触控目标适合 Pad，键盘 / 指针均可完成核心操作；中途离开自动暂停，失败原因和下一步建议明确。
- **玩法深度**：每款至少补足一项可持续目标，例如关卡、难度、AI、随机局面、任务、连击、道具、Boss 或局内成长，避免只剩一次性演示。
- **验证**：功能变化只运行本次相关 E2E；纯 UI 调整不追加 E2E。每款完成时检查深浅主题、Web 横屏与 Pad / 窄屏布局，并同步更新《乐园小游戏》。

## 首轮实施记录

1. **样板收口**：云端黄金矿工完成独立角色、矿藏、商店素材和层间经济系统。
2. **核心局内素材**：星牌记忆与云径连连看共用 18 枚一致的游乐图标；星屿扫雷使用独立星雷精灵，均直接进入核心棋盘而非只做装饰。
3. **识别系统**：其余十款采用两套主题精灵条替换单字 / emoji 标识，让大厅预览、游戏标题和局内视觉语言一致。
4. **既有能力复核**：十四款均已具备独立音乐 / 音效、关键动效、暂停与后台冻结、至少一项持续目标，以及 Web / Pad / 窄屏适配。

后续若继续扩展新关卡或玩法，只在本文件追加单款细节，并把玩家可见规则写回《乐园小游戏》；总体设计文档只保留「十四款统一升级」这一主要方向。
