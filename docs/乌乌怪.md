# 乌乌怪（Gloom Gremlins）设计画像

> 卷星世界反派设定。数据源：`src/content/gloom.ts`（`GLOOMS` / `GLOOM_LORE`）。
> 通用法则：乌乌怪由**坏习惯与负面情绪**滋生；它们最怕**“认真的星光”**——孩子每认真一次，卷星的星光就亮一分，乌乌怪就弱一分。被击败后化作**星尘与星屑**（可用于星尘召唤与飞船升级）。

---

## 1. 迷雾乌 · Misty Gloom（杂兵 🌫️）

- **外貌特点**：一团紫灰色的雾团，像融化了一半的棉花糖，边缘不断滴下灰色小水珠。两只一大一小的半睁困倦眼，嘴角下撇，头顶永远顶着一朵小乌云，走路飘忽不定。
- **角色定位**：在校舍与课本之间吐雾，专门让人**“看不清题目”**——读题晃神、漏看要求，是学校里的常见杂兵。
- **弱点**：**大声朗读 + 圈出关键词**。把题目读出声、圈住重点，雾气立刻散开；明亮星光会让它缩成一滴水。
- **口头禅**：「看不清吧？看不清就别写了～」
- **配色**：紫灰 `#8f86c9` / 浅紫 `#c9c4ee` / 高光 `#f2f0ff`

## 2. 拖延乌 · Dawdle Gloom（杂兵 ⏳）

- **外貌特点**：灰毛树懒与抱枕的混合体，背着一只被它按停的大闹钟，肚皮上浮着“待会儿”三个字。眼睛常年闭着打呼，四条短腿软趴趴，一碰就往后倒。
- **角色定位**：出现在任务开始之前，把“马上做”变成“等会儿做”，专门**拖慢行动、消磨时间**。
- **弱点**：**立刻开始（先做 5 分钟）**。只要孩子动手，它背上的闹钟就重新走动，指针一响便把它弹飞。
- **口头禅**：「再玩一会儿嘛，作业明天也来得及～」
- **配色**：灰 `#9aa0b0` / 浅灰蓝 `#cfd5e2` / 高光 `#f4f6fb`

## 3. 马虎乌 · Sloppy Gloom（精英 🩹）

- **外貌特点**：长着三只眼睛却各看一个方向，身体贴满写错的答案、橡皮屑和撕掉一角的草稿纸；尾巴歪成问号，末端系着一个打歪的蝴蝶结；两只细长的手总在乱擦乱改。
- **角色定位**：制造**“看错、抄错、漏题、算错”**——错题本的主要来源，也是最会伪装的乌乌怪。
- **弱点**：**逐字检查 + 复算一遍**。认真检查时它的三只眼会同时对上，随即被自己缠住打结。
- **口头禅**：「差不多就行啦，谁在乎那一个零～」
- **配色**：珊瑚 `#e0938f` / 浅粉 `#f6c9c2` / 高光 `#fff3f1`

## 4. 分心乌 · Fidget Gloom（精英 🌀）

- **外貌特点**：圆滚滚像一颗弹跳球，浑身伸出无数小手小脚，手里攥着陀螺、泡泡水和小喇叭；头顶一只彩色风车疯狂旋转，转得人眼花，自己却越转越兴奋。
- **角色定位**：在写作业、上课时钻进耳朵，把注意力拽走，让**“再玩一下”盖过“先做完”**。
- **弱点**：**专注计时（番茄钟）+ 收好玩具**。环境一安静、计时一开始，它的风车停转，所有小手小脚被定住。
- **口头禅**：「看这里看这里！这个更好玩！」
- **配色**：橙金 `#f2b158` / 浅金 `#ffe0a8` / 高光 `#fff8ec`

## 5. 乌乌王（放弃乌）· Quitter Gloom King（BOSS 👑）

- **外貌特点**：巨大的黑色毛绒怪，头顶一顶歪掉的破王冠，身体由无数小乌乌怪挤压拼成，缝线处透出幽紫光；胸口有一道**碎裂的星形旧伤**——当年被铁砣击中留下的痕迹。声音低沉带回声，走近时灯光会变暗。
- **角色定位**：**最终 BOSS**。只在孩子遇到难题、连续答错、累了想哭的时候现身，贴着耳朵说“你不行，放弃吧”。
- **弱点**：**坚持与求助**。连续再试一次、请老师家长帮忙、把错题重做，它胸口的星形伤就越亮；光聚满时王冠落地、身体碎裂，化作星尘。
- **口头禅**：「这么难，你肯定做不到的。」
- **配色**：暗紫 `#4a3f7a` / 深空 `#2a2350` / 幽紫光 `#b9a8ff`

## 设定补充

| 层级 | 成员 | 出现场景 | 对应坏习惯 |
|---|---|---|---|
| 杂兵 | 迷雾乌 | 学校 · 读题 | 读题不清、漏看要求 |
| 杂兵 | 拖延乌 | 任务开始前 | 拖延磨蹭 |
| 精英 | 马虎乌 | 作业 · 检查 | 粗心、看错抄错 |
| 精英 | 分心乌 | 上课 · 写作业 | 走神、贪玩 |
| BOSS | 乌乌王 | 难题 · 连错受挫 | 想放弃 |

- **与世界观联动**：铁砣（总指挥官）退役前曾击伤乌乌王，留下胸口星形伤；阿光（星校长）常用“乌乌怪最怕认真的人”鼓励孩子。
- **后续可扩展**：为 5 只乌乌怪生成「乌乌怪」图鉴卡（对应档案库分类 `monster`），立绘沿用本文件的配色与外貌描述。
