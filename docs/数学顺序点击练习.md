# 数学顺序点击练习

2026-10-10 确定：按顺序点击数字的操作题只读操作要求，不再逐个播报数字卡片。数字卡要打乱，完成后要能重新练习。界面只适配 Pad 横屏。

## 数字卡和完成行为

2026-10-10 全项目排序题排查后，数字卡洗牌防护统一使用 `orderingOptions`，保留稳定错序及原判题、重练行为。语文课内和复习也接入相同规则，详见[排序题选项打乱](排序题选项打乱.md)。

「沿数轴走10到15」及共用的数字顺序学具使用 `MathNumberOrder`。数字卡洗牌后既不是正序，也不是整组倒序；一轮作答期间位置保持稳定，点击「再做一次」重新洗牌。点错数字不推进，也不直接告诉下一个答案。

首次操作保存每一步，完成后保留已排好的结果和「再做一次」入口。重做时数字卡恢复可点击，用独立草稿重新排，不把旧完成快照清零。重做完成后再次保留结果，支持连续重做。刷新或重新进入时仍显示已验证的完成结果；未完成时恢复原断点。

「再做一次」固定在数字练习卡右上角，配一个回转箭头；完成提示以浅绿色状态条放在同一行左侧。中间只排列数字目标、数字卡片与反馈。卡片顶部预留操作栏空间，按钮至少44px高，适配 Pad 横屏与深浅主题。此项仅调整样式，按项目约定不运行 E2E。

首次完成保留正常自动推进；如果在跳转执行前点击「再做一次」，取消尚未执行的任务和阶段跳转，留在原题。回看或重做不撤销完成勾选、星级和解锁记录。

## 朗读规则

顺序操作的数字卡组标记为不播报选项。进入题目、返回题目和主动重播时，只读对应操作要求。「1～5的认识」中按从小到大排数字的卡组同样不枚举数字。普通判断题仍朗读答案选项，填空题仍朗读填写要求；输入、点选、重做和反馈不会自动重复播报。

真正的数轴展示保留位置顺序，不能把数轴刻度本身随机打乱；打乱的是供孩子选择的数字卡片。

## 验证

15项相关单元测试通过，覆盖洗牌稳定性、错序不推进、连续重做、完成恢复、朗读排除和重做取消待跳转。2项 Pad 横屏相关 E2E 通过，检查实际朗读请求、首次完成后的立即重做、历史完成重做和刷新，以及页面溢出。仅运行本次相关用例。

「再做一次」位置调整单独检查1024×768和1280×800、深浅主题共4种横屏状态：按钮位于卡片右上角，高度44px，完成提示与按钮不遮挡数字区，页面无溢出；仅进行静态界面检查，不重跑 E2E。
