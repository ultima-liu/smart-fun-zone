## 交互与完成条件

- 会认的字：逐字点读字形和拼音；进入时只播报说明，卡片不会被当成选项一次性读完。不在认字说明中显示教材页数。
- 认字抽查：抽取最多三个字，先听词语和要找的字，再从静音选项中选择。答错可再听，答完后直接进入写字观察，不显示完成中间页。
- 写字观察：展示教材书写字和用户指定的补充字（园地一“九”），逐个点读观察。
- 实际书写：可看笔顺范写，在屏幕田字格逐笔检查；全部字写完记录完成，继而进入未完成的知识桥。
- 园地完成要求认字点读、认字抽查、范字观察和实际书写都完成。知识桥先做完也不能跳过认写；全部任务和知识桥完成后自动进入真实表达。
- 沿用按儿童、课文分别保存的断点。只在本次由未完成变为完成时推进，手动回到已完成 tab 不再次跳走。原“词语积累”的点读记录不冒充抽查或实际书写完成。
