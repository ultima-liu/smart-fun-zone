# 英语课文布局与自动推进

2026-10-09：英语三年级上册 44 课统一采用已经确定的数学、语文课堂格式；适配 Web 与 Pad 横屏。

## 目录与课堂

- 目录标题栏加高至 132px，删除“五步课堂”介绍。六单元与 Revision 直接显示为可点击按钮，课文列表局部上下划动；不使用单元下拉框或课文分页。返回目录和刷新保留所属单元。
- 课堂采用“标题 → 学习步骤 → 公共提示与语音重播 → 当前任务”的完整一屏布局。右侧明确显示“不懂就问／点我问聪聪”。删除老师头像、老师讲解按钮、额外目标栏、底部上下活动/课文按钮及手动进入下一阶段按钮。
- 五个阶段按英语实际内容组织为：看图发现、听读原课、教材练习、实际表达、迁移挑战。完成最后一道迁移题后自动保存参与奖励，返回所属单元目录。已完成课的奖励回顾不设置左侧任务栏。
- 实际存在多个任务时才显示约 124px 的左侧精简任务 tab，完成状态以勾选显示；单任务直接铺满。最子级任务以有名称的横向 tab 显式呈现，不用折叠区隐藏儿童必做活动。
- 题卡以“题目与朗读图标、相关演示（有实际材料时）、紧凑选项、透明提示”从上到下居中分布。简短选项不再拉成巨大的整栏按钮，提示不铺浅黄色底块。
- 教材练习顶部不显示“已完成／再做一次”提示，已完成的选择题仍可直接再次点击选项。完成勾选继续显示在学习步骤或任务 tab；奇偶配对在操作区下方保留“重新配对”按钮。
- 题目和每个答案选项的文字均保持单行，覆盖看图发现、教材判断、故事与阅读线索、迁移挑战、声音辨认及原声听后题。选项按钮随内容取宽，按钮整体可排到下一行；取消原先 46%／440px 的选项宽度上限。较长文字按实际可用宽度适当缩小字号，完整显示，不截断、不使用省略号；切题、字体加载与 Pad 横屏尺寸变化时重新适配。只调整显示，沿用原有答题、朗读、完成与重复练习行为。
- 教材原页由标题栏打开完整对照窗口；局部插图可点图放大，完整显示、不裁切、不按高度分页。原页退出回到当前任务，不占用判断与表达练习的主体空间。
- 听读原课中的单词配图固定为 72×72px 的小图，文字区承接剩余宽度；配图不随按钮拉宽，保持图集中的原有比例。`friends-a` 的 ear、eye、mouth、hand、arm 与其他共用词卡采用同一规则。
- 规范书写的“占格规则”页只展示学习说明，取消整个“试着说一说”作答区，包括举例要求、输入框、语音入口和检查反馈。首次重点中的标题、三层房子说明、四线格 A/a/h/g 示意、上/中/下格说明、四类字母的全部例字和规则、口诀均保留，并铺满页面居中排列；格子说明独立排在示意图旁，保持可读字号。示意图同时受所在区域的宽、高约束，不跨出外框压住文字。后续单元沿用原有占格复习内容。说明页不再作为必做检查项，不自动记录“回答通过”；实际屏幕书写仍需逐笔检查通过。
- 英语四线格统一只显示四条横线，不加围住格子的外边框或圆角；覆盖六单元共用的静态范字、逐笔范写、描写提示、屏幕练写区与占格规则示意，以及旧四线格样式。笔画、占格、书写检查、清空重做与完成记录沿用。
- 四线格练写区一直显示淡色描写路径，取消描写提示按钮；进入、落笔、重写、清空与切换字母后均保留对应提示。详见 [屏幕书写自动检查](屏幕书写自动检查.md)。
- 全部 52 个大小写字母按教材六页的编号、箭头核对笔顺；A 从顶端向左下起笔，范字、演示、描写和校验共用修正模板。占格规则补充教材手写 f 伸入下格、占三格；英语与拼音各用自己的笔顺。详见 [英语字母笔顺](英语字母笔顺.md)。
- “认字母”以 4／5 条横向学习行展示大小写、两个例词和中文释义，覆盖全部 26 个字母与 52 个例词。字母名在前，每个英文例词后用中文读意思；进页、重播和点字母采用相同顺序。例词可独立点读，当前选词有独立跟读入口；保留既有完成记录，点字母不再立即弹出例词跟读窗。对应字母在词首、词中或词尾均标蓝；合适的现有图集素材显示为 40×40px 小图，can 等抽象词及人名不强配图。细节见 [英语字母认读](英语字母认读.md)。

## 各课型内部排版

| 课型 | 实际任务与横屏布局 |
| --- | --- |
| 主题与问题 | 教材图与歌谣接龙并排，逐拍实际点读；歌曲关键句与教材原声另设选学页。 |
| Part A / B | 按真实教材栏目生成“教材任务 1…”，场景与句子/词卡并排；有不同材料时再分听读、词与短句。Look and match 必须完成真实三组配对。 |
| Letters and sounds | 认字母、声音与拼读、规范书写三个必做任务；字母歌谣为一个选学页，同页分区展示录音的“字母歌谣”和“词中声音歌谣”两个部分，共用顶部原声播放器，不再拆成两个 tab。自动播报及重播只读操作提示。占格规则和动手书写分为子任务；笔顺与四线格横向并排，书写记录独立于拼读。 |
| Start to read | 教材图与全部阅读证据并排；读完后自动进入证据定位题。 |
| Part C 项目 | 先听读制作计划并判断起始动作；实际制作以表单和作品预览并排，多个内容使用直接按钮逐项编辑。有效作品检查保存后自动进入实际介绍，不能只保存结构就完成项目。原有单元自评保留为独立选学页。 |
| Reading time / Revision | 按真实分镜分幕，每幕先听读画面，再找该幕线索；听读和判断都完成后自动进入下一幕。所有幕完成后才推进主阶段。 |
| 实际表达 | 左侧情境图与任务，右侧示范/句子提示、录音与实际表现记录。跟示范、借提示、自己说三个层级逐项实际尝试后自动推进；角色扮演保留为可见选练入口。 |

原声歌曲、chant、孤立音位与原声听后任务继续保留，录音缺失时明确待补。普通点读不算原声听力完成，奖励不代表这些专项能力已经掌握。没有新增补充听力题库。

2026-10-10 字母歌谣：六单元的两个部分均为同一段录音的文字，同页完整展示，共用一次播放器；按补充要求取消“原声听后任务”入口及其弹窗。自动播报及公共重播只读中文播放提示，不读字母、例词、歌谣句子或音位；孩子主动点击“完整词点读”时仍可听单个词。旧两个子 tab 的选择记录不再参与显示，必做任务与完成记录沿用。详见 [英语字母歌谣](英语字母歌谣.md)。

## 完成、恢复与自动推进

- 最子级任务从未完成变为实际完成后，约 750ms 自动进入下一未完成任务。主阶段只有全部必做内容已完成才自动推进。已完成页的回看、普通重绘和初次恢复不触发跳转。
- 每个故事线索、阅读证据、项目起始动作、节奏接龙、配对与实际书写分别保存真实任务状态。字母课的听读完成由认字母、拼读、实际书写共同决定，初次完成和刷新恢复都不再要求 `source:writing-rules` 回答记录；旧的规则回答及能力历史不删除。旧的 `sourceActivityDone` 总标记不能代替仍然必做的子任务检查。
- 表达层级、拼读层级、实际项目草稿及所有嵌套任务的选中位置按儿童/课文/阶段/任务隔离保存；切课、刷新和更换儿童不串状态。声音比较仍须成功听完整词或明确选择看读练习后才能回答。
- 项目结构检查与实际介绍分别完成；修改作品会撤回介绍完成。自记只能记为练习，家人观察与自动检查单独存储；使用提示不会被认证为无提示独立表现。
- 课程流程升级为 `sfz-english-g3a-flow-v6:<child>:<lesson>`，读取旧 v5 断点兼容。旧“知识延伸/学习反馈”映射到迁移挑战/已获奖励回顾，旧实际表达记录继续读取；不删除旧进度或历史能力证据。
- 选学歌曲原声、角色扮演、单元自评不参与普通教材必做集合；缺失原声不会阻塞孩子完成当前课堂，也不会自动标为听过。整个必做材料集合完成后可手动回到原声或选练页。

## 朗读与设备

- 按最子级 tab 进入自动朗读一次；换幕、表达层级、拼读层级分别触发。读取当前材料和按屏幕顺序排列的全部答案选项；填空/作品字段读填写要求，不读孩子保存的答案。公共栏提供“再听一遍”，题目旁提供圆形朗读图标。
- 声音与拼读属于听辨练习：进入子任务和公共“再听一遍”只读题目要求，不读选项、完整词、分音提示或新词示范。完整词由孩子点击“听完整词”播放，播放自然结束且成功后才能选择；停止或失败不开放答题。明确选择“先看词练习”才展示文字，并按辅助练习记录。
- 声音与拼读的顶部统一为标题／进度与原声并排，下方独立三步导航；听辨主体按“先听完整词／再选答案”两区并排，问题位于两区上方，状态反馈位于下方，避免将按钮和文字平均散落在整屏。读新词的要求跨两栏，左侧为单词和分音提示，右侧为录音与反馈；取消左右大卡片及重复的“读出来，自动检查”标题。分音提示各音用小标签与加号连成一排，未展开时不留空白槽；展开后仍在同一横屏内完整展示。原有朗读、提示标记与自动检查规则沿用。
- 英文教材词句与英文答案使用英文示范音色，中文要求使用中文音色。独立拼读环节只读要求，不先读出未示范的新词或孤立音位。
- 手动点读、听词、原声或录音优先于排队的自动朗读；切任务及退出停止旧音频。录音隐藏/退出时停止录音并释放麦克风；录音仍只用于本页回听，不上传或持久保存。
- 声音和语音开关继续有效；首次浏览器音频尚未激活时，在首次触摸后读当前任务。语音服务不可用时仍可完成文字与真实操作。
