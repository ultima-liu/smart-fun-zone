# 新手剧情流程（系统引导教程）

> 版本 v1.0 · 与代码实现一致（`content/story.ts` + `features.ts` + `NpcBuddy`/`StoryStrip`）
> 目标：新登录的孩子在引导下，**按顺序**完成剧情，功能随剧情**逐个解锁**，如同游戏新手关。

---

## 〇、总览

- **剧情条**（首页顶部，呼吸高亮 + 手指）始终指向**当前唯一可推进的任务**；点击剧情条 → 跳到对应功能页面。
- 首页使用三栏布局时，剧情条固定在**中栏、卷星正上方**；它与卷星均参与正常布局流，保留间距，不得遮挡下方内容。
- **解锁对话发生在功能页的 NPC 上**：进入页面后 NPC 头部出现「!」，自动弹出气泡对话（逐句朗读）。对话完成后回首页，在任务条点击「🎁 领取」统一领取卷星币与该 NPC 的对应图鉴卡；动作型节点仍只发放卷星币。
- **没有剧情时**点 NPC → 随机闲聊一句。
- 新手剧情**未全部完成时也不再锁定页面滚动**：引导期间允许自由滚动浏览（原 `body.story-lock-scroll` 的 `overflow: hidden` 与强制回到顶部已移除）。
- 部分节点（上课/玩游戏）不对话、只做动作，达成后在首页剧情条点「🎁 领取奖励」结算。

## 三、功能门禁（按剧情解锁）

| 功能 | 解锁条件 | 覆盖路由 |
|---|---|---|
| 学校 `school` | 完成序章 p1 | `/map` `/subject` `/learn` `/practice` |

| 补给站 `store` | 完成 c2-2 | `/store` |
| 总部 `hq` | **始终开放**（序章对话在总部完成） | `/profile` |

未解锁时：
- 底部导航**置灰 + 🔒**，点击不跳转（音效 + 语音提示）。
- 首页入口（学科轨道 / 补给站积分 / 继续学习 / 星球建筑）点击被拦截。
- 直接输 URL 也进不去（FeatureGate 锁定页：「××× 还未开启 · 先回首页看剧情」）。

## 四、交互与反馈

- **剧情条**：首页顶部，整条**光晕呼吸**（不缩放，避免越界）+ 手指 👆 +「点击剧情继续」；点击任意处按状态执行：跳出对话场景 / 领取奖励 / 进对应页。
- **NPC 立绘**：人形卡通形象，悬浮在页头右上；有进行中剧情时头部出现「!」并**进页自动触发对话**；无剧情点击→**随机闲聊**。
- **对话气泡**：NPC 旁小气泡，逐句朗读；「继续 ▸」推进，「完成 ✓」结束；「✕」跳过（不计完成）。
- **自定义音效**：开门 `door`、引擎 `thrust`（startThrust 持续）、进入 `enter`、领取 `collect`、解锁建筑 `spotUnlock` 等，全部走火山 TTS / WebAudio。
- **完成反馈**：
  - 对话完成 → 自动跳回首页，卷星对应建筑**解封动画**（灰暗🔒→金光粒子爆开 + 「××× · 解锁！」飘字）；非建筑节点 → 卷星**中心点灯** +「任务完成！」。
  - 领取奖励 → 全屏**星星金币爆开** + 金色横幅「🎉 奖励已领取！」。

## 五、语音与设置

- 语音朗读统一走火山 TTS（`speak`），受「声音总开关 + 语音朗读」控制；后端 `/api/health` 的 `ttsConfigured` 需为 true。
- `speakVolc` 带**请求令牌**，避免并发朗读叠音（"两个人同时读"问题已修复）。
