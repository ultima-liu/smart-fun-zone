## 页面布局

- 数学课文页与语文、英语课文页一致，取消应用外层和课文页的居中限宽，铺满 Pad 横屏可用宽度；左右仅保留相同的 20px 内容内边距，不再留下大块空白。五阶段共用此布局。本次仅调整 UI，按 `AGENTS.md` 不运行 E2E 用例。
- 2026-10-09 布局检查：比大小课的五阶段在 1024×768、1366×768 横屏下，应用外层与课文页均与视口等宽，页面没有横向溢出或整体缩小。
- 保留“先猜 → 动手试 → 说理由 → 小检测 → 智能闯关”五阶段导航。
- 进入当前最子级任务时自动朗读题目和全部可见答案选项，顺序点击数字的操作题只读要求、不枚举数字卡，填空题读填写要求；公共提示右侧提供“再听一遍”，具体行为见[数学任务自动朗读](数学任务自动朗读.md)。
- 本课公共提示直接放在五阶段导航下面，例如“比大小 · 一一对应”“先配对，再写符号”及方法说明；所有阶段都可看见。
- 左侧移除聪聪老师整张讲解卡片，包括标题、讲解文字与操作按钮，只保留任务 tab 等当前必要的操作入口。“不懂就问”放在公共提示语右侧，使用问号对话气泡配明确文字按钮，并显示“点我问聪聪”，让孩子直接知道可以点击；入口至少 44px。
- 点击提问按钮打开独立答疑窗口，保留本课快捷问题、文字与语音输入、回答朗读和关闭入口，支持 Esc 关闭及返回按钮焦点；对话按完整消息切换，不挤占课文主区，不生成滚动条。切换学习阶段后重新开始该阶段的答疑，与原行为一致。页头“听聪聪讲”保留。
- 左侧从顶部开始竖排任务 tab。动手阶段根据每课实际任务显示“教材任务 1”“教材任务 2”等实际教材任务，完成后显示 ✓。任务标题只作导航，完整任务要求显示在右侧内容顶部。
- 左栏通常宽 124px，竖屏宽度下为 112px；任务按钮至少 48px 高。主要空间留给右侧当前图片、学具、问题和操作。
- 没有任务 tab 的阶段不渲染左栏，内容自动铺满整行，包括原任务栏空间；当前适用于“先猜”“小检测”和“智能闯关”，Web / Pad 各断点一致。
- “先猜”删除学前测试、学习准备与支持路径选择，孩子直接观察并选择猜想，不判对错，记录后自动进入动手试。不再依据旧学前测试的支持路径精简课内闯关题目；历史路径记录和证据不清除。
- 比大小教材任务一压缩顶部为一行任务标题，整张任务卡按左右结构排列。左侧是操作区：三组情境切换、并排的小猴和水果数量调整、配对进度及材料；右侧是说明区：配对步骤、自由探索说明、即时反馈、比较结果，以及小朗读图标、撤销、再配一次按钮。名称不折成竖排，加减按钮固定 44px，右侧说明和按钮与材料始终同时可见。分与合将分玉米操作与关系图并排，其他分合教材将待分材料与篮子并排；连续变化将当前材料与待加入材料并排，十格框限制合理宽度。认数课横屏将数量与学具放在左列、书写放在右列，算盘独占一行。“1～5 的认识”内容及完成条件见[1～5 的认识任务与排版](1～5的认识任务与排版.md)。
- 不显示“上个活动 / 下个活动”或阶段末尾的继续按钮。课内仍保留检查答案、表达完成、知识判断和检测中间题的“下一题”等真实操作。
- 数学教材、教具箱和生活练习采用固定尺寸模式，所有嵌套活动继承这一规则：数量、反馈或完成状态改变时不自动缩放整页。页头与阶段导航保持位置，内容过长时只滚动当前任务区；材料托盘有固定高度，数量多时在托盘内滚动，长数线在轨道内横向滚动。图片、材料和操作仍属于同一项活动，不拆成分页；触摸目标至少 44px。小游戏继续沿用原来的整场景适配规则。

“说理由”左栏展示“说出理由 / 知识延伸”。说出理由只保留一次文字或语音输入，输入结束后 AI 直接给结果，通过即解锁知识延伸，不再填写补充说明、单独提交录音、点击 AI 确认或再做关系选择。具体交互与兼容规则见[数学理由自动检查](数学理由自动检查.md)。“智能闯关”删除生活迁移及整个左侧任务栏，题目与完成反馈直接铺满内容区。公共提示和提问入口位置保持一致。

### 子任务完成门槛（2026-10-08）

教材任务包含子 tab 时，所有有可核验完成条件的子任务都须完成，不能用第一张卡的完成代替整个教材任务。旧的总完成勾选须以实际子任务作答重新核验；恢复已完成任务或手动回看不误触发跳转。修复原因、逐项规则和验证见[数学教材子任务完成与推进](数学教材子任务完成与推进.md)。

2026-10-10 补充：连续任务完成后停在终点，明确点击“再做一次”才重置。内层、本轮任务包和大阶段共用本轮完成状态；重做末题也会自动进入后续待完成任务或“说理由”。反馈延迟期间其他完成状态更新不再吞掉跳转。全册逐课检查范围见[数学自动跳转排查](数学自动跳转排查.md)。

## 完成状态与自动推进

| 位置 | 推进条件 |
| --- | --- |
| 先猜 → 动手试 | 已提交猜想，无需学前测试或准备路径选择 |
| 动手阶段的任务 | 当前真实教材任务完成后，转到后面的第一个未完成任务 |
| 动手试 → 说理由 | 实际教材任务全部完成，不再要求小探索 |
| 说出理由 → 知识延伸 | 一次文字或语音表达由 AI 自动检查通过，无额外关系选择 |
| 说理由 → 小检测 | 理由表达与知识延伸均完成 |
| 小检测 → 智能闯关 | 最后一题正确后自动记录本组检测结果，进入闯关 |
| 智能闯关完成 | 最后一题正确后自动记录闯关结果和原有课程奖励，留在完成反馈；没有生活迁移步骤 |

任务之间保留约 750ms 的成功反馈，阶段及最后一题保留约 1s。不能以点击 tab、看过内容或旧的笼统“动手完成”标记代替真实完成条件。

已完成的教材任务记录保留，回看时自由改变数量或材料不会丢失完成勾选。手动选择已完成任务或已解锁阶段后停留在所选内容，不反复自动跳走；在已解锁课程中完成新的待做任务，仍会自动向前推进。手动切换、离开页面时取消待执行的任务跳转。

同阶段任务面板保持挂载，切换 tab 保留答案、学具和书写状态。任务 tab 支持点击，以及上下箭头、Home、End 键选择。
