## 独立 UI 风格

- 视觉名：**西行绘卷**。墨绿黑与旧金为基底，朱砂藏印，青玉与骨白按角色点缀。
- 独立卡面渲染组件采用完整画作、古金双线边框、云纹四角、编号藏印、人物称号与归属。保留画作本身色彩，不叠加旧卡牌的增艳滤镜。
- 选择西游记套系后，档案库切换为西游卷首、墨绿展柜、古金按钮及对应浅色/深色主题；详情采用纸绢底色，卡背采用墨绿和金线。
- 未拥有时可查看画作预览，明确显示“待收集”；真实拥有记录仍以抽卡/授予为准，不预先点亮。
- 详情显示人物介绍、原创题句、身份、法器/本领、造型依据，以及可点击的原著回目。
- Web 展柜最多五列；1100px 以下四列、850px 以下三列、600px 以下两列。iPad 支持横竖屏，窄屏详情上下排列并可滚动。
- 卡牌支持点击或 Enter/空格打开详情。游客可按套系筛选画作；登录后可使用完整收集和详情交互。

## 收集与资源

- 加入现有全套系召唤池，也兼容已有指定套系抽卡函数。未增加额外付费入口。
- 沿用单抽 100、十连 900 卷星币与既有稀有度权重；集齐十张领取 500 卷星币一次。
- 资源为十张独立 WebP，位于 `public/assets/cards/journey/`，每张约 0.3–0.4 MB；由 `src/content/characterAssets.ts` 统一引用。西游画作含场景背景。
- 使用内置 **imagegen** 工具生成，原始 PNG 保留于 Codex 生成目录，优化 WebP 保存到项目。生成规格和人物提示词见 [西游记美术提示词.json](西游记美术提示词.json)。
- 人物数据及造型依据：`src/content/journeyCards.ts`；独立卡面：`src/components/JourneyPortrait.tsx`；卷首与详情：`src/components/JourneyCollection.tsx`；样式：`src/pages/journey-cards.css`。
