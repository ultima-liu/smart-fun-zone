# 数学一年级上册教材覆盖台账

本台账是整册修复的唯一审计基线，按教材**印刷页码** P1-P111 建立，而不是按 PDF 文件页码建立。

- [mathTextbookCoverage.ts](../src/content/mathTextbookCoverage.ts) 是页级归属表：每一页只归属一个课时，用于防止遗漏或重复认领。
- [mathTextbookTaskLedger.ts](../src/content/mathTextbookTaskLedger.ts) 是任务级台账：一行就是教材上一个可观察、可验收的动作，ID 固定为 `MATH-G1-P页码-序号`；它记录归属课时、当前缺失状态和验收标识。

验收标识是实现时必须补齐的用例名称或自动化测试选择器，不表示该用例已经存在；只有实际用例落地并通过后，任务才可改为 `implemented`。自动化基线同时校验 P1-P111 的页级唯一归属、任务级逐页覆盖、任务 ID 唯一性和课时归属有效性。

## 状态定义

- `partial`：已有同名或相近课时，但教材任务、表征或练习不完整。
- `missing`：现有课程没有等价任务。
- `planned`：完整计划已经拆出独立课时，但课程尚未创建。
- `implemented`：仅在原任务、等价交互、练习、表达/检查和验收均完成后使用。

## 使用规则

1. 开始任何数学课程改造前，先从台账 ID 领取范围。
2. 完成一个教材任务时，同时更新课程数据中的 `coverageIds`、任务级台账状态和相关测试；不可只更新页级归属。
3. 不允许删除或合并台账项来让覆盖率看起来更高；需要合并呈现时，仍保留各自的覆盖 ID。
4. 新增 5 课时前使用 `planned`；课时落地后改为对应真实 ID，并按实际完成程度更新状态。当前 5 节均已创建，状态为 `partial`，不能因目录可进入而写成 `implemented`。
5. 全部条目变为 `implemented` 前，整册不得标记为“教材完整”。
