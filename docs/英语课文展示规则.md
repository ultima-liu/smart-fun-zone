# 英语课文展示规则

2026-10-10：覆盖英语三年级上册全部 44 课的展示规划。最初仅统一“插图＋点读”，此次扩展到歌曲、字母歌谣、独立原声、表达示范、角色台词与复习答案。共用原则见 [课程内容展示规则](课程内容展示规则.md)。仅适配 Pad 横屏。

## 通用规则

1. 页面保留课程标题、学习步骤、公共提示与当前任务层级。任务顶部放标题和既有进度／说明，不额外堆叠介绍卡片。
2. 连续文字始终按教材顺序单列排列，不能因句子多而拆成左右两列。独立单词、字母才采用网格；同一录音的不同部分使用分区标题，而不是拆录音 tab。
3. 每句话呈现为紧凑文字行：左侧小序号／完成勾，中间正文与人物名，右侧小朗读图标。整行可点击，普通行最小 48px，独立词的点读触摸区域最小 44px。不采用每句一个圆角大卡片，不用 `1fr` 均分剩余高度。
4. 普通正文 18–20px，人物名与提示 12–13px，完整显示；句子按可用宽度适配字号，不截断、不省略。字母歌谣 16px，将同一字母的音位、例词、例句合为完整句组行，原文与顺序不变。
5. 先按实际横屏可用高度分配标题、播放器、正文和操作空间，禁止用滚动条作为布局修复的兜底。字母课必须一次完整呈现；不能用隐藏溢出、裁字、压缩整页或删内容来通过验收。长材料的历史局部滚动检查不等于无滚动验收。
6. 原声使用统一“小唱片”皮肤，与对应完整教材材料集中展示。取消通用“原声听后任务”入口，原书本身的听力题保留在对应录音旁；播放不作为完成条件。
7. 完成只改变小勾，已完成内容继续显示和可点读。反馈采用轻量文字；展示调整不改变点读、作答、录音、完成与自动推进条件。

## 两个基本阅读结构

- **有对应插图**：左侧约 34% 展示完整图片，右侧约 66% 放播放器、紧凑正文和反馈；间隔 18–24px。图片保持比例、不拉成空白高框，可点图放大；图下显示放大提示，不遮挡教材文字。
- **无对应插图**：阅读区居中，最大宽度 880px；顶部播放器，下方正文。无需为播放器单开右栏，也不为了凑两栏增加图片。独立原声页沿用同样的顶部对齐方式。

## 全部课型与阶段的对应关系

| 位置 | 统一呈现方式 |
| --- | --- |
| 六单元开篇歌谣接龙 | 左图右文，播放器在正文顶部，单列逐拍点读，保留顺序检查与反馈。 |
| 六单元歌曲原声 | 顶部播放器＋单列歌词，保留全部重复句；完整歌词同栏直接展示，保留全部重复句，不再按三／四句切段。 |
| Part A/B 对话、动作、短句 | 左教材场景右原声与单列句子，人物名附于对应句子。 |
| Part A/B 词汇 | 两列独立词项，配图固定 72×72px；单词和原有例句都保留。 |
| 认字母 | 每个字母一行，四／五行同时展示。行内依次是大小写及点读、两个并列例词、跟读；标题旁提供完整字母表入口，不混入整册录音。行高至少 60px，例词／跟读触摸区域至少 48px。中文、40×40px 合适配图和全部内容保留，无正文滚动。 |
| 字母歌谣 | “教材听读”默认第一页保留主课“字母与例词”的完整教材图，后接附录 P80–82 的大字歌谣，按完整字母组续页，同一播放器持续播放；保留原书页对照。互动练习同时展示“字母歌谣”“词中声音歌谣”两部分，每个字母的完整句组合为一行，底部保留完整词点读。两部分不拆录音 tab，自动播报只读操作提示。 |
| 声音与拼读 | 教材首音／尾音题在原声旁展示原图和原选项，与自编三步拼读分开。自编任务标题／进度、独立导航、正文依次排列；听完整词与选答案并排；合音页左侧单词与分音，右侧录音、反馈和完成短句。不保留空提示槽，不滚动正文。 |
| 占格规则、规范书写 | 规则页示意图与四类字母的 2×2 说明并排，口诀在底部；书写页标题与字母选择同排，范字和屏幕书写并排，下方操作／状态稳定，无嵌套滚动。四条横线无外框，描写提示持续显示。 |
| Start to read | 左图右文，原声在顶部，证据按原文顺序单列；判断题仍用题目结构。 |
| Reading time / Revision | Reading time 没有配套录音，不编造教材原声。Revision 五段原声分别对应具体原书栏目；互动分幕阅读和线索题保持，文字合成点读采用标题旁小播放图标。 |
| 项目计划、项目原声 | 制作步骤左图右文，步骤按顺序；独立原声顶部对齐。实际编辑仍为表单与作品预览并排，作品介绍示范用标题旁小播放图标。 |
| 实际表达 | 左侧情境，右侧示范／提示与录音；示范短句与播放操作合为紧凑点读行。 |
| 角色扮演 | 台词按轮次单列，当前轮轻量突出；按完整对话轮次续页，保留角色、录音按钮及全部台词，不使用正文滚动。 |
| 看图发现、教材练习、迁移挑战 | 题目、必要图片／演示、紧凑选项、反馈组成完整任务；题目与选项完整单行。配对等实际操作保留真实操作布局。 |
| 复习答案 | 显示提示后的答案采用同一紧凑点读行，录音与回想条件保持。 |

## 共享实现与核对

- `EnglishReadingLayout` 根据有无 `picture` 选择插图分栏或纯文字结构，承接原声、正文与反馈。
- `EnglishReadingLine` 统一源材料、开篇、歌词、完整词、示范、拼读完成短句及复习答案的点读呈现。各调用位置只传材料与已有点击行为，不重复定义大句子按钮。
- 不保留旧歌曲两列布局、句子等高拉伸与仅限定于插图页的点读样式。
- UI 调整按项目约定不运行 E2E；以 TypeScript、相关组件 ESLint、空白检查及 Pad 横屏页面核对验证。重点检查六单元歌曲、五字母歌谣、词汇、长台词与局部滚动。

2026-10-10 验证完成：TypeScript、6 个修改组件／页面的 ESLint 与空白检查通过。1024×768 逐页核对六单元歌曲（6／8／12 句），全部为单列 48px 点读行、无页面溢出，长歌词仅在正文区滚动；核对 Friends 与 Numbers 字母歌谣，保留两个部分及 3／6 个完整词。1366×1024 核对词汇、对话、阅读、项目步骤、独立原声、故事和 Revision，配图保持 72×72px，材料顺序及内容完整。全局角色台词和作品介绍采用共享显示／播放规范，未为了预览额外完成儿童的录音或作品检查。本次没有运行 E2E。

## 2026-10-11 原声与原教材材料

教材听读按录音数量并排展示：一段为单栏，两段为左右两栏，三段为等宽三栏。所有栏目及各自材料、播放器同时可见，不使用下拉框、栏目按钮或栏目切换。每栏保留中文标题、图标及教材页码；播放、进度、重播各自独立，开始播放另一栏时暂停正在播放的音频，避免声音叠加。

歌曲的全部歌词与重复句直接同栏显示，不再按三／四句切段。多栏歌词采用 16px／20px 行距，较长歌句可自然换行；每句话仍只在对应歌曲栏内按原顺序排列。跨页原书材料的查看与续页操作留在各自栏底部，切文字页不切断录音。辨音题在各自栏内纵向排题，图片、选项及自动反馈完整保留。附录仍是单栏完整词表／字母表。

原声区域由 `EnglishRecordedMaterials` 统一呈现，每栏固定分配标题、播放器、正文、原页操作空间。附录使用有限视口高度；不隐藏正文，不出现页面或正文滚动条。七段附录录音不挂局部练习，原书辨音与自编拼读分开。取消通用原声听后入口，播放不算完成。现有互动点读、跟读与书写仍在同课互动练习中保留。详细对应见 [音频对应检查](英语教材音频对应检查.md)。

## 字母歌谣 Pad 大字文字（2026-10-11）

六单元的字母歌谣默认第一页保留主课“字母与例词”图文，随后使用可重排的歌谣文字，避免把高而窄的附录截图缩进整栏后字迹过小。正文在 1024×768 横屏为 20px／26px 行距；宽度至少 1180px、高度至少 900px 时使用 24px／32px 行距。按照原书 P80–82 保留字母名、结尾重复句、每个音位的两次重复、例词及完整句，词序与原书一致。

材料按“主课字母与例词图文 → 字母名歌谣 → 词中声音歌谣”排列，主课图文不得移到原书对照入口代替默认展示。文字后续按完整字母组展示“词中声音歌谣”；两栏布局每页两个字母组，三栏布局每页一个字母组。Friends、Families、Animals、Plants 各4页，Colours 5页，Numbers 7页，共28页（六张主课教材图＋22页大字歌谣）。翻页仅切换文字，同一段录音、播放器和播放进度保持；不是把录音的两个部分拆成两个活动 tab。各录音仍按原规则同时分栏展示，文字页不用下拉框，不出现正文滚动条。原书截图保留在“查看原书页”入口，返回后仍在当前文字页。歌谣文字不加入语音合成朗读。

验证：1024×768 实际逐页检查六单元全部22页，字号均为20px，所有正文都在内容区内，没有页面或局部滚动条；1366×1024 检查 Families 两栏词中歌谣、Numbers 三栏字母名歌谣，字号为24px、无越界及滚动。播放 Families 原声后切换文字页，确认录音仍播放、时间继续前进。TypeScript、相关组件和专项测试文件 ESLint 通过。维护已有 E2E 的原书页入口定位，按纯 UI 修改约定未运行 E2E。
