## 对应与展示规则

- 每段录音明确绑定一个课时或附录入口，同时记录完整原文／原题的原书区域；不能只凭页码匹配，同页多个栏目也不能互相替代。
- 有录音的课时在“听读原课”内提供“教材听读”和“互动练习”。前者显示录音对应的完整教材材料，后者保留既有点读、跟读、书写、角色扮演和项目操作。自编拼读任务不挂教材辨音录音。
- 六份 `Words in each unit` 对应 P83–85 附录的完整单元词表，共 108 个词条；`The alphabet` 对应 P91 的完整 Aa–Zz。七段附录录音独立展示，不冒充 Part A/B 几个例词或每单元四／五个字母的录音。
- 附录词汇／字母卡片整张可点击点读，并显示小喇叭；词汇先用英文读单词，再用中文读该词释义，字母使用英文 `Letter A` 等形式读字母名，不把 Aa 连读成单词。支持键盘 Enter／空格和重复点读；点读暂停教材原声，切换附录或离开页面停止当前点读，不新增完成条件。
- 首音、尾音题采用原书图片与原有字母选项，成功开始播放对应录音后才能作答；自动判断，错题可重选，不要求孩子或家长确认。
- 歌曲完整歌词（含重复句）直接同栏展示；字母名及词中声音歌谣是同一录音的两个部分，原文可通过续页按钮查看，切文字页不切断录音。
- 播放器直接嵌入材料上方，沿用“小唱片”皮肤，提供播放／暂停、进度、时长和重播。取消通用“原声听后任务”入口，不新增播放次数、听完录音等完成条件。教材听读只自动播报操作提示，不合成朗读录音文字。
- 同课录音同时展示：一段单栏，两段左右两栏，三段等宽三栏。每栏中文标题、对应材料与独立播放器直接可见，不用下拉框或栏目切换。播放另一栏会暂停前一栏。
- 只适配 Pad 横屏。播放器、导航与完整材料保持一屏；长原书材料按明确续页展示，不隐藏正文、不用滚动条承接。
- 没有耳机录音的 Reading time 等内容不编造原声。

## 原书区域生成

`scripts/render-english-recorded-materials.py` 从已核对的 JSON 区域生成原书展示材料和辨音图片，不根据标题或页码推测绑定。需要 Poppler、Pillow，运行时传入上述 PDF 的绝对路径。印刷 Pn 对应 PDF 第 n+5 页。区域调整后需重新生成并检查实际图片边界。

下载脚本 `scripts/download-english-g3-originals.py` 仅用于官方节点文件下载和 MD5 校验，凭据不进入代码、来源目录或文档；本地凭据文件由 Git 本地排除规则忽略。重新下载／转码必须保留已核对的映射，不能覆盖成按页码猜测的目录。
