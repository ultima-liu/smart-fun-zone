# 课程完成后的重复练习

更新日期：2026-10-10。适用范围：语文、英语、数学课程，界面按 Pad 横屏设计。

## 确定的规则

- 完成是进度状态。教材学具等操作任务完成后保留题目与操作入口；数学检测和智能闯关整组结束后显示独立完成页，不再显示最后一道题。点击「再做一次」后重新进入本组第一题。
- 已完成的题目可以重复作答，需要清空整组操作时提供重做入口。英语教材练习的选择题直接点击选项即可再次作答，顶部不显示“已完成／再做一次”；奇偶配对的重置入口放在操作区下方，显示“重新配对”。
- 首次练习继续保存断点，首次真实完成仍按既有规则自动推进。重新查看或重做已完成任务不撤销完成勾选、已有星级及解锁状态，也不当成新完成而自动跳走。
- 连续任务整组完成后从原组第一题开始重复练习；重做使用本页独立草稿，刷新或重新进入仍保留已验证的完成记录。未完成的任务仍恢复原断点。
- 十和一学具保留当前操作结果：点击“捆成 1 个十”后，十根散开的小棒变成用绳带捆好的一捆，十位显示 1；首次完成、回看和刷新都保留结果，不立即重置为散开的小棒。只有点击“再做一次”才清空本轮操作，重做完成后仍保留一捆及所摆的个位，历史完成记录不变。首次完成仍按原来的成功反馈时长自动进入后续任务。
- 练习中的实际能力表现继续单独记录，历史完成进度不代表每次作答都正确。
- 数字顺序学具完成后保留结果和「再做一次」；重做重新打乱卡片并恢复点击，完成快照不变。立即重做会取消首次完成后尚未执行的自动跳转，详见[数学顺序点击练习](数学顺序点击练习.md)。
