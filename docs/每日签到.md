# 每日签到

## 领取规则

- 签到以设备本地自然日为准，每位孩子每天仅可领取一次。
- 连续签到未中断时依次累计；漏签后下一次从第 1 天开始，累计签到次数不清零。
- 第 1、2、4、5、6 天：5 卷卷豆；第 3 天：10 卷卷豆；第 7 天：20 卷卷豆与 3 星尘。第 7 天后继续签到，从新一轮第 1 天计算奖励。

## 数据与入口

- Zustand 持久化数据：`dailyCheckin[childId]`，包含 `lastDate`、`streak`、`total`。
- 总部右侧的“每日星签”是唯一领取入口。成功签到会写入积分流水，并在第 7 天增加材料柜中的星尘。
