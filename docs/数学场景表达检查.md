# 数学场景表达检查

更新日期：2026-10-10。适用范围：一年级数学上册 47 课的动手任务，以及共用题目朗读。

## 场景表达约定

先让孩子知道要做什么，再呈现可操作的材料。题干、材料、点击动作、语音和反馈必须表达同一种数学关系。

- 材料名称不能代替操作要求，例如不能只朗读“数轴轨道”。
- 数序用连续编号和等距位置表达；比较远近时保留同一排实物，允许数相邻位置之间的步数。
- 静态说明使用普通文字，不能设计得像可点击的页签。
- 物品与单位保持一致，整捆和零散的物品必须能从图上分辨。
- 问题依赖的路线、分组或数量材料必须出现在当前页，不让孩子猜原教材图。
- 顺序点击成功的车厢立即显示深绿色底色、白色编号和对勾；保持完整不透明度，禁用重复点击时不能变成灰色。
- 已完成的任务仍能主动重做；回放草稿不覆盖首次完成记录和奖励。

## 实现与兼容

火车保留旧进度键 `twenty-number-rail`、`twenty-number-near`、`twenty-number-near-eighteen`。旧版完成记录可直接恢复；明确点击“再做一次”后从第一步开始，重复练习不覆盖首次记录。车厢的物理顺序保持从小到大，这里是在学习数轴，不使用找数字卡题的随机排列。

共用朗读在当前卡没有明确操作或问题时，查找其所属任务要求；只描述故事的连续变化卡补读当前动作按钮。字段中的孩子答案、完成反馈和隐藏兄弟卡不参与朗读。

## 检查范围

使用隔离儿童档案和模拟语音接口，遍历 47 课、266 个动手任务状态，核对最内层卡的要求、可操作材料、选项与朗读内容。本轮不是对全部随机题或实体 iPad Safari 的穷举验证。

## 2026-10-10 · 车厢点击反馈修正

已复现浅色主题下车厢有 `visited` 和 `aria-pressed=true`，但通用按钮的浅色背景覆盖了已点亮样式，导致操作成功后仍像没有点击。车厢样式增加明确作用域，已点亮车厢显示深绿色、白色编号、绿色描边和白色对勾。未点亮车厢保持浅蓝色，小熊所在车厢保留黄色。点击反馈仅调整 UI，按项目约定使用横屏预览核对。

同轮修复火车重做完成后不进入外层 tab2 的功能问题，详见[教材子任务完成与推进](数学教材子任务完成与推进.md)。相关 E2E 只用于检查首次完成与重做的自动跳转、进度恢复，不为纯样式改动添加用例。

点击反馈分别核对 1024×768 浅色与 1280×800 深色 Pad 横屏：已点亮车厢保持深绿色和对勾，不因禁用状态变灰；未点亮车厢保持浅蓝色。
