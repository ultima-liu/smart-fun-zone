# 首页任务展示改造

日期：2026-10-02｜状态：星环来信版与 3D 卷星首页已实施。

## 一、改造边界

首页升级为真实 3D 卷星科幻世界，完整场景细节见[卷星3D首页](卷星3D首页.md)。保留顶部状态与控制区、中央可交互卷星、卷星上的学校/总部/档案库/船坞入口、悬浮的补给站与空中乐园、底部补给领取、镜头安定和学习助手。首页不再重复显示底部列车导航。

原首页左侧身份卡和右侧任务卡删除。孩子档案缩为顶部头像入口；原身份卡中的属性雷达、学科百分比和继续学习条不再占首页空间。旧右侧每日/每周任务列表彻底退出儿童端。

## 二、当前结构

1. **顶部**：孩子头像、名字和头衔用于切换档案；Web 与 Pad 均保留余额；右侧常驻复习和设置；语言、声音、主题、全屏及家长入口折叠到设置，场景底部提供“认识地点”。
2. **中央卷星**：仍是首页主视觉和主要目的地导航。孩子可以拖动或滚轮环绕完整 360°，点击模型或 HTML 名称入口；地点下方显示场景名，聚焦或悬停时底部补充用途。点选后短镜头过渡进入原模块。
3. **两条送达渠道**：课程表邮件、复习和家长约定进入卷星旁的星环收件站；存在实际未读的来信时，小邮差飞船按新邮件 ID 在当前会话执行一次送达，并显示“新来信”。已读来信仍保留待处理状态，完成但未领奖时独立显示“奖励待领取”。挑战、探索和主题活动只以漂流讯息出现在空间安全区，点击后直接阅读，不进入信箱、不触发信箱提示。
4. **三个信箱分类**：当前来信保存当天尚未领奖的全部课程邮件；未完成保存以前日期仍未完成或未领奖的邮件；已完成保存已完成并领取奖励的邮件。分类内容固定为左右双栏，左侧列出全部任务条目，右侧显示选中条目的详情。点击漂流物打开独立的漂流讯息界面，不显示信箱分类。
5. **全局导航与学习助手**：首页只保留学习助手，一级目的地通过卷星场景进入；分层 SVG 星际列车改为仅在主要二级页面显示，方便跨模块切换。具体视觉、动效和适配规则见[首页底部星际列车导航](首页底部星际列车导航.md)。

## 三、任务怎样展示

课程邮件完全由管理端周课程表决定，不再询问学科偏好。管理员为周一至周五选择当天学科，系统为每个学科按教材顺序选择第一节未完成且从未发信的课程；一节课对应一封邮件，邮件显示实际来信日期、完整课名、未开始／未完成／已完成状态和生成时的奖励。

信纸顶部固定保留关闭入口和“当前来信、未完成、已完成”三个分类，内容区独立滚动。左侧列表始终展示当前分类中的全部任务，点击任务后在右侧查看详情和主操作。没有“稍后处理”操作；关闭详情、合上信箱或选择其他条目都不会移除任务。课程完成后先显示“已完成 · 待领奖”，领取后才增加卷星币并移入已完成。完成一节课不会立即生成下一封邮件；后续邮件只在课程表中的对应学科上课日生成。

课程、每日复习和家长任务进入收件站；专项挑战、探索支线和主题活动使用空间漂流讯息。章节任务在课程结算时自动推进和庆祝，不额外要求孩子领取。七类只用于系统配置与家长理解，不作为儿童首页的七个入口。

## 四、固定调度规则

当天课程表中的每个学科最多生成一封邮件，全部进入当前来信，并按日期和稳定 ID 排序。没有剩余未完成且从未发信的课程时不生成空邮件。课程之外的复习、家长任务和来访继续使用各自调度；挑战、探索和活动只出现在空间漂流渠道。课程完成不会触发“下一节课程”推送。

来访任务每天最多主动出现两项。孩子可以放走当前漂流讯息，或点击“自己探索”进入地图；同一访问会话内不继续用新来访打扰。所有地点仍可自由进入，任务不会锁首页功能。

## 五、响应式要求

Web 和 Pad 横竖屏均以卷星为中心，六处地点与收件站围绕卷星分布，首页移除远征战舰；竖屏保持场景世界坐标，通过底部定位找到视口外或背面设施。低高度、触屏和竖屏允许滚动，不裁切入口。地点名称按钮至少 48px 高。信纸继续保持左侧任务列表与右侧详情的双栏，主行动按钮至少 72px。漂流来访使用实际内容，不伪造装饰任务。

## 六、阅读与欢迎动效

首次会话有镜头安定，返回时短欢迎；阅读结束欢迎、暂停场景环境时间，关闭后恢复。后台和场景不可见时停止持续绘制，减少动态效果时取消自动飞行与导航过渡。完整交互、资源释放、回退与性能边界见[卷星3D首页](卷星3D首页.md)。

状态优先级、已读存储范围与地点提示细节见[首页体验优化](首页体验优化.md)。

任务种类、完成条件和奖励规则见[任务系统](任务系统.md)，具体调度与拒绝规则见[呈现与交互](任务系统/呈现与交互.md)。
