# 首页任务展示改造

日期：2026-09-29｜状态：已实施。

## 一、改造边界

首页继续使用原有卷星观测台，不重做整个首页。保留顶部状态与控制区、中央可交互卷星、卷星上的学校/总部/档案库/船坞入口、悬浮的补给站与空中乐园、远征战利品、到达动画、底部导航和学习助手。

原首页左侧身份卡和右侧任务卡删除。孩子档案缩为顶部头像入口；原身份卡中的属性雷达、学科百分比和继续学习条不再占首页空间。旧右侧每日/每周任务列表彻底退出儿童端。

## 二、当前结构

1. **顶部**：孩子头像、名字和头衔用于切换档案；中间保留余额；右侧保留语言、声音、主题、全屏和复习入口。
2. **中央卷星**：仍是首页主视觉和主要目的地导航。孩子可以拖动、点击卷星，或直接进入原有地点。
3. **航行通讯**：桌面上停靠在卷星右下方的空白处，一次显示一件具体任务的标题和直接出发按钮。它采用环形通讯器与光带造型，不压缩卷星，也不占用整行高度。
4. **任务航行舱**：点击通讯内容打开覆盖在场景上方的宇宙航行界面。这里有当前航线、星际书包、星光收获三个视图；它们是孩子当下的行动与回顾，不是七类任务导航。书包保存已开始但未完成的事项及到期家人任务，收获只回看完成结果。
5. **底部导航与学习助手**：恢复首页显示，继续沿用项目原来的主要导航方式。

## 三、任务怎样展示

首次没有学科偏好时，首页通讯只问“今天想先学哪门课”。点开航行舱后，在当前航线中选择数学、语文、英语；选择后立即显示该学科下一节具体课程。

正常状态下，首页通讯只显示送达提示、当前任务标题和直接出发按钮。点击通讯内容进入航行舱，当前航线完整呈现说明、奖励、出发、“换一个航线”和“自己逛逛”。完成后，首页通讯先显示本次成果；在航行舱确认后再看下一件事。整个流程不使用小弹出卡和底部抽屉。

航行舱的顶部固定保留关闭入口和三个视图，内容区独立滚动。书包和收获条目可以完整阅读；书包里的任务可直接继续。关闭后回到原卷星位置，不改变当前任务选择。

课程、每日复习、专项挑战、探索支线、主题活动和家长任务都使用这个送达位置。章节任务在课程结算时自动推进和庆祝，不额外要求孩子领取。七类只用于系统配置与家长理解，不作为儿童首页的七个入口。

## 四、固定调度规则

首页按以下顺序选择当前内容：刚完成的成果、暂停中的任务、到期家长任务、当天复习、首次学科选择、匹配当前学科的来访任务、下一节课程。同级任务按教材顺序或固定 ID 处理，避免刷新后随机变化。

来访任务每天最多主动出现两项。点击“换一个”后，当天不再主动送同一项；点击“自己逛逛”后，30 分钟内不继续用新来访打扰。所有地点仍可自由进入，任务不会锁首页功能。

## 五、响应式要求

Web 以原尺寸卷星为中心，任务通讯停靠在卷星右下方的空白区域，并避开学习助手；平板上通讯排在卷星下方，保持卷星优先。航行舱按视口居中，占用可阅读的宽度和高度；顶部固定、内容区滚动，不裁切长列表或遮住关闭按钮。主要行动按钮保持足够触控面积，首页任务文字不覆盖卷星上的地点入口。本项目仅按 Web 与平板适配。

任务种类、完成条件和奖励规则见[任务系统](任务系统.md)，具体调度与拒绝规则见[呈现与交互](任务系统/呈现与交互.md)。
