# 英语字母课布局检查

2026-10-10。按用户要求重排，页面与正文都不能出现滚动条，不能删内容、裁内容或缩小整页。仅适配 Pad 横屏。前版 48 状态检查没有验收正文实际滚动高度，旧版局部滚动方案已废止。

## 最终布局

1. 认字母：标题与原声并排，每个字母一行；行内依次是大小写及点读、两个例词、跟读入口。四／五个字母与 52 个例词全部保留；行高至少 60px，例词／跟读触摸区域至少 48px。
2. 声音与拼读：顶部标题／进度与原声并排，下方独立三步导航。听词与作答分区；合音页左侧显示单词与分音，右侧录音、识别反馈和完成短句。展开提示也不需要滚动。
3. 字母歌谣：原声与标题说明并排；同一录音的两部分同时呈现，每个字母的音位、例词、例句合成完整句组行，保留原文及顺序。底部完整词可点读，没有原声听后任务，也不自动朗读录音文字。
4. 占格规则：示意图与四类字母的 2×2 说明并排，口诀在底部。书写页标题与选字母同排，范字／手写并排，下方保留操作、状态及检查说明。描写提示持续显示，四线格无外框。
5. 共用场景初次显示继续提供默认居中，测量后的定位沿用；本次没有改变学习完成或自动推进条件。
