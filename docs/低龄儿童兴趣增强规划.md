# 低龄儿童兴趣增强规划

版本：v1.2

状态：方向已确认，首个试点已实现

确认日期：2026-09-28

## 一、目标

面向 3–8 岁儿童，尤其是识字量有限、注意力时间较短的低龄儿童，把学习从连续答题转为有角色陪伴、有实际目的、有可见成果的短篇游戏体验。

规划围绕三种核心感受展开：

- **我想帮它**：孩子与小卷建立持续的陪伴关系，学习任务具有情感动机。
- **我想试试**：孩子可通过点选、拖动和探索自行发现答案，错误只触发线索与再次尝试。
- **这是我做的**：学习产生可以保留、展示和继续使用的作品或场景变化。

## 二、功能规划

| 优先级 | 功能 | 核心玩法 | 与现有系统的关系 |
| --- | --- | --- | --- |
| P0 | 卷星生活小剧场 | 在水果店、野餐、修理铺等生活场景中完成 2–5 分钟的小任务 | 复用语音、游戏结算、星星与课程知识点 |
| P1 | 小卷陪伴成长 | 小卷记住近期共同完成的事情，以表情、语音和新互动回应成长 | 复用小卷角色、剧情节点与孩子档案 |
| P1 | 我的星球小屋 | 种花、铺路、摆家具，学习成果转化为长期保留的场景变化 | 承接学习花园、装扮和物品体系 |
| P2 | 会回应的互动绘本 | 听故事、点角色、拖道具、选择故事下一步 | 扩展现有剧情与语音能力 |
| P2 | 我来当小老师 | 让孩子帮助小卷解题、纠正小卷的可解释错误 | 用于课程复习和知识迁移 |
| P2 | 卷星创作工坊 | 用形状、颜色、角色和贴纸创作作品并保存到展览墙 | 复用图鉴素材和物品资源 |

首期只实现 P0 试点；其他功能先保留规划，不同时铺开。

## 三、首个试点：小卷水果店

### 3.1 定位

「小卷水果店」是一段以帮助兔兔店长招待客人为目标的数学情境游戏。孩子通过给顾客分水果、补齐缺少的数量和判断哪一篮更多，练习点数、一一对应、数量补足和大小比较。

首期目标年龄为 3–6 岁，单次体验控制在 3–5 分钟。结合当前空中乐园已经移除全部游戏入口的决定，首版作为数学课程或今日复习中的「情境实践课」接入，不恢复旧游戏大厅；验证玩法后再评估独立的生活小剧场入口，并与小屋成果联动。

### 3.2 单局流程

1. 兔兔店长欢迎孩子，并说明今天来了几位动物客人。
2. 孩子选择一位客人，听取它想要的水果数量。
3. 孩子把水果逐个拖进篮子，篮子和客人同步进行点数反馈。
4. 数量不足或过多时不判失败，兔兔店长提示孩子观察空位或重新数一遍。
5. 三位客人都拿到正确数量后进入野餐合照。
6. 结算展示本局完成的帮助、星星和一张可保存的水果贴纸。

### 3.3 难度分层

| 年龄/级别 | 数量范围 | 主要操作 | 知识目标 |
| --- | --- | --- | --- |
| 3–4 岁 / L1 | 1–5 | 拖入对应数量，固定篮子圆点提示 | 点数与一一对应 |
| 4–5 岁 / L2 | 1–10 | 补齐缺少的水果、选择更多或更少 | 数量补足与比较 |
| 5–6 岁 / L3 | 10 以内 | 根据两位客人的总需求进行分配 | 简单加减与分解 |

同一轮连续两次需要提示时，下一题减少数量或恢复圆点辅助；连续三题独立完成时，下一题可小幅增加数量。难度变化不向孩子展示“降级”字样。

### 3.4 低龄交互规则

- 开始任务不依赖阅读，指令同时使用角色动作、画面高亮与语音。
- 每个画面只保留一个主要目标，主操作热区不小于 72px。
- 首题由兔兔店长演示一次；孩子开始操作后不连续打断。
- 拖错位置时水果回弹，并用目标篮子的轻微发光提供线索。
- 数量错误时先邀请重新点数，再显示篮子圆点，不出现红叉、扣分或失败页。
- 每次完成一位客人的需求都立即获得角色表情、简短语音和场景变化。
- 结算以“帮助了谁、完成了什么”为主，星星作为附加反馈。

### 3.5 内容与数据结构

关卡继续采用配置驱动，建议每题至少包含：

- 客人角色、情境语音与目标水果；
- 目标数量、初始数量和可选干扰物；
- 能力标签，如 `counting`、`one-to-one`、`compare`、`make-up`；
- 演示方式、一级提示和二级提示；
- 完成反馈、贴纸奖励和适用年龄段。

学习记录至少保留能力标签、是否独立完成、使用提示次数和完成时长，用于后续推荐与难度调整；不把点击速度作为学习能力指标。

## 四、后续联动

试点验证有效后，按以下顺序扩展：

1. 小卷在首页记住孩子最近帮助过的客人，并发起下一次邀请。
2. 水果店获得的贴纸可以放入星球小屋或作品墙。
3. 数学课程完成后，如果本课内容适合水果店，直接推荐本课专属的水果店情境作为迁移练习。
4. 复习系统在相关知识到期时生成新的客人订单，不直接重复原题。
5. 继续以相同框架增加公交站、整理房间等场景，覆盖不适合水果店、野餐或修理铺的课程。

## 五、试点评估标准

内部试玩和后续儿童试用重点观察：

- 孩子能否在不读文字的情况下独立开始第一项任务；
- 是否愿意在第一次错误后继续尝试；
- 能否理解学习操作正在帮助故事角色；
- 完成后是否愿意再招待一组客人；
- 更换水果和角色后，能否继续使用同一种数学方法；
- 提示是否真正帮助观察，而不是直接暴露答案。

若多数孩子需要成人逐句解释，优先修正语音、动作演示和画面线索，不通过增加文字说明解决。

## 六、明确边界

- 不设置公开排名、连败惩罚、倒计时催促或随机付费奖励。
- 陪伴反馈以预先设计的安全语音和状态为主，首期不接入开放式儿童聊天。
- 现实世界探险卡必须由家长选择或确认，不要求儿童上传照片、语音或个人信息。
- 首期不把新玩法加入每日任务，避免兴趣试点变成必须完成的清单。

## 八、与正式课程的结合方式

状态：2026-09-28 已确认；按课场景映射、课程结尾入口、复习匹配、水果店、动物野餐和形状修理铺已实现。

### 8.1 总体原则

课程与兴趣功能采用按课对应的简单规则：

1. 每节课先完成自己的课堂操作。
2. 根据本课知识选择最自然的生活场景；水果店、野餐、修理铺都只是可选场景。
3. 场景固定三步短任务，全部练习本课核心能力，不拼入前后课程内容。
4. 间隔复习复用同一节课的场景配置，在当天、第 2 天和第 4 天更换任务顺序或表面题目。

### 8.2 兴趣功能的课程职责

| 功能 | 接入频率 | 在课程中的职责 |
| --- | --- | --- |
| 小卷陪伴成长 | 每节课 | 回忆上次经历、朗读任务、提供分级提示、认可孩子使用的方法 |
| 卷星生活小剧场 | 按适合的课程 | 用三步专属任务迁移本课方法；没有合适场景的课程暂不显示 |
| 我的星球小屋 | 每个单元 | 承接单元成果和创作物，形成长期保留的个人空间 |
| 会回应的互动绘本 | 每个语言或生活主题 | 串联阅读、听说、顺序和情绪理解，不要求每课配置一册 |
| 我来当小老师 | 按薄弱点触发 | 在反复需要提示时，让孩子用摆放、选择或完整句式把方法教给小卷 |
| 卷星创作工坊 | 单元收尾 | 综合多个知识点完成可以保存的作品 |
| 现实世界探险卡 | 每周 1～2 个、由家长选择 | 把课程知识迁移到家庭和户外，不加入儿童每日必做任务 |

### 8.3 生活小剧场与数学课程映射

| 场景 | 当前接入课程 | 专属任务方向 |
| --- | --- | --- |
| 小卷水果店 | 1～5 的认识；比大小；6～9 的比大小和第几；分与合；6～9 的分与合；1～5 的加法、减法；求一共有几只、求还剩几只、求一共有多少；10 的认识；9 加几；8、7、6 加几；8＋9 的多种算法 | 装篮、比较订单、分装水果、合计、售出后求剩余和十格盒凑十 |
| 小卷动物野餐 | 在校园里找一找；在操场上玩一玩；在教室里认一认；在教室里玩一玩；学习准备；第几 | 准备物品、安排座位、辨认左右、按顺序领取食物和遵守出发时间 |
| 小卷形状修理铺 | 认识立体图形；立体图形的拼搭；立体图形拼一拼；复习与关联：立体图形 | 选择零件形状、判断滚动和稳定、搭建底座与拼组方块 |

以上课程完成后在结尾显示对应生活小剧场的非强制入口。每个场景的三步任务都直接对应刚学的能力；表中未列出的课程当前不显示生活小剧场。同一课程重复进入保持任务稳定，后续复习节点再更换任务顺序或表面情境，检验孩子能否迁移同一种方法。

### 8.4 数据与推荐规则

- 课程、情境实践和复习题统一使用能力标签，例如 `counting`、`one-to-one`、`compare`、`make-up`、`compose`、`addition`。
- 情境实践记录独立完成、提示后完成、提示次数和用时；用时仅用于发现操作阻塞，不直接判断学习能力。
- 孩子连续独立完成某能力时，可以减少图形辅助或增加一步条件；连续需要帮助时，先恢复圆点、配对和操作演示。
- 情境实践可以更新能力画像，但不能替代正式课程的教材学习、课堂练习和课程完成状态。
- 家长报告优先展示「能独立完成什么」「在什么提示下完成」，正确率作为补充信息。
- 课程订单按孩子、课程和难度稳定生成；复习订单额外按当天、第 2 天、第 4 天区分。只有难度或复习节点变化，以及孩子主动开启下一组时，订单才随之变化。

### 8.5 推荐实施顺序

1. ✅ 给现有数学课程补齐统一能力标签和课程到情境任务的映射表。
2. ✅ 让课程结尾按标签推荐水果店对应订单，并让今日复习按到期标签生成任务。
3. ✅ 为水果店补齐加法、减法、凑十三类订单，覆盖一年级上册更多核心内容。
4. ✅ 使用同一套情境框架实现「动物野餐」和「形状修理铺」，复用角色、提示、记录与推荐能力。
5. 接入星球小屋，把单元成果和水果贴纸转化为可摆放、可回看的长期作品。

### 8.6 当前落地示例

- 完成「1～5 的加法」后，进入小卷水果店，三张订单都把两部分水果合起来。
- 完成「在教室里认一认」后，进入小卷动物野餐，通过安排野餐座位练习参照物、左右和第几。
- 完成「认识立体图形」后，进入小卷形状修理铺，通过选择零件练习球、圆柱、正方体和长方体的特征。
- 上述课程进入当天、第 2 天和第 4 天复习时，继续使用该课对应的生活场景并呈现稳定变式。
