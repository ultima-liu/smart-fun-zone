# 英语看图发现

2026-10-09 修正：看图发现按课时配置，停止让同单元所有课文共用单元首页的问题。六个单元的 42 课和两课 Revision 都有独立的主问题与两个观察方向，数据维护在 `src/content/englishDiscovery.ts`。

各类课时的观察重点：

- 主题与问题：保留单元大问题，观察单元开篇情境。
- Part A / Part B：围绕本课对话人物、动作与交流目的提问，例如 Mike 与 Binbin 互相问候、Sarah 帮 Chen Jie 分享彩笔、购物时区分水果数量和钱数。
- Letters and sounds：观察本课字母及例词中的位置，各单元使用自己的字母与词，不能把文字图片当作已经听懂音素的证据。
- Start to read：观察海报、短文或故事里的线索，带着问题读原文，例如家庭的共同点、颜色提示的意义、生日故事中数字的用途。
- Part C 项目：观察需要制作的实际作品，问题对应思维导图、家庭树、动物图画书、纸上花园、颜色翻页书与生日卡。
- Reading time：围绕本课故事的角色、关系或变化提问。
- Revision：分别观察到访时的介绍与回应、一起玩时的礼貌行为。

图片通常使用本课第一张教材页。六个项目课使用本课最后一页的制作与分享画面，避免显示前一页听力练习却问后面的作品。图片不能越过当前课的页码范围。

儿童选择一个想了解的问题后进入听读。这里是选择观察方向，不设置唯一正确答案，不把好奇心选择记成能力测验。历史完成进度与奖励保留；已完成课程可以重新选择。切换课文时同步切换主问题、观察方向和图片，旧选择不能替新课完成。
