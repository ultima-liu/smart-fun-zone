# 数学任务自动朗读

更新日期：2026-10-10。适用范围：数学全册 47 课。

## 确定的行为

- 纯讲解自动播一次完整方法、例子和口诀；只保留公共重播按钮。首次完整播完按知识桥顺序进入下一步，回看与重播不跳走。详见[课程纯讲解自动播放](课程纯讲解自动播放.md)。
- 进入当前最子级任务时，自动朗读一遍题目和全部可见答案选项，按照画面上的选项顺序朗读。
- 顺序点击数字的操作题只读操作要求，不逐个播报供选择的数字卡；返回或主动重播也遵守这条规则。普通判断题继续朗读选项，详见[数学顺序点击练习](数学顺序点击练习.md)。
- 填空题朗读填写要求，算式题朗读完整算式的填写要求，不播报正确答案或孩子已经填写的内容。
- 触发粒度按实际任务层级确定：五阶段下面有教材任务时，以教材任务为准；教材任务下面还有完整任务卡或更内层任务卡时，以最后一层任务卡为准。隐藏的任务面板保持挂载，但不参与朗读。
- 某张任务卡只有操作材料、材料名称或算式时，补读所属任务的操作要求；连续变化题若题干只描述故事，补读当前按钮的动作。优先使用当前卡的明确指令，不合并兄弟卡的题目和选项。火车车厢等特殊操作提供与画面一致的完整指令，顺序点击不枚举编号。
- 返回先前看过的任务时重新朗读一次。点击已选中的同一个 tab、填写答案、改变完成勾选、显示提示或反馈，以及窗口尺寸变化，都不触发重复朗读。检测和闯关换到下一题或替换新题时，朗读新题。
- 公共提示语右侧增加蓝色扬声器“再听一遍”按钮，位于“不懂就问”左边，点击重读当前最子级任务。原题目旁“听题”按钮保留，单独朗读题目。
- 切换任务、切换课文或离开页面时，停止旧朗读并取消尚未开始的待播；快速连续切换只播报最后停留的任务。
- 朗读遵循现有声音与语音开关。关闭时不自动播放，重播按钮禁用；开启后朗读当前任务，不批量补播之前的任务。
- 首次从网址直接进入且浏览器尚未允许音频播放时，等待首次鼠标、触摸或键盘交互，再朗读当时所在任务。启动画面退出后才开始自动朗读。
- 删除原有外层学习阶段的自动讲解，避免和最子级题目朗读重复或互相打断。答题即时反馈、朗读示例与课内答疑保留。

教材实际操作、独立作答判断、课文断点、星级和奖励沿用现有逻辑。知识桥的纯讲解由播放结束推进，静音时保留阅读入口；回看和重播不自动跳页。朗读题目和全部选项不会将孩子标记为使用答题提示。

## 实现与兼容

课文主区统一识别当前可见最子级面板；任务切换后留出 250ms 让嵌套任务卡完成注册，只为当前叶子安排一次朗读。重播实时读取当前题目与选项。检测题直接提供本题朗读内容与题目标识，确保换题、随机变式和替换题都使用对应内容，且不包含正确答案字段。

任务编号、输入框无障碍名称和键盘导航保持原样。所有课文共享一个重播按钮，避免每张卡额外增加一排操作或占用内容页空间。

教材任务 1 已删除摆一摆与生活中找一找，教材任务 2 已删除点子与数字连线，自动朗读只收集当前保留的题目与选项。任务 2 页面和朗读顺序均为 ① 圈选、② 数字与实物连线、③ 数序，详见[1～5 的认识任务与排版](1～5的认识任务与排版.md)。以下全册记录保留朗读功能首次验证时点。

- 3 个相关浏览器用例通过，覆盖教材任务与两层嵌套任务卡、选择题题干与全部选项、提示不重读、填空题填写要求与重播，并在 1440×900 Web 中验证内容完整。语音接口使用隔离模拟，校验实际发送的朗读文本，不调用真实语音服务。
