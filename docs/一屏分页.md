# Web / Pad 单屏内容设计

更新日期：2026-10-08。

## 已确定的设计

Web 和 Pad 的课文学习页采用一屏一页，不出现页面上下或左右滚动条。数学目录按 2026-10-08 的最新约定例外：标题和单元入口固定，课文完整卡片可上下滑动，取消分页按钮并隐藏滚动条。页面必须按内容设计，禁止按屏幕像素高度截断长页面；一张图片、一个学具、一道题与它的操作不能分到两个内容页。

- 固定页面标题、当前单元或学习阶段；主要空间留给当前内容。
- 三科课文页面取消“上一课 / 下一课”按钮；更换课文通过页头返回对应学科目录选择。数学课文同时去掉底部学习状态与课程位置；语文、英语底部保留紧凑的课程位置与学习记录提示，将空间留给学习内容。
- 数学目录的课文卡片可上下滑动，单元直接点击选择；其他目录和商品列表按完整卡片翻组；横屏通常双列，窄分屏单列。卡片数量随展示区尺寸调整，不生成图片的“上半页”和“下半页”。
- 儿童学习页不通过折叠提示、目标或教材任务来省空间。这些内容直接显示，孩子进入页面即可看见。
- 必须分步完成的内容使用始终可见的活动入口，切换保留答题和操作状态，不把浏览活动误记为完成任务。语文、英语显示“正在做几 / 共几项”与“下个活动：具体名称”；数学用左侧任务 tab 和完成勾选，按真实完成状态自动推进。
- 数学公共提示位于五阶段导航下面，提示右侧用“不懂就问 / 点我问聪聪”按钮提供答疑；有任务时左侧放精简任务 tab，无任务 tab 的阶段由内容铺满整行。先猜直接观察图和选择猜想，不提供学前测试。课文内去掉“小卷水果店”的介绍与进入按钮；动物野餐、形状修理铺仍保留直接可见的入口。
- 三科目录直接显示学习路线、当前单元提示或教材页进度，不要求孩子点击小三角寻找说明。
- 图片使用完整展示和等比适配；游戏、题目、商品预览及弹窗作为完整场景适配可用空间。
- 教材提供“放大整页”，在独立预览中显示整张教材图片；装扮商品采用插画与介绍并列，避免图片被文字区挤压裁切。
- 预览关闭入口独立于内容区；底部导航、系统安全区和悬浮入口有预留空间。
- 不使用通用的“上一屏 / 下一屏 / 页首”去截取长页面，不依赖改变 `scrollTop` 展示内容。

## 页面组织

| 页面 | 内容设计 |
| --- | --- |
| 学校 | 选择年级，再看该年级六本课本；横屏六列，竖屏三列两行 |
| 三科目录 | 书名与整册进度、简短工具区、单元选择、完整课程卡片与翻组按钮 |
| 语文 | 看图找线索 / 教材完整页；完整听读 / 重点词语；教材任务 / 知识桥；阅读体验 / 迁移实践 / 口语；学习记录 / 挑战 |
| 数学 | 公共提示在五阶段导航下，左侧短标题任务 tab，右侧完整任务；认数展示、算盘和书写合为教材任务 1，教材练习为任务 2，另有小探索；完成自动推进，回看停留 |
| 英语 | 保留五步流程；故事每一幕明确展示“听读这一幕 / 找这一幕的线索”两个活动，整张插图与当幕四句对话同屏；字母发现、读词歌谣与书写分别展示；教材判断、实际操作和表达分别展示 |
| 总部、设置、船坞 | 成长 / 荣誉 / 收藏柜；孩子档案 / 声音显示 / 账号；飞船改装 / 进化图谱 |
| 档案库 | 套系与稀有度选择、完整卡牌展示；预览插画与介绍并列，故事资料单独展开 |
| 补给站 | 装扮 / 道具 / 奖励货架，完整商品卡翻组，整屏试穿预览 |
| 乐园 | 保留分类选择，完整游戏卡翻组；进入游戏后单独展示完整游戏界面 |
| 复习、错题、管理 | 完整复习任务、错题卡或数据行翻组；表单和分类入口保持可达 |
| 来信、助手 | 完整任务条目或消息切换；详情和输入区各自保留 |

## 实现约定

`src/components/ScreenPages.tsx` 提供以下展示能力：

- `ScreenPages` 只管理动态视口、安全区和底部导航预留；不计算分页边界。
- `ContentPages` 按完整 React 卡片、数据行或任务翻组；图片与卡片主体始终属于同一个元素。
- `ActivityDeck` 由页面明确传入活动内容与名称，保留隐藏活动的组件状态；语文、英语等启用 `guided`，显示编号路线、当前活动位置及上 / 下个活动入口。数学课文使用 `MathLessonActivityTabs` 和 `MathLessonActivityPanels`，不提供上 / 下个活动按钮。
- `WholeStage` 对完整活动或弹窗等比适配，不拆内容、不计算滚动偏移。优先通过页面重新排版提供足够空间，避免把整张长页面缩成很小的内容。

布局覆盖集中在 `src/screen-pages.css`，Pad 基础触控规则位于 `src/pad-layout.css`；首屏前独立加载样式。新页面先设计内容层级与活动边界，再使用布局组件，不能重新引入按高度切图片的分页方式。

2026-10-07 的儿童发现性调整：撤掉此前新增的老师提示、数学目标、教材任务、生活剧场和三科目录折叠区；不能以“保持单屏”为理由重新隐藏孩子当前需要知道的内容。家长观察表和系统设置与儿童学习引导分别设计。

老师文字优先简短地说明当前怎么做，目标与任务另行直接呈现；完整语音说明仍通过“再听一遍”播放。英语故事的幕次和活动入口并列，避免重复工具栏挤压教材插图。极窄或极短窗口先保留故事的最小排版高度，再整体适配，避免活动内容高度归零或被底部按钮遮住。

## 检查记录

2026-10-08 数学目录与全册课文横屏重排见[数学全册 Pad 横屏检查](数学全册Pad横屏检查.md)。数学课文布局与自动推进的前轮设计、36 个代表布局组合、47 课任务面板检查和相关功能验证见[数学课文布局与自动推进](数学课文布局与自动推进.md)。下方保留此前各轮检查存档。

使用隔离的 Chromium 浏览器体验档案，屏蔽真实 API；检查页面、分类、活动切换与预览画面，不执行答题提交、兑换、召唤或管理保存。

上一轮单屏设计复查视口包括 Web 1440 × 900、Pad 横屏 1024 × 768、Pad 竖屏 768 × 1024、分屏 540 × 720、短横屏 1024 × 500。检查 23 个主要路由共 115 个布局组合，未发现页面尺寸溢出或内部滚动区域；补查代表课程活动、教材整页与卡牌、商品预览，并在目录标题和商品卡调整后再次复查这四个页面。

本轮儿童发现性调整针对校园课准备与动手、认数课、语文观察、英语故事和三科目录，使用上述五种视口检查 40 个布局组合；另检查校园、认数、英语故事在横屏、竖屏与分屏中的活动入口切换，共 9 个组合。未出现页面尺寸溢出、内部滚动区或上述儿童引导折叠区。横竖屏 Pad 代表画面另作目视检查，确认当前插图、提示和下一活动入口可见。540px 分屏及 500px 短窗口仍采用更紧凑的整体适配，部分学具和文字较小，尺寸检查不能代替孩子在实体设备上的操作体验评估。

源码通过 TypeScript、生产构建与包体预算检查。按 `AGENTS.md` 的“只修改 UI，不跑相关用例”约定，不运行 E2E 功能用例。实体 iPad Safari、系统软键盘与浏览器工具栏仍需设备复查。
