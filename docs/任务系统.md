# 每日与每周任务系统

## 设计目标

任务使用明确、可核对的行为条目：签到、三门课程、图鉴召唤与商店兑换；不以小游戏局数、时长或游戏种类作为完成条件。每项任务独立结算，孩子可按自己的学习计划完成，不要求每天清空全部清单。

## 每日任务

| 任务 | 完成判定 | 奖励 |
| --- | --- | --- |
| 完成今日签到 | 当日已在总部领取签到 | 3 卷卷豆 |
| 完成一节语文课程 | 当日一节语文课的课堂练习正确率达到 80% 及以上 | 8 卷卷豆 |
| 完成一节数学课程 | 当日一节数学课的课堂练习正确率达到 80% 及以上 | 8 卷卷豆 |
| 完成一节英语课程 | 当日一节英语课的课堂练习正确率达到 80% 及以上 | 8 卷卷豆 |
| 完成一次图鉴召唤 | 当日在档案库完成一次单抽或十连 | 3 卷卷豆 |
| 在商店兑换一次物品 | 当日在补给站成功兑换一件虚拟物品 | 3 卷卷豆 |
| 升级一次飞船 | 当日在船坞成功升一级 | 15 卷卷豆 |
| 完成一个家长任务 | 当日由家长确认完成一项家庭任务 | 12 卷卷豆 |

每日任务在本地自然日零点重置；每个任务独立结算，不要求全部完成。

## 每周任务

| 任务 | 完成判定 | 奖励 |
| --- | --- | --- |
| 完成 3 节语文课程 | 本自然周有 3 节不同语文课的课堂练习正确率达到 80% 及以上 | 20 卷卷豆 |
| 完成 3 节数学课程 | 本自然周有 3 节不同数学课的课堂练习正确率达到 80% 及以上 | 20 卷卷豆 |
| 完成 2 节英语课程 | 本自然周有 2 节不同英语课的课堂练习正确率达到 80% 及以上 | 16 卷卷豆 |
| 完成 2 次图鉴召唤 | 本自然周在档案库完成两次单抽或十连 | 8 卷卷豆 |
| 兑换 2 件学习补给 | 本自然周在补给站成功兑换两件虚拟物品 | 8 卷卷豆 |

每周任务以周一零点为起点重置。任务奖励通过积分流水幂等入账，同一周期不会重复发放。

飞船已满级时，“升级一次飞船”不显示；没有家长布置的待完成任务时，“完成一个家长任务”也不显示。这样不会用不可完成的项目占据今日任务清单。

## 数据口径

- 达标课程：课堂练习正确率达到 80% 后产生 `练习达标`；同一课在同一周期只计一次。
- PEP 英语三年级上册独立课时使用 `english-g3a-<课时 id>`；本轮已实现的教材情境判断与知识迁移题都一次答对时记录达标，纳入今日/本周英语课程任务。原版歌曲、音位辨音与只听材料未提供时另有“听力待补”标记，不能当成已完成的听力目标（详见《英语三年级上册课程.md》）。
- 图鉴召唤：积分流水中的 `图鉴召唤`，单抽与十连都计作一次。
- 商店兑换：积分流水中的 `兑换商品`，仅成功购买虚拟物品后计入。
- 飞船升级：当天积分流水中的 `飞船升级`。
- 家长任务：`customTasks` 中当天被家长确认、带有 `doneAt` 的任务。
