# 任务系统

版本：v4 已实施｜日期：2026-09-29｜状态：七类任务、主动送达、首页中央任务展示、奖励结算与同步已接入产品。

## 已确认范围

保留七类：课程任务、章节任务、每日复习任务、专项挑战任务、探索支线任务、主题活动任务、家长任务。

剧情主线已从项目删除，不恢复剧情链、功能门禁或剧情领奖。平台每周任务、收集养成任务不纳入新系统；不得改名后塞进其他分类。图鉴、商店、飞船、徽章保留自身功能，但不生成“抽卡几次、购买几件、升几级”的平台任务。

本文件替代前几轮方向提案与数学首章样板，也是当前实现的产品规则入口。旧每日/每周任务清单与自动扫描已经移除。

## 分类与独立规格

| 类别 | 职责 | 周期 | 独立设计 |
| --- | --- | --- | --- |
| 课程任务 | 完成一节具体课程，三科各自推进 | 每课一次 | [课程任务](任务系统/课程任务.md) |
| 章节任务 | 完成一个教材单元，自动累计课时成果 | 每单元一次 | [章节任务](任务系统/章节任务.md) |
| 每日复习 | 回顾一节到期课程 | 每任务日最多一项 | [每日复习任务](任务系统/每日复习任务.md) |
| 专项挑战 | 对指定知识点完成独立挑战 | 每个挑战首次达标一次 | [专项挑战任务](任务系统/专项挑战任务.md) |
| 探索支线 | 在独立情境里应用知识、完成角色委托 | 每个委托一次 | [探索支线任务](任务系统/探索支线任务.md) |
| 主题活动 | 在开放期完成固定主题任务组 | 每期一次 | [主题活动任务](任务系统/主题活动任务.md) |
| 家长任务 | 完成家庭约定的现实事项 | 按约定周期 | [家长任务](任务系统/家长任务.md) |

界面采用主动送达：七类只用于内部规则，儿童端不设置分类任务中心。小卷或来访角色直接给出当前任务，孩子一键出发；首页保留原有中央卷星并删除左右固定卡。详见[呈现与交互](任务系统/呈现与交互.md)与[首页任务展示改造](首页场景与任务推送.md)。不设置平台“全部清空”奖励。

## 统一规范

每项任务必须有稳定 ID、类别、固定标题与说明、来源内容、前置、入口、完成条件、奖励、周期、进度口径、历史成果处理和内容版本。文本与目标来自教材映射或人工配置，不在运行时自由生成。

- 课程、章节按教材目录确定；每日复习按固定排序选取；挑战、探索、活动先有完整清单再发布。
- 进度只用客观数量，例如“4/6 课”“2/3 步”。没有课内检查点时显示未完成/已完成，不根据停留时间伪造百分比。
- 缺课程、题包、素材或完成事件的配置保持草稿，不出现无效的“去完成”入口。
- 任务前置只影响该任务，不锁学校、乐园等功能。
- 系统任务自动验证，线下家庭任务明确区分自报与家长确认。

## 首版奖励

| 类别 | 首版建议 | 去重范围 |
| --- | --- | --- |
| 课程 | 8 卷卷豆 | 孩子 + 教材 + 课时 |
| 章节 | 30 卷卷豆 | 孩子 + 教材 + 单元 |
| 每日复习 | 8 卷卷豆 | 孩子 + 任务日 |
| 专项挑战 | 15 卷卷豆 | 孩子 + 挑战 ID |
| 探索支线 | 10 卷卷豆 | 孩子 + 委托 ID |
| 主题活动 | 首个三步活动完成 18 卷卷豆 | 孩子 + 活动期次 |
| 家长 | 家长填写，可为 0，可关联允许发放的已有物品 | 孩子 + 家长任务 + 发生周期 |

以上是当前已接入的默认值，管理员可按七类统一调整奖励或停用某类系统任务。任务不额外发课程星、不改变乐园币、不授予尚未定义的徽章、不创建未制作的贴纸或新装扮。

课程“练习达标”基础豆已并入新课程任务，避免同一行为叠发。首版五个探索任务使用独立固定题组和独立任务 ID；原水果店与数学情境实践仍是自由活动，不会自动推进探索任务，因而不会对同一次任务完成叠发。签到、远征等独立系统经济保持原规则。

最后一课可以同时结算课程 + 章节；已经接受且开放中的活动若明确要求该行为，可再推进活动。复习只计复习，挑战只计挑战，不冒充新课完成。所有命中项目合并在一个结果面板逐项列明。

## 时间、存档与迁移

- 档案保存家庭时区，初始采用家庭设置或首次设备时区；任务日为该时区自然日。更改时区不重开已结算名额。复习仍沿用学习后的 0/2/4 天到期计算。
- 每日复习任务 ID 绑定任务日、课程与复习节点，刷新不会换题或重复奖励。
- 本地保存完成事实、任务状态和待同步奖励。服务端用稳定奖励键去重，不累加两台设备的余额；同步状态与完成状态分开。
- 切换档案严格隔离；刷新、回看、重练、同步重放不重复奖励。改文案不创建新奖励身份。
- 历史课程/章节承认完成，标记“已在更新前完成”，不追补新一次性奖励。历史部分完成的章节在更新后补齐剩余课程，可正常领章节奖励。
- 旧每日/每周入口与自动发奖扫描已关闭，不删除既有积分或学习成果。
- 家长任务已有周期、完成与待审核记录保留。取消平台每周任务不等于删除家长自行约定的每周某天事项。
