# 聪明乐园 · 产品质量升级方案（商业化品质版）

版本：v1.1 ｜ 范围：**只做产品质量，不做付费/订阅/登录/运营** ｜ 目标：达到可正式发布给真实用户使用的商业级品质

> 实施进度：阶段 1–5 已完成（v0.2）。详见下方各阶段完成情况与验收结果。

## 0. 商业级品质的定义（验收标准）

产品要达到"像正式上线的儿童产品"而不是"开发原型"，按下述六条验收：

1. **视觉**：有品牌感（Logo/吉祥物/统一设计系统），游戏有主题场景插画，无"白卡片 + emoji 拼凑"的开发感
2. **听觉**：有背景音乐、专业音效、清晰配音；BGM / 音效 / 语音三者可独立开关
3. **交互**：动效流畅（60fps）、反馈即时、防误触、无卡死、无逻辑漏洞
4. **内容**：12 个游戏全部可玩、关卡完整、难度曲线合理、知识内容准确
5. **可靠**：平板/手机/桌面均正常，弱网与离线可用，无崩溃，有错误兜底
6. **工程**：类型安全、lint 通过、核心逻辑有测试、可一键构建部署

## 1. 现状评估（Demo → 商业级的差距）

| 维度 | 现状 | 差距要点 | 优先级 |
|---|---|---|---|
| 视觉品牌 | emoji 图形、白卡片、通用样式 | 无品牌 IP、无场景插画、组件态不完整 | 最高 |
| 音频 | WebAudio 合成音效、浏览器 TTS | 无 BGM、音效单薄、配音质量一般、开关单一 | 高 |
| 动效 | 基础 CSS 动画 | 无页面转场、无粒子特效、无吉祥物反馈 | 高 |
| 内容 | 3 可玩 + 9 占位、每游戏 3 关 | 12 游戏未全、关卡少、成长系统未落地 | 高 |
| 可靠性 | 未做离线、适配靠响应式 | 无 PWA、无加载/错误态、无障碍不足 | 中 |
| 工程 | tsc + vite build | 无 lint、无测试、无 CI | 中 |

## 2. 视觉品牌与设计系统（最大差距）

- **品牌 IP**：吉祥物（建议"小恐龙"形象贯穿全局：Logo、加载页、胜利动画、空态插画）
- **设计令牌**：色板 / 圆角 / 阴影层级 / 间距 / 字号梯度 收敛为 CSS 变量规范
- **组件精修**：按钮、卡片、弹窗、进度条、徽章、开关的完整状态（默认/悬停/按压/禁用/加载）
- **场景插画**：6 大类别主题场景——农场（数学）、字母城（语言）、逻辑森林（逻辑）、记忆星空（专注）、自然花园（自然）、安全小镇（生活）
- **图标系统**：统一风格的 SVG 图标集（自绘或基于可商用开源库重绘统一样式）
- **素材路线**：一期用可商用高质量素材（Twemoji CC BY 4.0 / OpenMoji / 自绘 SVG）统一风格；二期可外包定制插画
- **字体**：确认商用授权（站酷快乐体免费商用 / 思源黑体 OFL），大号圆体排版规范

## 3. 音频系统

- **BGM**：大厅 / 游戏 / 结算 3 套轻快循环曲目（CC0 音乐库或自制作曲）
- **音效库**：点击、正确、错误、翻牌、收集、胜利、结算等 15+ 个专业音效（Kenney CC0 等）
- **配音**：优先用高质量 TTS 预录（如 edge-tts）替代运行时浏览器 TTS，文案情绪化、双语；保留运行时 TTS 作回退
- **设置升级**：BGM / 音效 / 语音三个独立开关（当前仅一个总开关）

## 4. 动效升级

- **页面转场**：路由切换淡入/滑动过渡（framer-motion 或轻量自研）
- **粒子系统**（Canvas）：星星收集飞入、胜利烟花、连击特效
- **吉祥物反馈**：答对鼓掌、答错摇头、胜利跳舞（SVG/CSS 动画）
- **物理感**：按钮弹性按压、卡片惯性滑动、结算星星弹跳
- **性能约束**：只动 transform/opacity、will-change 管理、避免布局抖动

## 5. 内容全量

- **补齐 9 个游戏**（按依赖顺序）：摘苹果、形状城堡、拼音钓鱼、汉字拼图、英语动物园、规律接龙、垃圾分类、动物在哪里、红绿灯
- **关卡扩充**：每游戏 3 关 → 5 关，覆盖 4 档年龄段难度
- **内容审核**：知识准确性校对、无不当内容、中英双语文案审校
- **成长系统落地**：学习花园（浇水长大）、每日任务、连续打卡日历
- **结算体验**：每关结束有成就播报与收集动画

## 6. 体验与可靠性

- **适配**：平板横屏优先；手机/桌面响应式；刘海/安全区适配
- **PWA**：离线缓存（Workbox）、可安装、启动屏与图标
- **状态处理**：加载骨架屏、错误重试、空态插画、弱网提示
- **防误触**：答题后锁定输入、连点防抖、双击放大禁用
- **无障碍**：对比度 WCAG AA、焦点可见、键盘可操作、aria 标签
- **家长引导**：首次进入的操作引导动画

## 7. 工程质量

- **Lint/格式**：ESLint + Prettier 接入并纳入构建
- **单元测试**：Vitest 覆盖核心逻辑（关卡生成、计分规则、存储读写、i18n）
- **E2E 测试**：Playwright 走通关键路径（建档 → 进游戏 → 答题 → 结算）
- **CI**：GitHub Actions（lint + test + build + 产物预览）
- **性能预算**：首屏 < 2s（本地），主包 gzip < 120KB，游戏素材按需懒加载

## 8. 素材版权策略

- 全部素材必须可商用：CC0 / 开源协议（Kenney、Twemoji CC BY 4.0、OpenMoji AGPL 注意替换）或自绘
- 字体商用授权确认（站酷快乐体 / 思源黑体 OFL）
- 建立素材清单（来源 + 协议）存档，规避版权风险

### 验收结果（v0.2）
- 视觉：吉祥物 IP + 6 场景插画 + 糖果设计系统 + SVG 图标 ✅
- 听觉：WebAudio 合成 BGM（大厅/游戏两套旋律）+ 8 类音效 + TTS 配音 + 三独立开关 ✅
- 交互：星星爆裂粒子 + 彩带 + 吉祥物动画 + 防误触锁定 ✅
- 内容：12 游戏 × 5 关全可玩 + 学习花园/每日任务/连续打卡 ✅
- 可靠：PWA 离线（SW + manifest + 图标）、错误边界、焦点可见、安全区、减少动效偏好 ✅
- 工程：ESLint 0 错误、Vitest 16 用例全过、Playwright E2E 主流程、GitHub Actions CI（quality + e2e）✅
- 性能：主包 gzip 78.7KB（预算 <120KB），首屏 <2s ✅

里程碑：
- **M1 视觉焕新版**（阶段 1+2）：观感/听感达到商业级
- **M2 内容完整版**（阶段 3）：12 游戏全可玩
- **M3 发布候选**（阶段 4+5）：可正式对外发布

## 10. 建议实施顺序

**阶段 1（视觉）→ 阶段 2（音频动效）→ 阶段 3（内容）→ 阶段 4/5（可靠与工程）**

理由：视觉与听觉是"demo 感"的最大来源，先升级收益最明显；内容全量决定可用性；可靠与工程在发布前收尾。
