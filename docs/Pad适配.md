# Web / Pad 布局适配

更新日期：2026-10-08。

## 适配原则

- 同一套页面支持 Web、Pad 横竖屏及分屏。按可用宽度决定排版，触屏大 Pad 额外放大常用控件。
- Web / Pad 以完整活动为布局单位：目录按完整卡片翻组，学习页按完整活动切换，管理表格按可用宽度重排。数学教材、教具与生活练习按 2026-10-10 的稳定尺寸约定，教材和生活练习在材料托盘及当前任务区允许局部滑动，独立教具箱按 2026-10-11 约定重排为无滚动工作台；均不根据数量变化自动缩小场景；其余页面沿用[一屏分页](一屏分页.md)。
- 儿童课程的老师提示、学习目标、当前教材任务和目录学习路线直接显示；分步活动提供明确入口，数学通过任务勾选和完成后自动推进引导，语文、英语保留下一活动入口，不靠折叠说明让孩子寻找内容。
- 普通按钮、输入框、筛选和关闭入口至少 44px 高。棋盘格、算珠、书写和拖拽学具保留组件自己的几何规则，不统一强行放大。
- 弹窗按完整场景适配，图片与确认操作保持一起；安全区使用 `env(safe-area-inset-*)`，高度使用动态视口 `dvh`。
- 允许用户手动缩放；触屏输入控件采用 16px 字号，减少 Safari 聚焦输入时的自动放大。

## 断点与实现

- `≤1194px`，以及 `≤1400px` 且主指针为触屏：Pad 共用控件、管理导航和游戏展示规则。
- `601–900px`：竖屏书架、游戏宽卡行和课程内容重排。
- `≤600px`：沿用窄屏结构，补充分屏下的课程步骤换行、管理表单换行和卡牌弹窗纵向布局。
- `pointer: coarse`：输入字号与普通按钮的触控优化；不覆盖拖拽学具和游戏专用的手势规则。

基础适配集中在 `src/pad-layout.css`，单屏布局与完整内容切换在 `src/screen-pages.css` 和 `src/components/ScreenPages.tsx`；通过明确的页面、控件类选择器覆盖历史样式。`src/main.tsx` 在首屏渲染前独立加载该样式，避免增加主样式包体积。`index.html` 的 viewport 保留手动缩放并启用安全区。

补给站商品预览使用 Portal 挂载到 `body`，避免页面入场动画的 transform 把固定弹层限制在长页面内部，造成预览面板出现在视口之外。商品预览与档案卡牌分别设置尺寸，消除同名 `.preview-card` 样式的影响。
