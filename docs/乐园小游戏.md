# 空中乐园 · 纯休闲小游戏模块

> 2026-09-28 确认的设计方案与实现口径。空中乐园定位为**与课程教学完全无关的纯娱乐街机厅**。

## 一、定位

- 乐园是孩子学完课后的放松奖励场景：进去就是玩，不考察任何知识点、不产生任何学习数据。
- 判断标准：删掉任何一个乐园游戏，课程学习不受任何影响。
- 不进课程推荐链路，不写入知识点掌握度（mastery）。
- **不发⭐星星、不发卷卷豆**——防止绕过任务/课程体系刷全局资源。
- 乐园自己的成长线：**最高分 + 乐园币 + 勋勋牌（二期）**，只在乐园内可见可用。

## 三、玩法框架

- **局制街机**：每局固定 60~90 秒（各游戏自定），分数制，无关卡包、无 L1–L5、无对错判定。
- **难度**：局内随时间渐升（加速/加密）；初速按孩子年龄档微调。
- **结算**：得分 + 打破最高分的庆祝动画 + 掉落乐园币 + 「再来一局」一键重开。
- **开局玩法说明卡（2026-09-28 补）**：进入游戏先弹「怎么玩」卡片——游戏大图标、玩法一句话、规则逐条（每条带 emoji 图标，含得分/扣分/结束方式），非计时局不显示秒数；泡泡同步语音讲解规则（语音自动剥离 emoji 只念文字）。**点「▶️ 开始玩」才挂载游戏组件并计时**，规则文案单一数据源在各游戏 `GameDef.rules`（中英双语），再玩一次不重复弹卡。

## 四、奖励与经济

- **乐园币（游戏币）**：按分数档 + 连击/破纪录彩蛋掉落；`gameCoins[childId]` 独立字段，不混入 `points`，不入商店。
- 消费端（二期）：局内小道具（磁铁吸星星/护盾挡刺球）、摩天轮舱皮肤、入场券造型。
- **星星口径**：乐园不发星。全局星星 = **课程星**（`childTotalStars` 从课程学习记录汇总，不再统计游戏 records），故事章节星数预告、首页/乐园头部的 ⭐ 均用课程星。

## 五、时长与休息

- 街机局时长计入每日限额（`todayPlaySec`，写入游戏 records），到点弹既有的休息弹窗。
- 连续玩 2 局后弹「喝口水，转转眼睛」轻提示（可关闭）。

## 六、页面与剧情

- 乐园页保留「云端游乐航站」视觉骨架；游戏入口以「游乐设施图集」回归；头部数据 = 课程星 / 卷卷豆 / 连胜，旁挂乐园币余额。
- 剧情第 2 章 c2-2「玩一局乐园小游戏」（rule `game`）正常完成；泡泡台词为街机厅口径。乐园门禁维持 c1-2。
- 家长报告游戏行：**最高分 / 局数 / 时长**，无正确率列（街机无对错）。

## 七、工程口径

- `GameDef`：去掉 `genre`/`levels`，增加 `durationSec`（一局时长）与游戏自述颜色；结算从星级改分数。
- `GameRecord`：新增 `score`（本局得分）；`stars` 恒为 0（字段保留，避免旧数据/云同步结构破坏）。
- 乐园币：store 新增 `gameCoins: Record<childId, number>` 与 `applyGameCoins(childId, delta)`；云端同步列为远期。
- e2e：乐园冒烟（进入 → 开一局 → 结算）为相关用例，随实现补充。

## 八、分期

1. **一期（核心）**：删教学游戏 → 街机框架（分数结算/时长统计/乐园币入账）→ 4 新 + 3 翻新 → 乐园页入口回归 → 星星口径切换 → c2-2 打通。
2. **二期**：乐园币消费端（道具/皮肤）、更多游戏、本机多孩子排行榜、勋章。
3. **远期**：records/gameCoins 云同步。
