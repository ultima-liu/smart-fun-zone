# 数学练习完成页

2026-10-09 确定：数学检测和智能闯关完成后不再显示上面的最后一道题；完成页只适配 Pad 横屏。

## 页面布局

- 整组完成时以独立结果页替换题干、题目材料、作答框、最后一题反馈和题号。公共朗读使用完成页提示，不再读最后一道题。
- 横屏左右两栏：左侧显示完成标志、完成标题和已有星星；右侧显示后续练习入口。占满课文可用内容区，不再将题目与结果纵向堆叠后整体缩小。
- 「再做一次」重新进入原组第一题；智能闯关保留「换一组新题，再独立试试」。
- 「我想挑战一下」在独立弹窗展示本课额外题，关闭返回完成页，不撑长结果页。额外挑战结果继续单独记录。

## 兼容

只调整结果页呈现与挑战的显示容器，不更改答题判定、进度记录、星级计算、一次性奖励和原有阶段推进。教材学具、知识延伸等完成后的保留原题规则不受影响；数学检测与闯关以本条新约定为准。

## 验证

本次为 UI 调整，按 AGENTS.md 不运行 E2E 用例。使用隔离的体验档案检查 Pad 横屏结果页、重复练习入口和挑战弹窗，不修改真实儿童数据。

## 2026-10-11 · 练习退出与返回

挑战结果页此前只显示“再做一次”，退出只依赖弹窗外部的小关闭图标，儿童不容易发现。挑战页改为内容内的固定标题栏，右侧始终显示至少 44px 的“退出挑战”按钮，未做完时也可随时退出。整组完成后的右侧操作区优先显示“返回课程”，关闭挑战并回到本课闯关完成页，保留“再做一次”。遮罩点击和 Escape 同样可退出，退出时停止正在播放的语音。

中途退出保留本组已完成题目，重新打开从未完成题继续；整组完成后退出保留挑战完成记录，不改变本课星级和奖励。课程闯关完成页补充“返回课程目录”，直达数学目录，不必反复进入练习才能离开。复习与错题入口保留各自原有的完成与返回流程。

本次只运行退出问题相关的 2 个端到端用例，在 1024×768、1194×834 Pad 横屏下均通过，覆盖退出按钮尺寸与可见性、中途退出恢复、Escape 退出、完成后返回、再次练习和星级不变，以及返回数学课程目录。截图见[挑战完成后的返回入口](assets/math-challenge-exit/挑战完成-1024.png)。
