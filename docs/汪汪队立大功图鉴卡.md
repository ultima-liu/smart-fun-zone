## 实现规则

- 套系 ID 为 `paw-patrol`，在档案库中独立筛选、收集与领奖。
- 每张卡通过 `src/content/characterAssets.ts` 的统一资源入口引用用户提供的 PNG 素材。
- 未解锁时仍展示本套系立绘预览，但保留锁定标记；抽到卡牌后按现有图鉴规则点亮。
- 卡面文案只描述角色在动画中的通用救援职责，不新增或改写剧情设定。
- 后续补充角色时，同步更新本文件、`src/content/starCards.ts`、`src/content/characterAssets.ts` 与对应测试。
