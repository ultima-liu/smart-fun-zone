# 本地启动指南

本项目 = **前端（Vite + React，端口 5173）** + **可选服务端（Fastify + MySQL，端口 8787）**。
纯前端启动即可体验大部分内容；语音（TTS）、家长账号/云同步需要把服务端一并跑起来。

## 0. 前置要求

- Node.js ≥ 18（Vite 5 生态），npm
- 可选：Docker（用于一键启动 MySQL）
- 可选：`npx playwright install chromium`（跑 E2E 测试前需要）

## 1. 快速启动（纯前端）

```bash
npm install
npm run dev        # 打开 http://localhost:5173
```

可用：英语/语文/数学课本、点读界面、跟读录音、小遊戏等大部分单机功能。
不可用：语音朗读（TTS）、家长账号登录与云同步——这些需要下面的服务端。

## 2. 语音（火山引擎 TTS）

朗读人声使用火山引擎 seed-tts-2.0，由**服务端代理注入密钥**（不进前端包）：

1. 根目录复制 `.env.example` 为 `.env.local`，填入密钥
   （火山引擎控制台 → 语音技术 → API Key 管理）：
   ```
   VOLC_SPEECH_API_KEY=你的密钥
   ```
2. 启动服务端（见第 3 节，监听 8787）。前端 Vite 已把 `/api` 代理到
   `http://127.0.0.1:8787`，语音请求自动到达服务端。
3. 重启 `npm run dev` 生效。未配置密钥或服务端未启动时，页面顶部会出现
   配置提示，语音静默（无兜底降级设计），页面其余功能不受影响。
4. 可选音色见 `.env.example`（`VITE_VOLC_SPEAKER_ZH/EN`、NPC 男声档位）。

排障：`curl http://127.0.0.1:8787/api/health` 可看服务端与 TTS 配置状态；
页面上确认右上角声音开关与"声音/语音"开关已打开。

## 3. 服务端 + 数据库（家长账号、云同步、内容包）

```bash
cd server
docker compose up -d mysql        # 启动 MySQL 8.0（本机已有可跳过）
npm install
cp .env.example .env              # 按需修改；VOLC_SPEECH_API_KEY 也在这里填
npm run db:init                   # 初始化数据库
node scripts/build-content-pack.mjs   # 从前端课程数据导出内容包
npm run seed                      # 导入内容包
npm run dev                       # 启动服务端 http://127.0.0.1:8787
npm run smoke                     # 接口冒烟测试（可选）
```

- `server/.env` 关键项：`MYSQL_*`（默认 root/sfz123456@127.0.0.1）、
  `JWT_SECRET`、`VOLC_SPEECH_API_KEY`（TTS 用）。
- 可选：小卷 LLM 学习助手需配 `CHAT_BASE_URL` / `CHAT_MODEL` / `CHAT_API_KEY`
  （OpenAI 兼容接口，baseUrl 填到 `/v1`）。
- 短信验证码默认 mock（固定 123456），接真实短信另配 `SMS_PROVIDER=aliyun`。
- 详细接口见 `server/README.md`。

启动顺序：**先服务端（8787），再前端（5173）**。

## 4. 构建、测试与工具

```bash
npm run build           # tsc 类型检查 + vite build（产物在 dist/）
npm run preview         # 预览构建产物（PWA 生效；/api 同样代理到 8787）
npm run lint            # ESLint（src + e2e）
npm run test            # Vitest 单元测试
npm run test:e2e        # Playwright E2E（首次先 npx playwright install chromium）
```

资产脚本（按需）：

- `node scripts/render-word-pictures.mjs`：重新生成英语词卡手绘插图
  （输出 `public/assets/english-textbook/words/`）。
- `npm run gen:words`：生成文本词条。
- 教材原版 MP3：放入 `public/assets/english-textbook/audio/` 并在
  `src/content/englishG3Audio.ts` 登记（详见 `docs/英语三年级上册课程.md`）。

## 5. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 语音朗读没声音 | ① 根目录 `.env.local` 未填密钥；② 服务端（8787）没启动；③ 页面声音/语音开关未打开 |
| 提示"星环学校未开启" | 新手剧情门禁：完成开篇剧情即解锁学校 |
| 家长中心登录失败 | 服务端或 MySQL 未启动；首次需 `db:init` + `seed` |
| E2E 报浏览器缺失 | `npx playwright install chromium` |
