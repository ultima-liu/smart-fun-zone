# 徽章系统

> 版本：v2.0（方案与内置数据）｜状态：旧徽章已下线；本方案定义后续授勋、展示与属性接入的唯一基线。

## 定位

徽章记录孩子在卷星世界里的真实里程碑：先完成故事里的第一步，再在学习、游戏、收集和远征中逐步精进。它**不能购买、不能交易、不会因重复练习而降级**。每枚只授予一次，已获得的加成永久生效；展示只是表达喜好，不影响强度。

## 展示规则

- 总部的「荣誉墙」展示全部已获徽章；按获得时间默认排序，可按学习、乐园、收集、远征筛选。
- 首页通行证可从已获徽章中精选最多 3 枚；默认展示最近获得的 3 枚。精选仅是外观展示，不会装备到角色身上。
- 获得瞬间弹出授勋卡：名称、意义、获得原因与属性增量；同一枚徽章的重复事件不重复弹出。
- 当前章节可获得但尚未达成的徽章显示轮廓和进度；未来章节保持未知，避免泄露后续剧情。
- 稀有度只服务于视觉与收藏排序（普通 / 稀有 / 史诗），不产生额外倍率，也没有排行榜比较。
- 每枚徽章使用一张独立透明背景的完整插画资产，主体造型直接表达徽章意义；禁止用通用线框符号代替，也不使用合图裁切。

## 属性规则

四维基础成长仍由课程、游戏、连续参与、远征等行为决定；徽章提供小而稳定的永久补正，作为“我走过这段旅程”的纪念，而非必须刷取的战力门槛。

- 单枚徽章总加成不超过 4 点；首批 12 枚任一单属性累计不超过 10 点。
- 加成自动计入四维，不需要穿戴、也不与换装槽冲突。
- 仅已授勋的定义可以结算加成；展示位、隐藏/显示、稀有度不会改变数值。
- 后续新增徽章必须绑定剧情章节或已经出现的可解释行为，且先补充本文件与 `src/content/badges.ts`。

## 数据与迁移

新存档建议使用 `badges[childId] = { badgeId, unlockedAt, source }[]` 保存授勋事实，使用 `featuredBadges[childId]` 保存首页精选。判定器根据剧情、课程三星、游戏记录、图鉴、远征和飞船等级幂等授勋。

本次已移除旧的商店 `b-*` 徽章、自动点亮的六枚临时成就、角色佩戴入口和首页旧展示。持久化版本升级时会删除既有 `b-*` 物品、旧佩戴字段和旧展示偏好；它们不会兑换为新徽章，因为新徽章必须按明确条件重新授勋。

## 接入验收

- 补给站不出现任何徽章商品，也不能购买徽章。
- 新徽章只在条件首次满足时授予一次；刷新、重进页面或重复完成不会重复加属性。
- 选中或取消首页展示徽章只影响展示，四维数值保持不变。
- 剧情按序推进时，基础徽章按上表从易到难出现；成长徽章显示可理解的进度。
