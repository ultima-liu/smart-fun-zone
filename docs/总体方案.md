# 幼儿智力训练小游戏网站 · 总体设计方案

版本：v1.1 ｜ 状态：关键决策已确认

## 1. 项目概述

### 1.1 项目定位
一个面向 3–8 岁儿童（以学龄前为主）的在线智力训练小游戏平台，支持按年龄段切换内容与难度，提供中英双语启蒙。通过"玩中学"的方式激发学习兴趣，覆盖数学、语言、逻辑、自然、生活等多元知识类别。

### 1.2 目标用户
- **直接用户**：3–8 岁儿童（识字量有限，依赖图形与语音），按年龄段分档（3–4 / 4–5 / 5–6 / 6–8）自动适配内容与难度
- **间接用户**：家长与幼儿园教师（负责账号管理、时长与内容控制）

### 1.3 核心价值主张
- **趣味优先**：游戏化机制让学习像玩游戏
- **多元知识**：一站式覆盖多个启蒙领域
- **安全纯净**：无广告、无内购、无社交
- **数据可视**：家长可查看孩子的学习成长轨迹

### 1.4 幼儿产品设计原则（贯穿所有设计决策）
1. **不识字也能玩** —— 所有关键信息"图形 + 语音"双通道呈现
2. **大目标、大按钮** —— 触控友好，防误触，热区 ≥72px
3. **即时正反馈** —— 每次操作都有声音/动画/星星回应
4. **只鼓励不惩罚** —— 错误时温和提示、可重试，无扣分
5. **短时高频** —— 单局 2–5 分钟，护眼提醒
6. **低挫败感** —— 难度自适应，连续失败自动降级

## 2. 内容规划：知识类别 × 游戏形式

### 2.1 年龄段分档与内容适配（已确认：多年龄段切换）
| 年龄段 | 认知特点 | 内容侧重 |
|---|---|---|
| 3–4 岁 | 具象思维、注意力短 | 颜色形状、点数 1–5、动物认知，语音为主 |
| 4–5 岁 | 开始理解数量与规则 | 数字 1–10、比较大小、配对分类、拼音声母 |
| 5–6 岁 | 幼小衔接期 | 20 以内加减、拼音拼读、汉字启蒙、找规律 |
| 6–8 岁 | 小学低年级 | 100 以内计算、英语词汇与简单句型、推理类游戏 |

切换方式：进入游戏大厅前选择/家长预设年龄段；同一游戏按年龄段加载不同关卡包，难度与语速自动调整。

### 2.2 类别矩阵（6 大类别）
| 类别 | 覆盖知识 | 对应游戏形式 |
|---|---|---|
| 数学启蒙 | 数数、数量比较、简单加减、形状 | 数字农场、摘苹果计数、形状配对 |
| 语言认知 | 拼音、汉字、英语单词 | 拼音钓鱼、汉字拼图、单词翻牌 |
| 逻辑思维 | 找规律、分类、排序、迷宫 | 规律接龙、垃圾分类、小迷宫 |
| 专注记忆 | 找不同、记忆翻牌、连连看 | 找不同、记忆翻牌 |
| 自然认知 | 动物、植物、天气、颜色 | 动物叫声匹配、四季穿衣、颜色大冒险 |
| 生活安全 | 安全常识、习惯养成 | 红绿灯过马路、安全小剧场 |

### 2.3 乐园小游戏（精品重启）
- **分类游戏馆（2026-09-29）**：空中乐园固定划分为棋类、牌类、消除、益智、敏捷五类；未开放分类只展示筹备状态，不提供假入口。

- **云台中国象棋（2026-09-29）**：作为棋类中的第二个游戏卡展示，点击后在乐园页内展开 9×10 单人中国象棋；孩子执红、电脑执黑，具备完整基础走法与将帅安全判定、合法落点、将军提示、三档棋力、吃子记录、悔棋和重开。

## 3. 游戏化机制
- **星星收集**：星星专属课程学习（课时按表现获 1–3 颗星）；乐园小游戏不发光星（2026-09-28 起全局星星口径 = 课程星）。当前棋类游戏只记录结果、难度与耗时，不启用乐园币。
- **奖杯/徽章**：里程碑成就（如"完成 50 局""连续 7 天打卡"）
- **学习花园**：完成任务让花园长大，可视化成长进度
- **低龄儿童兴趣增强规划**：围绕「陪伴、情境、创造」逐步建设小卷陪伴成长、卷星生活小剧场和星球小屋；课程采用「每课有课堂操作、每个核心知识组有情境实践、每个单元有可保留成果」的三级结合方式，不为每节课重复制作独立小游戏。首个试点「小卷水果店」已形成可见的单元旅程：前三课完成后开店、后续课程逐项增加任务、单元结束开放综合订单并收藏小屋装饰；当天/第 2 天/第 4 天按到期课程生成变式订单，连续受助后进入小老师模式（详见《低龄儿童兴趣增强规划.md》）。
- **任务系统新设计（2026-09-29，已实施）**：保留课程、章节、每日复习、专项挑战、探索支线、主题活动、家长七类；不恢复剧情主线，不设平台每周或收集养成任务。三科各自推进，每日最多一项到期复习，教材单元自动累计；儿童端任务由角色主动送达，一次只呈现一个具体邀请。首页保留原中央卷星，删除左右固定卡，不建设七类任务中心。各类规则、奖励和实现状态见[《任务系统.md》](任务系统.md)。
- **新手剧情任务已删除（2026-09-29）**：新手剧情链路整体下线——`content/story.ts` 剧情数据、`storyProgress.ts` 顺序完成/领奖、首页剧情条（StoryStrip）、NPC 剧情对话（StoryDialog）、功能门禁（FeatureGate / features.ts）全部移除；学校、乐园、补给站等所有入口直接开放，底部导航与首页卷星建筑不再有锁定/封印态；本地存档的剧情字段由存储迁移 v5 清除，云端 `story_progress` 表与 `/api/sync/story` 端点同步移除；家长中心「重置剧情」按钮删除。NPC（铁砣/阿光/泡泡/铛铛/晶晶）保留纯闲聊，徽章改为成长授勋口径（`storyGate` 字段已移除，授勋判定待徽章页接入时实现）。
- **任务内容可控性要求**：各类任务均须明确来源、触发条件、入口、完成规则、奖励与验收；运行时不自由生成任务或补剧情。旧方向提案及数学首章样板已被[七类任务设计](任务系统.md)替代。
- **首页任务展示（2026-09-29，已实施）**：保留原有顶部控制、原尺寸中央卷星、远征、到达动画、底部导航和学习助手；删除左右固定卡，改用卷星旁的航行通讯按固定优先级一次送达一项，点开进入完整的宇宙航行舱。具体见[《首页场景与任务推送.md》](首页场景与任务推送.md)。
- **英语教材课程**：学校书架开放 PEP 三年级英语上册独立目录和 44 个课时；每课保留原教材情境并做点读、操作、知识延伸，原版音频不足的目标明确待补（细节见《英语三年级上册课程.md》）。
- **间隔复习总入口**：首页以「📚 复习」集中呈现语文、数学、英语当天要回看的课程；课时完成后按当天、第 2 天、第 4 天安排回顾，卡片明确本次复习重点（细节见《学习复习系统.md》）。
- **星航协作队图鉴卡**：档案库新增四人原创协作小队套系，角色以可复用的独立全身立绘接入，详见《星航协作队图鉴卡.md》。
- **布鲁克战队图鉴卡**：以用户提供角色图制作 11 张透明独立立绘卡，按用户确认的官方名称补齐葡萄队长与危客军团角色背景，和原创小队严格隔离，详见《布鲁克战队图鉴卡.md》。
- **难度自适应**：正确率 >80% 升一级，<40% 降一级

## 6. 技术方案

### 6.1 技术选型
| 层 | 选型 | 理由 |
|---|---|---|
| 前端框架 | React 18 + TypeScript + Vite 6 | 生态成熟、组件化复用、按路由拆包 |
| 互动渲染 | HTML/CSS/Canvas | 轻量、加载快，覆盖教材与乐园互动 |

| 状态管理 | Zustand | 轻量 |
| 数据 | localStorage 本地优先 + MySQL 云端同步 | 离线可学习，登录后按账号与孩子隔离同步 |
| 服务端 | Node.js + Fastify + MySQL | 账号、权限、同步、统计、TTS/LLM 代理 |
| 部署 | 静态前端 + 独立 API 服务与 MySQL | 前后端职责清晰，可分别扩容 |

## 11. 主题系统（深色 / 浅色）
> 全站双主题，一键切换；默认深色。

**两套主题**
| 主题 | data-theme | 风格 | 背景 | 卡片 |
|---|---|---|---|---|
| 深色（默认） | `dark` | 午夜玻璃 | 深夜蓝紫 `--sky-mid:#0d0b26` | 深空玻璃卡 + 白字 |
| 浅色 | `light` | 糖果童趣 | 淡粉→淡紫→淡蓝渐变 | 奶油白卡 + 深色文字 |

**实现要点**
- `store` 新增 `theme: Theme('dark'|'light')` + `setTheme`，`persist` 持久化。
- App 根节点据 `theme` 设 `document.documentElement.dataset.theme`。
- `:root` 定义深色主题变量；`:root[data-theme="light"]` 覆盖为浅色变量组：
  `--ink/--ink-soft/--paper/--paper-soft/--line/--glass-*/--sky-top/mid/bottom/--shadow-*/--inset-high`。
- 首页顶栏 `🌙/☀️` 按钮切换；首页卡片/底部导航在浅色下均有对应浅色覆盖。

**脚本入口**
- `types.ts`：`export type Theme = 'dark' | 'light'`
- `store.ts`：`theme` + `setTheme`
- `App.tsx`：`useEffect(() => { document.documentElement.dataset.theme = theme }, [theme])`
- `HomePage.tsx` 顶栏切换按钮

**注意**
- 大量组件用 CSS 变量（`--ink/--paper/--line` 共 198 处），浅色下自动生效；
- **硬编码深色卡片的组件**（pass-card / task-panel / hh-card / resume-bar / bottom-nav 等）需在浅色主题下单独覆盖转浅。
- 全局深色实卡规则必须限定在非浅色主题，并且只使用明确的组件选择器；禁止以 `[class*="-card"]` 等命名子串决定配色。

### 总部页面规划（个人中心「我的」）

> 定位：卷星总部（`/profile`，底部导航「我的」）= 孩子的**个人中心**：已获得物品的管理、成长（头衔/四维）、日常（签到）、钱包、设置，以及家长/管理员登录的快捷入口。
> **职责边界**：总部负责"已获得物品的管理 + 个人成长与账号入口"；**图鉴 / 点亮 / 收集进度**全部归档案库，总部不出现"未拥有、未点亮"占位与进度。

#### 信息架构（一级分区）
1. **我的角色与成长**
   - 角色形象大图（当前装扮/徽章上身预览台）+ 姓名/年级/学段徽章。
   - **头衔徽记**：显示当前头衔（如 `titleTier1~5`，由总星星决定），点开查看档位规则（星星 → 头衔升级进度）。
   - **四维属性卡**：智慧 / 勇气 / 巧思 / 协作（`AttrRadar` 雷达图摘要，复用首页同一套行为推导公式）；点开查看四维解释与提升途径。
2. **收集柜**（核心）：只陈列**已获得**物品，分 4 柜（见下）；不出现未拥有占位、不显示收集进度。
3. **每日签到**：签到卡（今日已签 / 可签到 + 连续 N 天）；每天一次，奖励卷豆/材料（见"签到规则"）。
