# 幼儿智力训练小游戏网站 · 总体设计方案

版本：v1.1 ｜ 状态：关键决策已确认

## 1. 项目概述

### 1.1 项目定位
一个面向 3–8 岁儿童（以学龄前为主）的在线智力训练小游戏平台，支持按年龄段切换内容与难度，提供中英双语启蒙。通过"玩中学"的方式激发学习兴趣，覆盖数学、语言、逻辑、自然、生活等多元知识类别。

### 1.2 目标用户
- **直接用户**：3–8 岁儿童（识字量有限，依赖图形与语音），按年龄段分档（3–4 / 4–5 / 5–6 / 6–8）自动适配内容与难度
- **间接用户**：家长与幼儿园教师（负责账号管理、时长与内容控制）

### 1.3 核心价值主张
- **趣味优先**：游戏化机制让学习像玩游戏
- **多元知识**：一站式覆盖多个启蒙领域
- **安全纯净**：无广告、无内购、无社交
- **数据可视**：家长可查看孩子的学习成长轨迹

### 1.4 幼儿产品设计原则（贯穿所有设计决策）
1. **不识字也能玩** —— 所有关键信息"图形 + 语音"双通道呈现
2. **大目标、大按钮** —— 触控友好，防误触，热区 ≥72px
3. **即时正反馈** —— 每次操作都有声音/动画/星星回应
4. **只鼓励不惩罚** —— 错误时温和提示、可重试，无扣分
5. **短时高频** —— 单局 2–5 分钟，护眼提醒
6. **低挫败感** —— 难度自适应，连续失败自动降级

## 2. 内容规划：知识类别 × 游戏形式

### 2.1 年龄段分档与内容适配（已确认：多年龄段切换）
| 年龄段 | 认知特点 | 内容侧重 |
|---|---|---|
| 3–4 岁 | 具象思维、注意力短 | 颜色形状、点数 1–5、动物认知，语音为主 |
| 4–5 岁 | 开始理解数量与规则 | 数字 1–10、比较大小、配对分类、拼音声母 |
| 5–6 岁 | 幼小衔接期 | 20 以内加减、拼音拼读、汉字启蒙、找规律 |
| 6–8 岁 | 小学低年级 | 100 以内计算、英语词汇与简单句型、推理类游戏 |

切换方式：进入游戏大厅前选择/家长预设年龄段；同一游戏按年龄段加载不同关卡包，难度与语速自动调整。

### 2.2 类别矩阵（6 大类别）
| 类别 | 覆盖知识 | 对应游戏形式 |
|---|---|---|
| 数学启蒙 | 数数、数量比较、简单加减、形状 | 数字农场、摘苹果计数、形状配对 |
| 语言认知 | 拼音、汉字、英语单词 | 拼音钓鱼、汉字拼图、单词翻牌 |
| 逻辑思维 | 找规律、分类、排序、迷宫 | 规律接龙、垃圾分类、小迷宫 |
| 专注记忆 | 找不同、记忆翻牌、连连看 | 找不同、记忆翻牌 |
| 自然认知 | 动物、植物、天气、颜色 | 动物叫声匹配、四季穿衣、颜色大冒险 |
| 生活安全 | 安全常识、习惯养成 | 红绿灯过马路、安全小剧场 |

### 2.4 内容扩展机制
- 每个游戏用"题库/关卡配置"驱动：新增内容不改代码，只加 JSON 关卡包
- 预留扩展类别：音乐节奏、空间想象、情绪认知等

## 3. 游戏化机制
- **星星收集**：每局按表现获 1–3 颗星，累计解锁新游戏（软门槛，不强制）
- **奖杯/徽章**：里程碑成就（如"完成 50 局""连续 7 天打卡"）
- **学习花园**：完成任务让花园长大，可视化成长进度
- **每日任务**：每天 3 个轻量任务，培养习惯但不制造压力
- **难度自适应**：正确率 >80% 升一级，<40% 降一级

- **课时页 `/learn/:id`（LessonPage）**
  - 新增面包屑（`.lesson-breadcrumb`）：学校 / 学科 / 单元 / 课时，学科、单元可点击回跳（保留年级/上下册参数）。
  - 懒加载占位由纯文字改为骨架屏（`.lesson-skeleton`，闪烁渐变条/卡片）。
- **错题本 `/wrongs`（WrongBookPage）**：支持 `?subject=` 学科过滤；学科入口进入时返回按钮回学科页、标题带学科名。
- **全局语音节流（speech.ts）**：同一文本 12 秒内不重复朗读，减少页面自动欢迎语/切换噪音；`speak` 与朗读类手动调用不受影响。
- **浅/深主题**：以上新样式均补充 light 主题覆盖（`.stage-card` / `.continue-card` / `.unit-ring` / `.lesson-breadcrumb` / `.ls-pulse` 等）。

### 4.1 页面地图
```
首页（选择小朋友 + 年龄段）→ 游戏大厅（按类别/推荐）
```

- 全局语音：进入游戏、读题、反馈均自动播报

## 5. UI/UX 设计规范
- **视觉**：明亮卡通、高饱和但柔和的糖果色、大圆角、厚实描边
- **字体**：大号圆体（站酷快乐体/思源圆体类），正文 ≥28px
- **布局**：平板优先（幼儿主要用平板），响应式兼容手机/桌面
- **触控**：图标 ≥72px 热区，防误触
- **无障碍**：色彩对比 WCAG AA、支持静音、支持家长代操作

## 6. 技术方案

### 6.1 技术选型
| 层 | 选型 | 理由 |
|---|---|---|
| 前端框架 | React 18 + TypeScript + Vite | 生态成熟、组件化复用 |
| 游戏渲染 | HTML/CSS/Canvas 为主；重动画用 PixiJS/Phaser 3 | 轻量、加载快，按需引入 |
| 语音 | Web Speech API 中/英双语 TTS（zh-CN / en-US，免费）；备选讯飞/火山 TTS | 无需后端、即时可用 |
| 状态管理 | Zustand | 轻量 |
| 本地数据 | localStorage / IndexedDB | 一期无需登录即可玩 |
| 后端（二期） | Node.js（NestJS）+ PostgreSQL / Supabase | 账号、云同步、统计 |
| 部署 | 一期 Vercel/Netlify 静态托管；二期云服务器 | 快速上线、成本低 |

### 6.2 架构示意（一期）
```
浏览器（React SPA）
  ├─ 游戏引擎层（统一 Game API：init / start / finish / record）
  ├─ 关卡配置（JSON 关卡包：题目、语音文案、图片资源）
  ├─ 进度与成就（本地存储抽象层 Storage API）
  └─ 语音服务（TTS 封装）
```
- **统一 Game API 是关键**：新游戏只需实现接口 + 提供关卡包，即插即用
- 资产管线：图片/音频压缩与预加载管理

### 6.3 核心数据模型
- `ChildProfile`：id、name、avatarId、age、createdAt
- `GameRecord`：id、childId、gameId、level、stars、correctRate、duration、playedAt
- `Achievement`：childId、badgeId、unlockedAt
- `ParentSettings`：childId、dailyLimitMin、enabledGames[]、soundOn
- `LevelPack`（静态配置）：gameId、level、questions[]

### 6.4 语音方案
- 一期用浏览器 TTS（Chrome/Edge），支持中文（zh-CN）与英文（en-US）语音，零成本
- 语音文案统一写在关卡配置中，后续可替换为真人录音
- 提供"语音开关"，家长可关

## 11. 主题系统（深色 / 浅色）
> 全站双主题，一键切换；默认深色。

**两套主题**
| 主题 | data-theme | 风格 | 背景 | 卡片 |
|---|---|---|---|---|
| 深色（默认） | `dark` | 午夜玻璃 | 深夜蓝紫 `--sky-mid:#0d0b26` | 深空玻璃卡 + 白字 |
| 浅色 | `light` | 糖果童趣 | 淡粉→淡紫→淡蓝渐变 | 奶油白卡 + 深色文字 |

**实现要点**
- `store` 新增 `theme: Theme('dark'|'light')` + `setTheme`，`persist` 持久化。
- App 根节点据 `theme` 设 `document.documentElement.dataset.theme`。
- `:root` 定义深色主题变量；`:root[data-theme="light"]` 覆盖为浅色变量组：
  `--ink/--ink-soft/--paper/--paper-soft/--line/--glass-*/--sky-top/mid/bottom/--shadow-*/--inset-high`。
- 首页顶栏 `🌙/☀️` 按钮切换；首页卡片/底部导航在浅色下均有对应浅色覆盖。

**脚本入口**
- `types.ts`：`export type Theme = 'dark' | 'light'`
- `store.ts`：`theme` + `setTheme`
- `App.tsx`：`useEffect(() => { document.documentElement.dataset.theme = theme }, [theme])`
- `HomePage.tsx` 顶栏切换按钮

**注意**
- 大量组件用 CSS 变量（`--ink/--paper/--line` 共 198 处），浅色下自动生效；
- **硬编码深色卡片的组件**（pass-card / task-panel / hh-card / resume-bar / bottom-nav 等）需在浅色主题下单独覆盖转浅。

### 浅色主题覆盖范围（`index.css` 浅色块）
- **通用深色玻璃卡**：`.module` / `.dressing-room` / `.dr-panel` / `.growb-banner` / `.settings-card` / `.entry-card` / `.dr-stage` / `.age-grid` / `.char-grid` / `.store-card` / `.dock-bar` → 白底+深字。
- **页头**：`.page-hero` + `.ph-*` 文字反色。
- **装扮/角色格子**：`.dr-cell` / `.char-cell` 转浅。
- **内容卡**：乐园游戏卡 `.game-card`、学校学科卡 `.subject-card` 转浅白底+彩色主题色块；学科深蓝信息区 `.subject-sheet/list/plan` 转浅。
- **首页**：`.pass-card` / `.task-panel` / `.hh-card` / `.resume-bar` 转浅+文字反色。
- **底部导航** `.bottom-nav`、**档案库**（糖果背景/召唤面板/双层筛选/展示柜/可翻转图鉴卡/抽卡弹窗均已在浅色块覆盖转浅）。

> 原则：页面框架（页头/tab/背景）走 CSS 变量自动变浅；**内层硬编码深色卡片**需逐一在浅色主题块内覆盖。

### 总部页面规划（个人中心「我的」）

> 定位：卷星总部（`/profile`，底部导航「我的」）= 孩子的**个人中心**：已获得物品的管理、成长（头衔/四维）、日常（签到）、钱包、设置，以及家长/管理员登录的快捷入口。
> **职责边界**：总部负责"已获得物品的管理 + 个人成长与账号入口"；**图鉴 / 点亮 / 收集进度**全部归档案库，总部不出现"未拥有、未点亮"占位与进度。

#### 信息架构（一级分区）
1. **我的角色与成长**
   - 角色形象大图（当前装扮/徽章上身预览台）+ 姓名/年级/学段徽章。
   - **头衔徽记**：显示当前头衔（如 `titleTier1~5`，由总星星决定），点开查看档位规则（星星 → 头衔升级进度）。
   - **四维属性卡**：智慧 / 勇气 / 巧思 / 协作（`AttrRadar` 雷达图摘要，复用首页同一套行为推导公式）；点开查看四维解释与提升途径。
2. **收集柜**（核心）：只陈列**已获得**物品，分 4 柜（见下）；不出现未拥有占位、不显示收集进度。
3. **每日签到**：签到卡（今日已签 / 可签到 + 连续 N 天）；每天一次，奖励卷豆/材料（见"签到规则"）。
4. **钱包**：卷豆（`points`）余额与用途入口（去补给站兑换）。
5. **快捷入口区**
   - 家长中心（PIN 保护 → `/parent`）
   - 管理员登录（→ `/admin`）
   - 账号切换 / 孩子登录（→ `/child-login`）
   - 退出登录

  - 已点亮：SSR/SP 带光晕边框；未点亮：降饱和/亮度并加锁。
- **抽卡动画**：`GachaModal` 以全屏「星门召唤场景」呈现——深空背景、暗角、多层旋转 SVG 法阵、中央能量球、通天光柱、天降光束、冲击波环、环绕火花、漂浮粒子。召唤采用「蓄力爆发」节奏：点击后震动/旋转逐级加速（法阵震颤→能量突破临界→到达极限），到达极限后白闪 + 大冲击波爆开，随后卡牌从光柱中浮现，伴随彩色星屑撒开并翻转 reveal；单抽展示一张大卡，十连逐张 reveal 成网格（每张都撒星屑）；新卡标 NEW / 重复卡标 DUPE 并显示兑换星尘数。
- **抽卡音效**：`src/sfx.ts` 纯 Web Audio 合成音效（无外部音频文件），受全局声音开关控制：打开召唤弹窗有柔和上行音；蓄力 4 级逐级升高（200→310→480→720Hz 锯齿+正弦双层）；爆开瞬间播放白噪轰鸣 + 低频 thump + 三连高音铃；每张卡 reveal 按稀有度奏响（R 523Hz → SR 698 → SSR 988 → SP 1319，SSR/SP 追加上行琶音）；按钮点击有清脆反馈音。
- **主题适配**：卡面基底保持深空宝石色以保证收藏卡质感；档案库周围 UI（召唤面板、双层筛选、展示柜）在浅色主题下走糖果色，在深色主题下走深空玻璃风。
