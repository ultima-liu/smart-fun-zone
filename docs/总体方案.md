# 幼儿智力训练小游戏网站 · 总体设计方案

版本：v1.1 ｜ 状态：关键决策已确认

## 1. 项目概述

### 1.1 项目定位
一个面向 3–8 岁儿童（以学龄前为主）的在线智力训练小游戏平台，支持按年龄段切换内容与难度，提供中英双语启蒙。通过"玩中学"的方式激发学习兴趣，覆盖数学、语言、逻辑、自然、生活等多元知识类别。

### 1.2 目标用户
- **直接用户**：3–8 岁儿童（识字量有限，依赖图形与语音），按年龄段分档（3–4 / 4–5 / 5–6 / 6–8）自动适配内容与难度
- **间接用户**：家长与幼儿园教师（负责账号管理、时长与内容控制）

### 1.3 核心价值主张
- **趣味优先**：游戏化机制让学习像玩游戏
- **多元知识**：一站式覆盖多个启蒙领域
- **安全纯净**：无广告、无内购、无社交
- **数据可视**：家长可查看孩子的学习成长轨迹

### 1.4 幼儿产品设计原则（贯穿所有设计决策）
1. **不识字也能玩** —— 所有关键信息"图形 + 语音"双通道呈现
2. **大目标、大按钮** —— 触控友好，防误触，热区 ≥72px
3. **即时正反馈** —— 每次操作都有声音/动画/星星回应
4. **只鼓励不惩罚** —— 错误时温和提示、可重试，无扣分
5. **短时高频** —— 单局 2–5 分钟，护眼提醒
6. **低挫败感** —— 难度自适应，连续失败自动降级

## 2. 内容规划：知识类别 × 游戏形式

### 2.1 年龄段分档与内容适配（已确认：多年龄段切换）
| 年龄段 | 认知特点 | 内容侧重 |
|---|---|---|
| 3–4 岁 | 具象思维、注意力短 | 颜色形状、点数 1–5、动物认知，语音为主 |
| 4–5 岁 | 开始理解数量与规则 | 数字 1–10、比较大小、配对分类、拼音声母 |
| 5–6 岁 | 幼小衔接期 | 20 以内加减、拼音拼读、汉字启蒙、找规律 |
| 6–8 岁 | 小学低年级 | 100 以内计算、英语词汇与简单句型、推理类游戏 |

切换方式：进入游戏大厅前选择/家长预设年龄段；同一游戏按年龄段加载不同关卡包，难度与语速自动调整。

### 2.2 类别矩阵（6 大类别）
| 类别 | 覆盖知识 | 对应游戏形式 |
|---|---|---|
| 数学启蒙 | 数数、数量比较、简单加减、形状 | 数字农场、摘苹果计数、形状配对 |
| 语言认知 | 拼音、汉字、英语单词 | 拼音钓鱼、汉字拼图、单词翻牌 |
| 逻辑思维 | 找规律、分类、排序、迷宫 | 规律接龙、垃圾分类、小迷宫 |
| 专注记忆 | 找不同、记忆翻牌、连连看 | 找不同、记忆翻牌 |
| 自然认知 | 动物、植物、天气、颜色 | 动物叫声匹配、四季穿衣、颜色大冒险 |
| 生活安全 | 安全常识、习惯养成 | 红绿灯过马路、安全小剧场 |

每个游戏说明：玩法、锻炼能力、难度分级（L1–L3）。全部游戏支持中英双语切换（语音 + 文案 + 题目）。
| # | 游戏名 | 类别 | 玩法简述 | 锻炼能力 |
|---|---|---|---|---|
| 1 | 数字农场 | 数学 | 数一数农场动物，点击对应数字 | 点数对应、数感 |
| 2 | 摘苹果 | 数学 | 根据数字摘对应数量苹果到篮子 | 数量对应 |
| 3 | 形状城堡 | 数学 | 将图形拖入对应形状的城堡门 | 形状识别 |
| 4 | 拼音钓鱼 | 语言 | 听读音，钓起对应拼音字母鱼 | 拼音听辨 |
| 5 | 汉字拼图 | 语言 | 将笔画/部件拼成汉字 | 汉字结构 |
| 6 | 英语动物园 | 语言 | 听单词选对应动物 | 英语词汇 |
| 7 | 规律接龙 | 逻辑 | 观察排列规律，选择下一项 | 模式识别 |
| 8 | 垃圾分类 | 逻辑 | 将垃圾拖入正确垃圾桶 | 分类归纳 |
| 9 | 找不同 | 专注 | 两幅图找差异（3–6 处） | 观察力 |
| 10 | 记忆翻牌 | 专注 | 翻开卡片找相同配对 | 记忆力 |

### 2.4 内容扩展机制
- 每个游戏用"题库/关卡配置"驱动：新增内容不改代码，只加 JSON 关卡包
- 预留扩展类别：音乐节奏、空间想象、情绪认知等

## 3. 游戏化机制
- **星星收集**：每局按表现获 1–3 颗星，累计解锁新游戏（软门槛，不强制）
- **奖杯/徽章**：里程碑成就（如"完成 50 局""连续 7 天打卡"）
- **学习花园**：完成任务让花园长大，可视化成长进度
- **每日任务**：每天 3 个轻量任务，培养习惯但不制造压力
- **难度自适应**：正确率 >80% 升一级，<40% 降一级

## 4. 产品功能结构

### 4.1 页面地图
```
首页（选择小朋友 + 年龄段）→ 游戏大厅（按类别/推荐）
    ├─ 游戏页（语音引导、答题、结算动画）
    ├─ 成就页（星星、徽章、学习花园）
    └─ 家长中心（PIN 保护）
```
- 游戏大厅：卡通九宫格，大图标 + 语音播报游戏名
- 结算页：庆祝动画 + 星星 + "再玩一次 / 下一关"

### 4.2 家长中心（PIN 保护）
- 每日/单次时长限制与休息提醒
- 类别与单个游戏开关
- 学习报告：类别雷达图、正确率、使用时长、进步曲线
- 多孩子档案切换

### 4.3 核心交互细节
- 全局语音：进入游戏、读题、反馈均自动播报
- 反馈设计：答对 → 鼓励音 + 星星弹出；答错 → 温和提示 + 重试
- 护眼：每 15 分钟弹休息提醒（家长可配置）

## 5. UI/UX 设计规范
- **视觉**：明亮卡通、高饱和但柔和的糖果色、大圆角、厚实描边
- **字体**：大号圆体（站酷快乐体/思源圆体类），正文 ≥28px
- **布局**：平板优先（幼儿主要用平板），响应式兼容手机/桌面
- **触控**：图标 ≥72px 热区，防误触
- **无障碍**：色彩对比 WCAG AA、支持静音、支持家长代操作

## 6. 技术方案

### 6.1 技术选型
| 层 | 选型 | 理由 |
|---|---|---|
| 前端框架 | React 18 + TypeScript + Vite | 生态成熟、组件化复用 |
| 游戏渲染 | HTML/CSS/Canvas 为主；重动画用 PixiJS/Phaser 3 | 轻量、加载快，按需引入 |
| 语音 | Web Speech API 中/英双语 TTS（zh-CN / en-US，免费）；备选讯飞/火山 TTS | 无需后端、即时可用 |
| 状态管理 | Zustand | 轻量 |
| 本地数据 | localStorage / IndexedDB | 一期无需登录即可玩 |
| 后端（二期） | Node.js（NestJS）+ PostgreSQL / Supabase | 账号、云同步、统计 |
| 部署 | 一期 Vercel/Netlify 静态托管；二期云服务器 | 快速上线、成本低 |

### 6.2 架构示意（一期）
```
浏览器（React SPA）
  ├─ 游戏引擎层（统一 Game API：init / start / finish / record）
  ├─ 关卡配置（JSON 关卡包：题目、语音文案、图片资源）
  ├─ 进度与成就（本地存储抽象层 Storage API）
  └─ 语音服务（TTS 封装）
```
- **统一 Game API 是关键**：新游戏只需实现接口 + 提供关卡包，即插即用
- 资产管线：图片/音频压缩与预加载管理

### 6.3 核心数据模型
- `ChildProfile`：id、name、avatarId、age、createdAt
- `GameRecord`：id、childId、gameId、level、stars、correctRate、duration、playedAt
- `Achievement`：childId、badgeId、unlockedAt
- `ParentSettings`：childId、dailyLimitMin、enabledGames[]、soundOn
- `LevelPack`（静态配置）：gameId、level、questions[]

### 6.4 语音方案
- 一期用浏览器 TTS（Chrome/Edge），支持中文（zh-CN）与英文（en-US）语音，零成本
- 语音文案统一写在关卡配置中，后续可替换为真人录音
- 提供"语音开关"，家长可关

## 7. 开发路线图
| 阶段 | 周期 | 目标 | 交付物 |
|---|---|---|---|
| 0 设计与定稿 | 1–2 周 | 方案评审、UI 设计稿、技术验证（TTS/动画 Demo） | 设计稿、技术 Demo |
| 1 MVP | 4–6 周 | 平台骨架 + 3 个代表游戏（数字农场/找不同/记忆翻牌） | 可试玩网站 |
| 2 内容扩充 | 4–6 周 | 12 个游戏全上线（含双语内容）、关卡系统、成就、学习花园 | 完整一期 |
| 3 家长中心 | 4–6 周 | 账号、云同步、学习报告、时长管控 | 正式版 v1.0 |
| 4 运营迭代 | 持续 | 节日主题、新类别、内容更新、数据优化 | 持续迭代 |

关键里程碑：
- **M1** 可玩 Demo（3 个游戏）→ 家庭内测
- **M2** 完整一期 → 小范围公测（10–20 个家庭）
- **M3** v1.0 正式发布

## 8. 内容安全与合规
- 无广告、无内购、无外链、无社交聊天
- 遵循《儿童个人信息网络保护规定》；若面向海外需另评估 COPPA
- 数据最小化：一期仅本地存储，家长可一键清除
- 内容审核：所有文案/图片符合幼儿认知与价值观

## 9. 验收标准（v1.0）
- 12 个游戏均可完整通关，无崩溃、无卡死
- 无文字依赖：仅凭语音与图形可完成所有游戏
- 触控响应 <100ms，动画 60fps，首屏加载 <3s
- 家长中心可用：时长限制、游戏开关、查看报告
- 通过 10+ 名 3–8 岁儿童无成人协助的实玩测试

## 10. 已确认决策
| 决策点 | 结论 |
|---|---|
| 年龄段 | 3–8 岁，支持按年龄段（3–4 / 4–5 / 5–6 / 6–8）切换内容与难度 |
| 语言 | 中英双语（含英语启蒙与英文语音） |
| 技术栈 | React 18 + TypeScript + Vite |
| 账号 | 一期免登录，本地档案 + PIN 家长中心；二期再评估云同步 |
| 平台 | 网页为主（平板优先），微信小程序列入二期评估 |
| 预算/周期 | 待定，影响路线图压缩或外包
