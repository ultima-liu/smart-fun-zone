# 课程字母读音与连续播报

2026-10-11 用户确定：语文课程中的字母按汉语拼音读，英语课程中的独立字母按英文字母名读。学科决定读法，不随界面语言改变。中英文或汉字/拼音混合说明整句连续播放，避免字母前后因请求、音色和录音切换出现长停顿。该习惯同步记录到 AGENTS.md。

## 当前规则

- 语文：i/u/ü 分别指定 yi1/wu1/yu1，ü 的两点不与声调一起删去。带调音节保留原声调，如 nǚ → nv3，lüè → lve4，bá → ba2；说明中读声母名称时使用拼音呼读音，不读英文字母名。解释中的字母不再删除。
- 英语：独立字母按26个英文字母名读，如 i/eye、u/you、c/see。英语单词、短句及冠词正常朗读，“a cat”中的 a 保留冠词读法，字母例词中的 ice/fish 不会受到 i/f 单字母规则影响。实际孤立音位和歌曲继续用教材原声，不将英文字母名代替词里的音位。
- 自动朗读、点读、公共重播、题目/选项、教学助手回答使用同一学科规则。显式学科参数可用于课程之外的复习入口。
- 有汉字的混合材料整句一次合成、一次播放，用同一个中文主持人音色自然读完字母和外语材料；纯英语示范仍使用英文音色。选择哪个音色与字母读法分开，混读不会把英语字母转成拼音。
- 纯拼音示范优先匹配已有真人录音。没有匹配录音的音节使用明确拼音发音规则合成；不按英文猜读，不把不同声调全转换成一声。合成失败不记作听完，听辨与真实发音检查的通过规则保持原样。
- 认字抽查仍只读题目，点击后播放目标词语和要找的字，汉字选项不播报；拼音听辨仍先听目标录音、再读选项。这种教学上的先后步骤与句子内部的连续朗读区分。
- 声音开关、实际播放结束、缓存重播、离开取消和原有自动推进规则保留。

## 实现

`courseSpeech.ts` 集中编译学科读法，保留拼音声调与ü。发音规则按每次文本使用独立标记绑定，避免把 i 的规则匹配到 ice 或其它词内部。标记只供合成，不改变页面题目和教材文字。

`speech.ts` 中的普通朗读、逐句朗读和混合朗读在课程路由内统一使用该编译器；中文与英文课程播报器也显式指定学科。`ChinesePinyinStudyStage` 移除原先删除拼音后追加“请家人示范”的点读做法。

`volcTts.ts` 将发音词典及语音指令送入同一合成请求，缓存键同时包含读法和学科指令。服务端原有完整请求缓存自动区分新旧读法；语文 i 与英语 i 不复用对方音频。

使用火山官方支持的 `additions.pronunciation_dict.tone` 与 `context_texts`，发音修正格式为“原词/(拼音音节)”，英文字母使用明确字母名称转写。参数依据见[火山单向流式合成HTTP文档](https://docs.volcengine.com/docs/DoubaoVoice/unidirectional-streaming-text-to-speech-http?lang=zh)。本次未引入新的语音服务。

42项相关单元测试通过，检查ü/声调、学科差异、冠词/单词不误替换、单次请求、纯拼音录音、失败/取消和缓存隔离。2项定向E2E通过，验证截图对应的i/u/ü规则页仅合成一次、缓存整句重播、切换任务，以及英语字母表和英中词义点读的连续请求。
