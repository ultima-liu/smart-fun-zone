# 课程邮件与周课程表

状态：已实施｜更新：2026-09-30。统一规则见[任务系统](../任务系统.md)。

## 1. 周课程表配置

**默认模板（2026-10-02 已实施）**：未发布任何课程表时，所有年级从周一语文、周三数学、周五英语的新课模板开始，周二、周四、周六各预填两科旧课复习，周日休息。上一版完整且未改动的预置模板自动升级；自定义课表保留。管理员可独立修改七天的新课和复习选项，详细规则见[每周学习节奏](每周学习节奏.md)。

管理员在 `/admin` 的“课程表”中按年级配置周一至周日，每天分别选择新课学科与复习学科。只决定“星期几安排哪些学科”，不指定具体课时。课程表里的年级用于决定哪些孩子收到安排，不限制学科教材自身标注的年级；例如一年级孩子也可以收到当前已开放英语教材的课程邮件。新课和复习都未选择时即为休息日；周末也可按需安排。

每个年级与星期只有一条配置，稳定 ID 为 `年级:weekday:星期数字`。课程邮件奖励按课程类别统一配置，生成邮件时写入邮件快照；之后修改奖励只影响新邮件。

## 2. 当天怎样选课

到达上课日后，系统为课程表中的每个学科最多生成一封邮件。具体课时按教材目录顺序选择，并同时满足：

- 孩子的档案年级匹配这张课程表，且课程属于当天学科当前已开放的教材；
- 没有有效课程完成记录；
- 从未被之前的课程邮件分配。

因此，同一课不会重复发信。孩子从学校提前学完后，系统会跳过该课，选择后面的第一节未完成课程；已发过信但仍未解决的课保留在原邮件中，后续上课日会选择下一节从未发信的课。该学科没有剩余课程时，当天不为它生成空邮件。

系统只在进入首页、课程表刷新或跨日刷新时补齐当天邮件，不会因为刚完成一课就立刻追加下一封。生成后的邮件固定保存来信日期、学科、课时和奖励，不受以后修改课程表、教材进度或奖励配置影响。

## 3. 一节课一封邮件

每封邮件显示：

- 实际生成的来信日期；
- 学科和完整课名；
- 当前状态；
- 完成后可领取的卷星币数量；
- “开始上课”“继续上课”或“领取奖励”的唯一主操作。

同一天配置多个学科时，每个学科生成一封独立邮件，全部列在“当前来信”中，不合并为一封总任务，也不自动依次打开。

## 4. 状态与分类

| 状态 | 判定 | 所在分类 |
| --- | --- | --- |
| 未开始 | 来信日期是今天，尚未从邮件进入该课，也未完成 | 当前来信 |
| 未完成 | 已从邮件进入但没有有效课程结果；或来信日期已经过去仍未解决 | 当天仍在当前来信，跨日后进入未完成 |
| 已完成 | 对应课程已经产生有效完成结果 | 未领奖时按日期留在当前来信或未完成；领奖后进入已完成 |

三个信箱分类为：

- **当前来信**：来信日期为今天、尚未领取奖励的全部课程邮件。
- **未完成**：来信日期早于今天、仍未完成或仍未领奖的课程邮件。
- **已完成**：已经完成课程并领取奖励的课程邮件。

课程完成只写入完成时间和结果，不立即发课程邮件奖励。孩子点击“领取”后，系统用 `course-mail-reward:<邮件 ID>` 幂等入账并归档。已完成但跨日仍未领取的邮件进入“未完成”，保留“已完成 · 待领奖”状态和领取入口。

## 5. 完成凭据

数学、语文、英语仍由各自课程页面写入有效完成结果。打开页面、停留时间或手动勾选不算完成。课程实际完成时间独立保存在孩子任务状态中，并随云端学习状态同步。

自由学习不会被抹掉。尚未生成邮件的课程如果已经完成，之后选课时会被跳过；已经生成邮件后再完成该课，原邮件会显示“已完成 · 待领奖”。重学课程不会重复领取同一封邮件奖励。

## 6. 保存、同步与迁移

周课程表保存为全局配置，由服务端 `store_config.course_schedule` 下发到所有客户端。客户端在启动、重新获得焦点、回到前台以及每 5 分钟拉取一次配置；跨过本地自然日后，首页在 1 分钟内刷新来信分类。

课程邮件的内容快照、开始、完成和领奖记录保存在每个孩子的 `taskStates.courseMails` 中，跨设备合并时保留完整快照。删除或调整周课程表只影响之后尚未生成的邮件，已有邮件及完成事实不删除。

旧版按日期指定课时的课程表升级后，按原日期对应的星期和学科合并为周课程表；已经生成的旧邮件补齐原日期、课时和奖励快照，继续按原状态展示。

Web 与 Pad 后台都必须可编辑七天的新课与复习选项；儿童端信箱在两种尺寸下都能显示多封邮件、日期、状态和领奖按钮。

## 7. 验收

- 同一天选择数学、语文和英语后，各生成一封当前来信，课名取三科各自第一节未完成且从未发信的课程。
- 已提前完成第一课时，系统跳过它并选择下一课；已发过信的课不会再次生成邮件。
- 后续上课日只在当天刷新时选择下一节，不因上一课刚完成而立即追加新信。
- 未勾选新课的日期、学科课程全部分配完毕时不生成课程邮件；勾选周末新课时照常发信。
- 打开一封后状态由未开始变为未完成，其他邮件不受影响。
- 完成后不自动增加卷星币；领取一次后积分增加一次并进入已完成，重复点击或跨端重放不重复入账。
- 未完成邮件跨日进入未完成；已完成但未领奖的旧邮件也能继续领奖。
