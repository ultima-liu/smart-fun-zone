# 每日复习任务

状态：已实施｜更新：2026-10-02。每天最多指派一项、最多发一次 8 卷星币；新课与复习的可编辑星期安排见[每周学习节奏](每周学习节奏.md)。

新课首次完成的本地自然日，该课出现一次独立 D0 短巩固。后续复习只在管理员为该年级、该星期勾选了对应学科时出现；不再自动按 D2/D4 到期。每个勾选的复习学科当天最多取一节此前已学的旧课，先选上次复习最早的课，同日做完不再追加第二节。没有旧课时不生成空复习卡。

复习入口列出当天所有短巩固与课程表复习。平台任务从中优先选择已学旧课，再选择当天短巩固，并保存当天目标；刷新不会换课。完成指定目标才可领取当日复习奖励。完成其他到期回顾只更新其学习记录，不发第二份奖励。新课通过本身不算短巩固；三科目前均使用独立小检验，英语也可在课内完成当天词句巩固。

旧课程表没有复习字段时，该日复习为空；旧 D2/D4 完成记录保留，不据此重新发奖。重学不重置首次学习日与已完成记录。管理员修改后，仍符合配置的当日指派保持稳定；未完成且已不符合配置的指派会重新选择或撤销，已领奖记录不重发。
