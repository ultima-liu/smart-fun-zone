# 每日复习任务

状态：设计建议。平台唯一固定每日任务，不附加签到、购物、抽卡或游戏要求。

## 生成规则

每天最多一项，目标是一节课的一次到期回顾。当天首次打开首页、复习页或开始复习前，读取已保存实例；没有实例才计算。

1. 只取有学习记录、已到期、可访问且具备有效复习完成事件的课程。
2. 同课多节点合并成一项：目标为最晚已到期节点，排序时间取最早未完成节点的到期时间。
3. 最早到期优先；同一时间按语文、数学、英语，再按教材课时顺序。
4. 保存目标课程、节点、任务日与奖励，刷新不更换。
5. 无候选显示“今天没有到期复习”，不拿新课凑数；当天后来出现候选可生成唯一一项。

沿用当天、第 2 天、第 4 天计划；刚学完课程的结算不能顺便算复习，需要另一次明确进入复习的活动。

## 完成依据

卡片显示“复习《课名》”及具体回顾内容。课内复习必须回传同课同节点的完成结果，再消除该节点与更早到期节点；不提前消除未来节点。

- 不以点击“已完成回顾”直接发任务奖励。
- 旧手动回顾可保留为自报，自动事件适配前不进入发奖候选池；上线清单必须列出各科已适配范围。
- 可用现有完整课时流程提供复习模式，但旧三星记录不代表本次已复习，也不因复习重置最初学习日期。
- 生活情境只有在逐课映射、能力覆盖和完成事件均匹配时才可替代；否则回到课内。
- 允许提示与纠正，完成流程即可，不要求首答全对。

## 奖励与日期

每天 8 豆；跨午夜完成归开始时绑定的旧任务日，不同时占新日名额。昨天未开始的任务不堆成今天的第二项，但课程仍在复习计划中参与排序。

自由复习别的课不会暗中改变任务。卡片明确指定课名；目标内容失效时显示原因，点“重新安排”按相同排序取其他有效候选，仍保留同一奖励名额。

## 呈现与验收

复习由小卷按主动送达顺序直接邀请，占用当次唯一主邀请，不再常驻一张复习卡。完成后先给成果反馈，不推荐第二项每日任务；没有到期复习时跳过复习邀请，不显示空卡。完整计划从学校复习入口进入 `/review`。

相同输入应选择同课；多科只生成一项；新课结算不误算复习；完成非目标课不误发；跨午夜、多设备只奖励一次。
