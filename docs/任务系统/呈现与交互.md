# 任务系统呈现与交互：主动送达

版本：v4 已实施｜2026-09-29

已实施要求：任务主动送给孩子；取消让孩子逐项寻找的七类任务中心；首页保留原有卷星观测台，只移除左右固定卡并重做任务展示。以下规则与当前实现保持一致。

## 1. 孩子看到的流程

回到首页 → 小卷或来访角色递来一个具体邀请 → 一键进入实际内容 → 做完自动记录 → 回首页看到成果 → 选择继续或休息。

七类用于配置、判定、奖励与家长查看，不作为儿童导航。儿童端不建设七类侧栏、七类网格或“全部待办”任务大厅，不出现未完成总数、欠账红点和全清奖励。

首页以原有中央卷星为主视觉，任务通过卷星旁的航行通讯主动送达；平板上通讯排在卷星下方。点开通讯进入完整的宇宙航行舱，查看当前航线、已开始的事项和成果。独立说明见[首页任务展示改造](../首页场景与任务推送.md)。本设计替代旧右侧每日/每周任务列表，不继续沿用“设为首页关注”的管理动作。

## 2. 七类任务怎样主动到达

| 内部类别 | 触发时机 | 孩子看到的内容 | 点击后 |
| --- | --- | --- | --- |
| 课程 | 首次选好学科后；没有更优先事项的回首页时 | 小卷：“今天去学《比大小》，试试哪边更多。” | 直接进对应课时 |
| 章节 | 一节课结算后更新；只差最后一课时随课程邀请提示；全部完成时庆祝 | “这个单元已经完成 4/8 课”；“这一个单元学完啦” | 可查看本单元学习足迹，无额外执行动作 |
| 每日复习 | 当天有绑定的到期课且未被孩子暂缓时 | 小卷：“上次学过的 1～5，今天再用一用吧。” | 直接进指定课的复习模式 |
| 专项挑战 | 满足明确先修，并刚完成该知识范围的学习后 | 阿光来访：“想试试这六道加减题吗？” | 确认知道“独立首答 5/6”后进入固定题包 |
| 探索支线 | 刚学完对应课程后的合适停顿点，或孩子以后主动要求换一个 | 兔兔来访：“帮三位客人装好水果吧。” | 展示三步简图后进入委托；不打开分类页 |
| 主题活动 | 已发布、在开放期、适用条件满足；孩子空闲时 | 场景里来访角色递来活动邀请，说明名字与日期 | 参与后进入第一步，未参与不生成一串待办 |
| 家长任务 | 家长设置的提醒时机到达，孩子回首页且当前无活动运行时 | “家人留了一件事：整理书包。” | 看原要求，可稍后或完成后提交；不跳入家长后台 |

角色只负责传达已有配置；不引入新剧情链、对话前置、功能门禁或随机剧情内容。所有人物话术必须与指定任务 ID 绑定。

## 3. 推送调度：规则固定、每次只说一件事

推送指应用内的主动呈现，不启用系统通知、短信或站外提醒。

### 首页的主邀请

仅在首次进入首页、从活动返回、孩子点“换一个”、前项反馈结束后重新决策；不会在孩子正在看一句话时自动换掉。

过滤不可访问、条件不满足、已完成、草稿、当天已暂缓的候选后，按以下顺序选一项：

1. 家长时长限制或休息状态：不推学习，给休息提示。
2. 本次返回刚完成的成果：先反馈，不用新任务遮住成果。
3. 上次已经开始但暂停的活动：询问是否继续，不强制恢复。
4. 已到明确提醒时机的家庭任务：先展示最早到期且未提醒的一项；这是告知，不强制先做。
5. 当天唯一的到期复习任务。
6. 当前学科的下一节课程。

同级用约定提醒时间/进入候选时间升序，再用稳定 ID 排序；课程使用教材顺序。没有学科历史时只问一次“今天想学哪门课”，提供已有教材的学科图标与语音；不能因英语上线就默认给低龄孩子安排三年级内容。

孩子在课堂中使用的学科更新其学习偏好；要换学科可点学校，不要求进入任务分类。

### 角色来访

挑战、探索、活动以及非定时的新家庭约定进入来访队列，在完成一次正式学习/复习返回后，或首页没有主邀请时呈现。一天最多主动递出两项新的来访邀请，七类共享这个额度，不按每类各推两次。

候选顺序：此前已经送到但未展开的来访 → 当前课程匹配的探索 → 刚解锁的专项挑战 → 未提醒的新家庭约定 → 已发布主题活动。同级按进入队列时间、固定 ID 排序。等待两个访问会话仍未送达的候选优先于新入队候选，避免总被新支线压住。

同一时刻前景只有一位讲话角色；其他候选保存在系统中，不在场景里排出七个叹号。主邀请尚未处理时，最多一个安静的来访角色有“想请你帮个忙”的气泡，不自动抢话。下一次自然停顿可直接展开此来访，无须孩子去找任务。

额度限制只控制主动打扰；孩子主动点“换一个”或去场景功能继续玩不受限制。所有先修、家庭限时和活动有效期仍需满足。

## 4. 拒绝、换一个与以后继续

首页航行通讯保留一个明显的出发按钮；“换一个航线”“自己逛逛”和详细规则、奖励放在点开后的当前航线，不在主画面铺成长表。

- 点“换一个”：当前建议当日暂缓，给最多两个具体替代，例如“学《天地人》”“帮兔兔分水果”；没有合适候选就自由活动。不能展示七个分类让孩子重新找。
- 暂缓每日复习只暂停催促，不改当天任务内容与奖励名额；之后孩子到学校的复习入口仍能主动完成。
- 拒绝后同一日不重复主动催促。家庭一次性事项和已接受支线保留；没有惩罚、扣分或角色失落文案。
- 点“自己逛逛”：本访问会话停止主动展开邀请，保留学校、乐园、总部等功能直达。下一次访问会话才恢复建议；会话以连续离开应用超过 30 分钟界定，刷新不算新会话。
- 已开始但暂停的事情进入“星际书包”；当天到期的家人任务也在这里可见。内容在航行舱内完整滚动，条目可以直接继续；没有七类筛选、未接任务池或完成率。
- “星光收获”只回看已完成成果与奖励；不会演变为待办中心。章节明细在学校教材目录和成果详情中查看。

## 5. 开始与完成

邀请必须直接落到实际课程/复习/题包/场景。不先打开通用任务详情页，不要求再次接取或领奖。专项挑战的阈值、家庭确认方式与活动日期在出发前明确说清。

完成事件由对应学习模块自动提供；没有儿童端通用“我完成了”按钮。线下家庭约定例外，按既定自报/家长确认规则处理。

课程与章节奖励在同一结果中逐项列示；回到广场只用一条成果回应，例如“小卷：这一课完成了，这个单元又前进了一步”。金额和规则可点开核对，不以连续领奖弹窗打断。

一次成果展示后提供“今天先到这里”和一个可选“还想做一点”；不会自动开下一课，也不连续弹出后面的邀请。章节达成庆祝后无需执行另一项“章节任务”。

离线保存成果与待同步奖励，状态说明不覆盖主体场景；重新联网的同步消息不抢孩子正在做的题。

## 6. 语音与输入

短句同时显示文字、角色和目的地高亮。首次用户交互后才尝试语音，每次送达只播一次；静音或语音失败仍可通过文字与画面完成选择。可主动点重听，正在教学时不播首页来访。

主按钮热区至少 72px；低龄用户不依赖滑动发现入口，不要求读懂“课程/章节/支线”的系统分类。家长端仍可按七类查看来源、完成条件和奖励，复杂管理留给成人。

## 7. 推送验收用例

- 冷启动有暂停课程及到期复习：先询问继续课程；暂缓后才给复习。
- 没有暂停事项、有定时家庭提醒及复习：家庭告知先送达；稍后处理后给复习，不锁住它。
- 当前课程完成：先显示成果；当前课有匹配探索时，主动继续入口才可展开对应委托，不自动开局。
- 章节完成：自动发奖与庆祝，不要求去任务列表领取。
- 同时解锁多个候选：仅一位角色发言，按固定队列等待，最多两次新来访主动邀请/日。
- 点“自己逛逛”后跨页面与刷新：同一会话不再弹邀请，全部功能入口仍可用。
- 作答、限时休息、家长待确认时：没有任务抢屏或重复催促。
- 新活动尚未发布：不会因为界面需要热闹而生成占位邀请。
