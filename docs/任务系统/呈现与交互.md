# 任务系统呈现与交互：主动送达

版本：v6 周课程表来信版已实施｜2026-09-30

已实施要求：任务主动送给孩子；取消让孩子逐项寻找的七类任务中心；首页保留原有卷星观测台，只移除左右固定卡并重做任务展示。以下规则与当前实现保持一致。

## 1. 孩子看到的流程

回到首页 → 小卷或来访角色递来一个具体邀请 → 一键进入实际内容 → 做完自动记录 → 回首页看到成果 → 选择继续或休息。

七类用于配置、判定、奖励与家长查看，不作为儿童导航。儿童端不建设七类侧栏、七类网格或“全部待办”任务大厅，不出现未完成总数、欠账红点和全清奖励。

首页以原有中央卷星为主视觉。课程、复习和家长约定化作信封送入星环收件站；挑战、探索和活动只化作空间中的一个漂流讯息，不进入信箱。孩子打开对应物件后才阅读任务并出发，未完事项与成果收进信件界面的抽屉。独立说明见[首页任务展示改造](../首页场景与任务推送.md)与[首页星际来信任务呈现方案](../首页星际来信任务呈现方案.md)。

## 2. 七类任务怎样主动到达

| 内部类别 | 触发时机 | 孩子看到的内容 | 点击后 |
| --- | --- | --- | --- |
| 课程 | 到达管理端周课程表中的学科上课日；每学科最多一封 | 来信日期、系统选出的完整课名、状态和完成奖励 | 直接进对应课时；完成后回信箱领奖 |
| 章节 | 一节课结算后更新；只差最后一课时随课程邀请提示；全部完成时庆祝 | “这个单元已经完成 4/8 课”；“这一个单元学完啦” | 可查看本单元学习足迹，无额外执行动作 |
| 每日复习 | 当天有绑定的到期课且尚未完成时 | 小卷：“上次学过的 1～5，今天再用一用吧。” | 直接进指定课的复习模式 |
| 专项挑战 | 满足明确先修，并刚完成该知识范围的学习后 | 阿光来访：“想试试这六道加减题吗？” | 确认知道“独立首答 5/6”后进入固定题包 |
| 探索支线 | 刚学完对应课程后的合适停顿点，或首页没有更高优先级邀请 | 兔兔来访：“帮三位客人装好水果吧。” | 展示三步简图后进入委托；不打开分类页 |
| 主题活动 | 已发布、在开放期、适用条件满足；孩子空闲时 | 场景里来访角色递来活动邀请，说明名字与日期 | 参与后进入第一步，未参与不生成一串待办 |
| 家长任务 | 家长设置的提醒时机到达，孩子回首页且当前无活动运行时 | “家人留了一件事：整理书包。” | 在信箱查看原要求，完成后提交；关闭信箱后仍保留在列表 |

角色只负责传达已有配置；不引入新剧情链、对话前置、功能门禁或随机剧情内容。所有人物话术必须与指定任务 ID 绑定。

## 3. 推送调度：规则固定、每次只说一件事

推送指应用内的主动呈现，不启用系统通知、短信或站外提醒。

### 首页的主邀请

仅在首次进入首页、从活动返回、前项反馈结束后重新决策；不会在孩子正在看一句话时自动换掉。

过滤不可访问、条件不满足、已完成、草稿和当天已放走的来访候选后，按以下顺序选一项：

1. 家长时长限制或休息状态：不推学习，给休息提示。
2. 本次返回刚完成的成果：先反馈，不用新任务遮住成果。
3. 当天课程表邮件：按当天配置学科生成，全部进入当前来信，不合并，不自动串行打开。
4. 上次已经开始但暂停的其他活动：询问是否继续，不强制恢复。
5. 已到明确提醒时机的家庭任务：这是告知，不强制先做。
6. 当天唯一的到期复习任务。

系统先按孩子年级和当天星期读取课程表，再为每个配置学科选择教材目录中第一节未完成且从未发信的课程。没有当天学科、周末或没有剩余课程时不生成邮件。孩子仍可从学校自由学习；提前学完的课程会被跳过，已经生成的邮件则保留原课时和奖励快照。

### 角色来访

挑战、探索、活动以及非定时的新家庭约定进入来访队列，在完成一次正式学习/复习返回后，或首页没有主邀请时呈现。一天最多主动递出两项新的来访邀请，七类共享这个额度，不按每类各推两次。

候选顺序：此前已经送到但未展开的来访 → 当前课程匹配的探索 → 刚解锁的专项挑战 → 未提醒的新家庭约定 → 已发布主题活动。同级按进入队列时间、固定 ID 排序。等待两个访问会话仍未送达的候选优先于新入队候选，避免总被新支线压住。

同一时刻前景只有一位讲话角色；其他候选保存在系统中，不在场景里排出七个叹号。主邀请尚未处理时，最多一个安静的来访角色有“想请你帮个忙”的气泡，不自动抢话。下一次自然停顿可直接展开此来访，无须孩子去找任务。

额度限制只控制主动打扰；孩子主动去场景功能继续玩不受限制。所有先修、家庭限时和活动有效期仍需满足。

## 4. 关闭、放走与继续

首页只展示信件物件及来源；打开收件站后，左侧列出当前分类的全部任务条目，右侧显示选中任务的详情、规则、奖励和出发按钮，不在主画面铺成长表。

- 收件站不提供“稍后处理”。切换左侧条目、关闭详情或合上信箱都不改变任务状态，任务仍留在原分类。
- 漂流讯息可选择“放走这条讯息”；放走后同一日不重复主动催促，没有惩罚、扣分或角色失落文案。
- 点“自己探索”：本访问会话停止主动展开邀请，保留学校、乐园、总部等功能直达。下一次访问会话才恢复建议；会话以连续离开应用超过 30 分钟界定，刷新不算新会话。
- 当天课程邮件无论未开始、未完成还是已完成待领奖，都留在“当前来信”。跨日仍未解决的邮件进入“未完成”。
- “已完成”只收纳已经完成课程并领取奖励的邮件；课程完成和奖励领取是两个独立事实。

## 5. 开始与完成

邀请必须直接落到实际课程/复习/题包/场景。课程邮件无需再次接取，但完成后需要在信箱主动领取邮件生成时保存的奖励。专项挑战的阈值、家庭确认方式与活动日期在出发前明确说清。

完成事件由对应学习模块自动提供；没有儿童端通用“我完成了”按钮。线下家庭约定例外，按既定自报/家长确认规则处理。

课程完成时不自动增加课程邮件奖励。回到信箱后该邮件显示“已完成 · 待领奖”；领取成功才入账并归档。完成一课不会自动开下一课，也不会生成下一封课程邮件。

离线保存成果与待同步奖励，状态说明不覆盖主体场景；重新联网的同步消息不抢孩子正在做的题。

## 6. 语音与输入

短句同时显示文字、角色和目的地高亮。首次用户交互后才尝试语音，每次送达只播一次；静音或语音失败仍可通过文字与画面完成选择。可主动点重听，正在教学时不播首页来访。

主按钮热区至少 72px；低龄用户不依赖滑动发现入口，不要求读懂“课程/章节/支线”的系统分类。家长端仍可按七类查看来源、完成条件和奖励，复杂管理留给成人。

## 7. 推送验收用例

- 冷启动有中途退出的课程及到期复习：两者都显示在对应分类的左侧任务列表，点击即可切换右侧详情。
- 没有暂停事项、有定时家庭提醒及复习：二者都进入当前来信左侧列表，默认选中优先级更高的家庭告知，点击另一条即可查看复习。
- 当前课程完成：先显示成果；当前课有匹配探索时，主动继续入口才可展开对应委托，不自动开局。
- 章节完成：自动发奖与庆祝，不要求去任务列表领取。
- 同时解锁多个候选：仅一位角色发言，按固定队列等待，最多两次新来访主动邀请/日。
- 点“自己探索”后跨页面与刷新：同一会话不再弹邀请，全部功能入口仍可用。
- 作答、限时休息、家长待确认时：没有任务抢屏或重复催促。
- 新活动尚未发布：不会因为界面需要热闹而生成占位邀请。
