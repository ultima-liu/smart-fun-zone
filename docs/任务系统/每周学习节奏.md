# 可编辑的每周新课与复习安排

状态：已实施｜更新：2026-10-02。课程邮件规则见[课程任务](课程任务.md)，奖励规则见[每日复习任务](每日复习任务.md)。

## 每天可选什么

管理员按年级编辑周一至周日。每天有两组独立选项：**新课**和**复习**，每组都可分别勾选语文、数学、英语，也可全部留空。某科新课被勾选时，当天按教材顺序发下一节未完成、从未发信的课程；某科复习被勾选时，当天从该科已学的旧课中选一节回顾。周末同样可安排新课或复习。空日期就是休息日。

新课完成当天出现该课的 **D0 短巩固**，需要另做小检验，不由新课通过自动完成。其后的复习只看课程表里的复习勾选，**不再按固定 D2/D4 自动生成**。某科一日最多选一节旧课；优先选择上次复习最早的课程，同一天完成后不再换出第二节。下一个勾选该科复习的日期仍可回顾已学课程。没有已学旧课时不生成空卡。

多科复习和当天短巩固可同时出现在复习入口。平台每日复习任务只指派其中一项、每天最多发一次 8 卷星币；完成其他回顾仍记录进度。修改课程表后，尚未完成且不再符合勾选的当日指派会重新选择或撤销；已发课程邮件与已完成奖励不受影响。

## 可修改的起始模板

未发布过课程表时，以以下模板开始。新课与旧课复习分开：周一、周三、周五是新课日（课后仍有独立短巩固），周二、周四、周六各预留两科复习，周日休息。尚未学过的科目不会生成空复习卡，所以第一周实际安排可能更少。它只是预填配置，管理员可以移动或增删任一选项。

| 星期 | 新课 | 复习 |
| --- | --- | --- |
| 周一 | 语文 | 无 |
| 周二 | 无 | 语文、英语 |
| 周三 | 数学 | 无 |
| 周四 | 无 | 语文、数学 |
| 周五 | 英语 | 无 |
| 周六 | 无 | 数学、英语 |
| 周日 | 无 | 无 |

管理员在 Web 或 Pad 的 `/admin` →「课程表」按年级查看七天的两组选项；点击「填入三课复习模板」只替换当前年级的草稿，点击「保存并发布课程表」后才同步到孩子端。上一版**完整且未改动的预置模板**自动换成这份均衡模板；自行调整过的课表保留。旧课表没有 `reviews` 字段时，该日期的复习选项默认为空。保存空白日会保留该配置，不会重新启用默认课表。

孩子自由学习或晚完成课程时，D0 以真实首次完成的本地自然日计算；后续仍按管理员选择的星期回顾。重学同一课不重置首次学习日或既有复习记录。
