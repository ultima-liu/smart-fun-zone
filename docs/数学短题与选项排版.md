# 数学短题与选项排版

更新日期：2026-10-08。适用范围：一年级数学上册 47 课，以及共用检测组件的复习、错题与挑战入口。

## 确定的排版

课文题卡必须铺满可用内容区的宽度与高度，保持一屏完整展示。四行内部内容居中，答案按钮仍按文字与操作需要决定尺寸，不将单个答案拉满整行。

- 检测、闯关及共用复习题按四行居中排列，顺序固定为：题目＋朗读图标、演示、选项／输入、提示与反馈；不再把演示与答案分到左右两栏。
- 第一行：题目居中，旁边是 48px 的蓝色圆形扬声器按钮，保留“听题”的无障碍名称。
- 第二行：完整图示与答题示范使用蓝色底板和实线边框，课文内演示区使用完整内容宽度，并分配剩余高度，图示在其中居中。没有图示且未打开示范的题目不生成空演示框。
- 第三行：浅色主题使用白色答案卡，深色主题沿用深色卡片；答案卡独立居中，保留紧凑、可点击的尺寸；数字填写的输入框与检查按钮相邻；算式输入区与两行键盘在这一行内排列。
- 第四行：提示和反馈居中排列，带“💡 提示”标识；不显示浅黄色区域、区域边框或黄色提示按钮，使用普通辅助按钮。答对后显示绿色反馈和推进按钮。提示文字展开时仍保留题目、演示和答案。
- 课文内整张题卡占满当前内容区，删除 940px／640px 最大宽度限制。纯文字题仍铺满外层内容页，内部题目、答案与提示居中，行间距按内容区高度的 10% 分配，限制在 28～56px，避免挤成一团；有演示时按题目、可伸展演示、答案、提示分配高度。课文外复习题使用其容器的完整宽度，高度遵循外部容器。
- 无演示的题目适当拉开选项横向间距（14～24px），辅助按钮间距 12px；选项本身尺寸保持紧凑，提示行仍无底色与区域边框。有演示时继续将剩余高度留给完整演示区。
- 单个符号、短数字：76px 宽、至少 60px 高的选项并排，字号 26px；不用整列宽度承载一个符号。
- 10 字以内短词、短算式：按钮宽度随文字内容变化，至少 52px 高；空间不足时自然换行。密集教材练习卡及立体拼搭判断使用至少 44px 高的短词按钮，符号选项使用 64px 宽、至少 52px 高的小卡，避免选择区挤占题目和材料。
- 长句选项：按两列可读宽度排列并允许换行，极窄窗口改成一列；不会强行压成小按钮。
- 数字填写：“写出你的答案”位于输入框左侧，与输入框、检查按钮同排并垂直居中，输入区整体居中；窄窗口仅将检查按钮换至下一行，标签仍在输入框左侧；算式填写保留两行数字、运算符键盘，不缩小为单字选择。
- 答题示范归入第二行，错误、正确及提示反馈归入第四行；各行的阅读顺序在 Web 与 Pad 保持一致。

先猜、教材任务、理由关系核对、小检测、智能闯关以及复习使用同一个选项组件。尺寸分类根据当前实际选项重新计算，换题或换材料后自动匹配，不按课文编号硬编码。操作材料、书写练习、完整插图和教材题目保留。

演示材料必须与题目中的实际物品一致，具体类型、分组、拿走状态与检查记录见[数学题目演示材料](数学题目演示材料.md)。

本轮只调整界面结构与样式，答题正误、证据记录、完成状态、自动推进、星级、奖励和历史快照沿用原逻辑。
