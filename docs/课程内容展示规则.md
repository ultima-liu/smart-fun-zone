# 课程内容展示规则

2026-10-10：按内容与操作的关系规划展示，作为语文、英语、数学课程同类页面的共用设计依据。只适配 Pad 横屏。具体落地先覆盖本次梳理的全部英语课型，英语细则见 [英语课文展示规则](英语课文展示规则.md)。

## 先判断内容，再选择结构

| 内容关系 | 展示结构 | 使用场景 |
| --- | --- | --- |
| 一张图对应一段连续文字 | 左图右文，播放器放文字区顶部 | 课文听读、故事分幕、看图读句、阅读证据、制作步骤 |
| 连续文字与一段录音，无对应插图 | 顶部播放器，下方单列正文；限宽并居中 | 歌曲歌词、纯文本朗读、独立原声 |
| 同一录音的多个部分 | 一个播放器，下面展示有明确标题的各部分 | 字母歌谣、分段材料；不因录音分段新增任务 tab |
| 多个互相独立的学习对象 | 按对象分网格，对象内部仍紧凑 | 单词、字母、识字；保留图、字、释义、例句的关系 |
| 题目与回答 | 一组连续的题干、必要演示、选项、反馈 | 判断、选择、迁移挑战；选项按内容取宽 |
| 实际操作与参考材料 | 参考与操作区并排，给操作区稳定空间 | 屏幕书写、配对、录音、作品编辑；触摸区域优先 |

同一种内容在任何单元、任何学习阶段采用相同规则。排列方式不由字数多少或“是不是选学”决定；连续文字不能因为超过五句就拆成两列。

## 内容、控件与状态的优先级

- 学习内容为主体，播放、重播、放大等操作附着在对应内容旁。使用小图标呈现播放操作，触摸区域仍至少 44px。不要把辅助按钮做成大面积内容卡片。
- 点读是文字行的操作。序号／人物、完整正文、小朗读图标组成一行，整行可点；普通行 48px 起，不均分剩余高度。读完仅改变小勾或当前行状态，正文和播放入口持续保留。
- 容器只在表达一个完整学习对象或分区时使用。避免播放器外再套大卡、每句话再套大卡、反馈再套大卡。
- 短内容按自然高度从上排列；长内容只在正文、台词或必要操作区内滚动。播放器、导航与关键操作稳定。完整保留材料、重复句、释义、图片，不以删除或省略号解决拥挤。
- 题目与选项保持单行、完整显示。材料正文按语义组织；歌谣的音位、例词和例句可以按完整句分行，仍保持原顺序和原文。
- 原声与语音点读各有明确入口，原声歌词不会因为版式调整自动切换成合成朗读。既有自动播报、作答条件、检查、完成、重复练习与自动推进逻辑由交互层负责，展示层不增加完成条件。

## 本次落地与后续约束

英语 44 课通过共享组件覆盖开篇、Part A/B、字母课、阅读、项目、故事与 Revision。歌曲不再使用独立的两列句子卡片；表达示范、完成后的拼读短句和复习答案同样使用紧凑点读行。字母与屏幕书写沿用专用结构，不把操作区压成文字列表。

新增页面必须先对应上表的内容关系，再复用已有结构；不能在新页面局部重新设定句子卡片高度、排列顺序和播放器位置。其他学科按相同依据逐步复用，本文不将尚未核对的其他学科页面记为已改完。
