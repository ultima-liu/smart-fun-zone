## 八项实施

1. **教材原声听后任务**：20 段原声提供隔离文本的听后任务：7 段根据现有明确文本自动检查，13 段通过录音回听和家人核对；未知脚本不设猜测答案。缺失的 7 处原声继续待补。另加的“听信息，做回应”自编补充模块已按用户要求删除，不再作为课内或复习的完成条件。
2. **递进表达**：44 课都经过跟着示范说、借助句子开头说、变化情境自己说。独立环节隐藏完整答案；用了句子提示后，家人勾选独立也只能记为提示后完成。支持真实或虚构名字、关系和年龄，允许直接说给同伴听。录音仅存当前页面用于回听，不上传、不持久保存；退出释放麦克风。
3. **奖励与证据分开**：完整走过课程得到参与奖励 3 星，历史奖励继续取最高。听懂信息、表达交流、阅读理解、辨音拼读、书写、制作介绍分别记录已练习尚未检查、提示后完成、独立完成、还需要帮助；记录区分孩子自记、家人观察、自动检查及课内/复习来源。自记不能提升能力或覆盖检查，最近困难可以覆盖历史好表现。文字转写只帮助核对内容，不称作发音准确度；固定目标跟读复用浏览器语音识别与本地匹配，开放表达仍使用实际录音。新词识别失败可放进对应短句重读，完整句子核对通过记为提示后完成，详见 [音频自动检查](音频自动检查.md)。
4. **声音到字母到合音**：六单元依次提供完整词的首音/尾音比较、听词选对应字母、用累计已学声音尝试未示范的规则短词，最后读短句。普通 TTS 只读完整词和短句，不生成孤立音位。音位与实际口语由家人观察，不能从转写推断。四线格书写有独立观察标准，不代替发音检查。
5. **真实项目**：朋友行动与理由导图、带主角的家庭关系树、可翻页的动物图片书、需要/给予/行动三条关系的纸上花园、可翻页颜色书、区分年龄和聚会时间的生日卡。支持纸上制作后填写关键信息；检查内容及关系，再实际介绍。编辑作品会撤回介绍完成状态。结构检查与口语观察分开；失败后修订或先听口语示范不会标为无提示独立表现。
6. **主动与延迟复习**：先隐藏答案回想/表达，尝试后才显示示范和检查；每轮三项核心词句，并在已学其他单元存在时混入一项。优先选择困难或需要提示的内容，随后按弱项做合音或新情境表达。总入口沿用课程表选择与节点推进，通过复习总入口安排短巩固。能力用于到期优先级：困难/未检查 1 天、提示后 3 天、独立 7 天；这是队列优先级，不替换课程表频次。点读、示范模仿和复习参与记录不持续压过有效检查。每次复习使用新会话，不能复用上一次完成状态跳过任务。
7. **控制负荷与课型目标**：每课以公共提示和当前任务呈现目标、必要材料和重点能力；2026-10-09 全屏改版后，Part A/B 按各教材任务自己的全部材料和实际配对判断完成，歌曲原声和角色扮演作为明确选学页。阅读、故事、字母、项目使用各自互动而不是只点击文本。首次 this/that、have/like、need/give、混色、数量单位、单双数的六个工具锚点先给规则并保留迁移检查；知识方法放在公共提示和对应迁移挑战中，不再设额外纵向讲解页。需要帮助的儿童仍可完成一轮学习，能力记录不会因此升级。
8. **语言内容维护**：词卡短句逐词显式维护，修正 a/an、复数、不定数名词、动词与身体部位、orange 水果/颜色多义、年龄/钱数/数量单位。颜色问句按具体情境解释，不将“单数 colour 必定只答一种颜色”作为绝对规则。教材检查使用同主题的干扰项。角色舞台只使用完整 Let’s talk 对话，避免不同活动的台词拼接或截断末句。

## 数据与边界

- 能力：`sfz-english-evidence-v1:<child>`，按儿童、课时、任务、来源和上下文存储最近记录，保留最多 1500 条；展示和复习按实际任务最新检查聚合。
- 练习：`sfz-english-practice-v1:<child>:<lesson>:<task>`，保存拼读进度、表达阶段及项目草稿；流程使用 `sfz-english-g3a-flow-v6`，兼容读取旧 v5 阶段。
- 原声 `taskReady` 表示已提供听后任务，不表示孩子已完成，更不参与奖励上限判定。参与奖励沿用现有 mastery 字段，不能解释为听说全面掌握。
- 页面兼容 Web 和 Pad 横屏，课堂采用一屏布局；本次验收宽度为 1024px 与 1440px，使用既有词义图片和真实作品预览。历史家人观察保留原来源；新口语确认检查实际录音，屏幕书写逐笔自动检查；还需要实际儿童使用来验证任务难度和教学效果。
