## 〇、物品体系总览（一图看懂）

> 物品 = 玩家（卷星人）可获取、可持有、可消耗/装配的一切东西。
> 按"经济角色"分五大类，形成「获取 → 积累 → 消耗 → 成长」的循环。

```
┌─ 货币类（消耗媒介）──────────────────────────────┐
│  ⭐ 星星   🪙 卷星币   🎮 游戏币   🎫 兑换卡(非货币) │
└───────────────────────────────────────┘
┌─ 材料类（养成/合成）────────────────────────────┐
│  ✨ 星屑   ✨ 星尘   ⚙️ 引擎环/光晶/护盾板(零件) │
└───────────────────────────────────────┘
┌─ 养成类（成长载体）────────────────────────────┐
│  🚀 飞船(等级/部件)   🎖️ 徽章   👑 头衔   🌟 四维属性 │
└───────────────────────────────────────┘
┌─ 收藏类（收集/展示）────────────────────────────┐
│  🃏 星际图鉴卡   🎨 装扮·人   🚀 装扮·飞船 │
└───────────────────────────────────────┘
┌─ 消耗品（即用道具）────────────────────────────┐
│  💡 提示卡   🛡️ 护盾   ❤️ 生命之心   🚀 火箭加速(游戏内) │
└───────────────────────────────────────┘
```

**世界观包装**：所有物品都来自"卷星宇宙"里可拾取的"星光资源"。卷星人被乌乌怪偷走的星光散落各处，通过学习、游戏、远征把它们收集回来，铸成点亮卷星的力量。

## 一、货币类

货币是消耗媒介，孩子在兑换/升级时花掉。**强调"三币 + 兑换卡"的闭环**，其中兑换卡不是货币（见 1.4）。

### 1.1 ⭐ 星星（星光 / 成长值）

> ✅已实现（`records.stars` 汇总为 `totalStars`）

| 项 | 说明 |
|---|---|
| **定义** | 卷星的"能量"，也是主人公的**成长值**（只增不减） |
| **获取** | 学习任务（课程/游戏/练习）、剧情任务（主线+支线） |
| **用途** | 解锁章节、点亮卷星进阶、参与成长花园（gardenStage） |
| **稀有度** | 无（基础成长币） |
| **上限** | 无上限（成长值不设顶） |

**世界观文案**：*"每一次学习都在收集星光。星光越亮，卷星就越有力量。"*

**工程口径**：星星由 `GameRecord.stars` 累加得到 `totalStars`；星星直接决定 `gardenStage` 与章节解锁门槛。

### 1.2 🪙 卷星币（积分 / 商店货币）

> ✅已实现（复用现有 points/beans 体系）

| 项 | 说明 |
|---|---|
| **定义** | 卷星货币，用于商店/船坞/图鉴等一切"花卷星币"的地方 |
| **获取** | 每日任务、远征战利品、剧情奖励、家长自定义任务加分 |
| **用途** | 商城兑换（装扮/道具/奖励券）、飞船升级、图鉴（替换路径） |
| **稀有度** | 无（基础商店币） |
| **上限** | 每日软上限 + 家长可设上限（`dailyLimitMin` 类配置） |

**世界观文案**：*"卷星币是补给定装好的通用能量，走到哪都能换成需要的东西。"*

**工程口径**：`points[childId]` + `pointLog[]`。`applyPoints` 幂等（sourceId 去重），负数为消费。`INITIAL_POINTS = 200`（新孩子初始，用于体验装扮/兑换）。

### 1.3 🎮 游戏币（乐园币） 🚧设计中

| 项 | 说明 |
|---|---|
| **定义** | 只在空中乐园（小游戏）内流通的局内货币 |
| **获取** | 小游戏内连击/彩蛋掉落（局内闭环） |
| **用途** | 游戏内皮肤、局内道具、游戏内排行榜装饰 |
| **稀有度** | 无 |
| **上限** | 仅限乐园内闭环，不通商城 |

**世界观文案**：*"乐园的彩蛋里藏着游戏币，只属于敢玩的卷星人。"*

**工程口径**：规划中，建议 `gameCoins[childId]` 独立字段，不混入 points。

### 1.4 🎫 兑换卡（家长奖励 / 非货币）

> 🚧设计中（世界观已定义；家长端家庭任务未接入）

| 项 | 说明 |
|---|---|
| **定义** | 孩子**完成家长布置的家庭任务**才获得的"现实奖励券" |
| **获取** | 唯一途径：家长在 /parent 定义家庭任务（如"连续3天学习""整理书包""练琴20分钟"），孩子完成并打卡 → 自动获得 |
| **用途** | 兑换现实奖励（看30分钟动画、周末公园券、一本书） |
| **稀有度** | 无 |
| **上限** | 家长可控（任务难度/频次） |

**关键规则**：兑换卡**不可用任何货币兑换**（防付费/防通胀），只能由家长任务获得；家长端确认任务完成并发放。

## 二、材料类

材料是养成/合成的"原料"，不直接消费，攒够后投入升级或合成。

### 2.1 ✨ 星屑（飞船升级材料）  ✅已实现

| 项 | 说明 |
|---|---|
| **定义** | 远征带回的"飞船燃料/材料"，用于飞船升级 |
| **获取** | 远征战利品（每包 +2，常驻必得） |
| **用途** | 船坞升级飞船等级 |
| **稀有度** | 无（常驻） |
| **消耗** | 升级飞船：`星屑 = 2 + (等级-1)*3` |
| **上限** | 随远征无限积累 |

**世界观文案**：*"远征队的飞船划过星河，带回的星屑是下一段航程的底气。"*

**工程口径**：`materials[childId].stardust`。升级时由 `upgradeShip(childId, stardustCost, beansCost)` 扣除。

### 2.2 ✨ 星尘（抽卡货币）  ✅已实现

| 项 | 说明 |
|---|---|
| **定义** | 星核档案库召唤图鉴卡的货币 |
| **获取** | 远征战利品（每包 **40%** 概率掉 1 份） |
| **用途** | 在星核档案库抽卡：单抽 10 / 十连 90 |
| **稀有度** | 无（货币） |
| **消耗** | 抽卡扣除；抽到重复卡按稀有度返还（R3/SR6/SSR10/SP20） |
| **上限** | 无限积累 |

**世界观文案**：*"远征队带回的星尘，是召唤卷星故事的力量。"*

**工程口径**：`materials[childId].cardShard`（字段沿用，文案为星尘）。抽卡 `drawCards(childId, count)`，结果进 `archivedCards[childId]`。

### 2.3 ⚙️ 飞船零件（引擎环 / 光晶 / 护盾板） 🚧设计中

对应世界观"飞船三部件"升级，按远征**区域**掉落三类零件。

| 零件 | 对应部件 | 获取 | 用途 |
|---|---|---|---|
| 引擎环 | 引擎 | 远征·星域区 | 引擎 0~10 级 |
| 光晶 | 光炮 | 远征·战区 | 光炮 0~10 级 |
| 护盾板 | 护盾 | 远征·边境区 | 护盾 0~10 级 |

**世界观文案**：*"不同的航区带回不同的零件，让你的飞船更耐战。"*

**工程口径**：规划中，建议 `materials[childId].{engineRing, lightCrystal, shieldPlate}`。

> 卡牌 = 卷星宇宙的角色/地点/飞船/事件/传说图鉴，与剧情强绑定。由**星尘抽卡**获得，首次获得点亮图鉴并可领固定奖励。

**稀有度**（四档）：
R、SR、SSR、SP


**3大套系**：

| 套系 | 内容 |
|---|---|
| 卷星人 | 人物：NPC｜
| 舰船 | 飞船：新手艇、探索艇、星舰、传奇舰
| 神秘 | 乌乌怪/传说：乌乌怪、星核、光核、卷星之谜 |

## 六、数值：战力计算（物品与战力的关系）

> 战力 = 主人公驾驶飞船作战的综合数值，用于离线远征结算、世界BOSS、剧情战斗关。**纯 PVE，不做玩家对抗排名。**

```
最终出战战力 = (基础 + 属性 + 飞船) × (1 + 头衔加成% + 徽章系列加成% + 卡牌羁绊%)
基础战力 = 50 + 主角等级 × 8
属性战力 = 智慧×0.9 + 勇气×0.6 + (创造+协作)×0.25
飞船战力 = 飞船等级×20 + 引擎加成 + 光炮加成 + 护盾加成
```

**物品 → 战力贡献**（汇总）：

| 物品/系统 | 贡献 |
|---|---|
| 四维属性 | 换算进属性战力 |
| 飞船等级 | ×20 + 部件加成 |
| 飞船部件(引擎/光炮/护盾) | 引擎/光炮/护盾加成 |
| 头衔 | 百分比加成 |
| 徽章系列 | 集齐 +5%/系列 |
| 图鉴卡羁绊 | 3/5 张激活 +4%/+10% |
| 装扮(人/飞船) | 纯外观，不加战力 |

## 七、数值：远征战利品掉落表

> 抽取来源 `content/expedition.ts`；按飞船等级加成。

| 战利品 | 类型 | 掉落规则 | 单项 |
|---|---|---|---|
| 🪙 卷星币 | 常驻 | 每包必得 | +4/包（×飞船加成） |
| ✨ 星屑 | 常驻 | 每包必得 | +2/包（×飞船加成） |
| ✨ 星尘 | 一般概率 | 每包 40% 掉 1 张 | +1 |
| 🎩 装扮 | 稀有 | 每包 8% 随机免费得1件 | 1 件 |

**累积规则**：

- 每 **5 分钟** 1 个远征周期 = 1 个补给包
- 收取：`周期 = floor((now − lastCollectAt) / 30min)`
- 上限：**240 周期（≈20 小时）**，满后停止累积
- 首次使用送 1 包
- 入账幂等：`expedition:<childId>:<time>:<i>`（sourceId 去重）

## 十一、设计原则与防通胀

1. **三币分流**：星星=成长(只增)、卷星币=商店(软上限)、游戏币=乐园闭环，各不干扰。
2. **兑换卡不走货币**：唯一来源=家长家庭任务，防付费与通胀。
3. **去赌博化**：图鉴以碎片合成保底，不靠纯随机逼氪；主线卡牌保底掉落。
4. **无真实付费**：所有货币 App 内闭环，奖励与现实奖励靠"兑换卡"家长审批桥接。
5. **家长可控**：家长可设置卷星币上限、关闭抽卡/远征/活动弹窗、出征时长。
6. **物品即成长叙事**：每类物品都对应一条"收集星光、点亮卷星"的剧情动机。
