# 数学题目演示材料

更新日期：2026-10-10。适用范围：一年级数学上册教材任务、小检测、智能闯关及共用复习组件；同时检查小探索的材料一致性。

## 确定的规则

题目明确指定杯子、盖子、鱼、花、花盆、积木、小棒或笔袋时，演示必须使用对应物品。题目本来给的是点子、圆片、十格板或抽象数量关系时，保留相应学具，不把所有题目都换成生活物品。

- 物品类型由出题处通过结构化材料信息指定，随机换题时物品与数量一起更新，不在显示时猜测题干。
- 杯子与盖子分别用有杯口、杯身及把手的杯子和带提钮的杯盖图示；杯子与盘子分别用杯子和有盘沿的盘子。分组标题直接写物品名称。
- 两组相同物品使用同一种图示，标出第一组、第二组；领走与剩余的重建情境直接标出对应部分。
- 大、小圆片同时体现实际大小差异，数量不受图形大小影响。
- 拿走或移出的物品保留原物品轮廓，用虚线、斜线及淡化表示已离开；没有离开的部分保持正常显示。
- 小棒使用真实棒状图示；一捆包含十根，十与一分别显示整捆和零散棒。笔袋位置题显示有编号的位置格及笔袋，不再显示小朋友队列。
- 十和一教材学具点击“捆成 1 个十”后，用包含完整十根小棒及绳带的 SVG 显示一捆，不再使用“╟╫╢”字符代替。保留成捆结果，只有明确点击“再做一次”才重置；完成和恢复规则见[课程重复练习](课程重复练习.md)。
- 数量较多时使用紧凑的完整网格，保证每个物品均显示；不省略、不截断、不用一个图标代替多个物品。
- 第四单元数位操作统一使用小棒：10 根零散小棒捆成 1 捆，个位仍显示零散小棒；读写和加减板同样使用整捆与零散小棒。避免题干是铅笔和笔筒，操作却变成捆小棒。具体检查见[数学场景表达检查](数学场景表达检查.md)。
- 小探索同一轮操作前后保持同一种物品：加法交换两组后仍显示积木，小棒放进十格位置后仍显示小棒。圆片与其他原有具体材料继续使用原有图示。

新物品图示使用项目内 SVG，跨 Web 和 Pad 保持相同轮廓，不依赖系统表情的杯盖图案。沿用铺满内容区、四行居中、紧凑选项和无底板提示行的布局。

本次仅调整演示信息与 UI，题目文字、答案、判分、奖励、完成条件及历史记录不变。按项目约定不运行 E2E 用例。
