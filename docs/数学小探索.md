## 交互与保存

每课两步观察，分别检查两个本课目标。先点击按钮改变实际材料，再填数、写完整算式或判断；操作未完成时不能提交。操作前后材料同时显示，便于对照。错误后提示回看材料，原题重试记为借助支持；新一步重新独立判断。算式输入采用有限规则，不执行输入；加法可交换两个加数，减法与连算保留数量角色和变化顺序。

完成后可“换一组材料再探索”，改变数量、形状、参照物或操作顺序。变式保持本课数域与目标，有限材料会循环，不承诺无限不重复。旋转或交换后数量、类别保持相同是本课应发现的关系，不直接提供判断答案。

课时、儿童分别保存轮次、观察步骤、已执行操作、输入及完成状态。新过程存于原任务快照内的 `teaching-exploration-v2`，完成状态同时同步旧的 `teaching-exploration-v1`，供学习流程读取。旧版已经完成的小探索保持完成；儿童可自行选择新探索。旧版未完成的通用活动从本课新计划开始，保留其他教材任务和课程进度。

Web 和 Pad 使用同一流程，按钮至少 44px，算式提供屏幕数字键。具体材料包括圆片分组与配对、十格板及剩余、一捆十根与零散小棒、带编号队伍、位置卡和立体模型；拼合方块以面贴面整排模型呈现。
