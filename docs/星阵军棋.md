# 星阵军棋

状态：2026-10-02 新增。入口：空中乐园 → 棋类 → 星阵军棋 → 进入军棋，在 `/lobby` 页内展开，同时只运行一个游戏。

## 模式与视觉

采用双人**明棋**：玩家执红先行，电脑执蓝，双方军衔全部可见。棋盘采用 5 列 12 行陆战棋沙盘，深松绿地形、黄铜铁路与木质边框，配象牙色红子、青玉色蓝子、山界和三条过桥路线。基础布阵、铁路、行营、大本营与交战规则参照 [Junqi 规则说明](https://www.junqi.app/zh/rules)。

本版明棋的目标是理解路线与军衔判断，不设暗棋翻子、隐藏身份、四国或在线多人模式。

## 布阵

每方 25 枚棋子：司令、军长、军旗各 1；师长、旅长、团长、营长、炸弹各 2；连长、排长、工兵、地雷各 3。

- 提供合法的默认阵型，可以直接开始；开局前点下方两枚红子交换位置，或点击「换一套布阵」生成另一套合法阵型。
- 军旗只能放在己方两个大本营之一，地雷只能放在己方最后两排，炸弹不得放在己方最前排，十座行营保持空白；违反限制的交换会被拒绝并解释原因。
- 棋力只能在布阵或结算后选择，局内与暂停时锁定；换棋力会重新进入布阵。

## 行棋与交战

- 每回合移动一枚棋子。公路沿线走一格，行营连有斜线；铁路无子阻挡时可直线走任意格，工兵还可以沿铁路转弯，不能穿过任何棋子。
- 山界只允许经左、中、右三条桥线穿越；棋盘线路与规则使用同一份连接数据。
- 行营内的棋子不能被攻击；友军不可吃。军旗、地雷和进入大本营的棋子都不能移动。
- 军衔：司令 > 军长 > 师长 > 旅长 > 团长 > 营长 > 连长 > 排长 > 工兵。大吃小，同级双方移除；低军衔主动攻击高军衔时，攻击者被取下。
- 工兵可排地雷；其他普通棋子攻击地雷会被取下，雷保留。炸弹与任何敌子相遇均双方移除。
- 夺取敌方军旗获胜；炸弹与军旗同归于尽也算夺旗获胜。对方无合法走法时同样获胜。
- **本版防僵局规则**：同一局面且同一方行棋累计出现三次，或连续 120 步无交战，自动判和。

## 棋力与辅助操作

| 棋力 | 策略 |
| --- | --- |
| 新兵 | 根据子力、前进与行营位置评估，增加较大的随机性 |
| 棋手 | 以子力交换、向前调动和行营保护为主，轻微随机化 |
| 参谋 | 在己方一步之后模拟对方的回复，优先检查交战回复，最多 40 个回复候选 |

- 合法落点高亮，建议落点显示金圈；「行棋提示」建议一步，由玩家决定是否执行。
- 「悔一回合」撤回最近一次玩家操作及此后的电脑回应，恢复棋盘、取下棋子与日志；可在电脑思考时撤回，保留最近 80 个玩家回合。悔棋不倒退有效游玩时长。
- 电脑回应约延迟 700 ms，暂停时取消待执行操作，继续后重新安排；切后台或窗口失焦自动暂停，需主动继续。
- 计时从开始对弈起，只累计活动对局时间；布阵、暂停和结算阶段不计时。
- 「认输」先暂停并显示确认；取消继续原局，确认后判负并结算。结算后「再来一局」回到布阵。中途返回列表不写记录。
- 指挥台显示轮次状态、行棋步数、用时、最近操作和被取下的棋子。Web 使用沙盘 / 指挥台双栏；Pad 竖屏将指挥台移到下方，横屏保留双栏。
- 鼠标或触屏点选操作，方向键移动棋盘焦点、Enter / Space 选择；H 提示、U 悔棋、P / Esc 暂停。支持中英文与减少动态效果设置；展开时隐藏浮动伙伴入口，避免遮挡棋盘。

## 记录

每局胜 / 负 / 和或确认认输只写一次 `gameId: sky-junqi`：`level: 1–3` 对应三档棋力，胜利 `correct: 1`、其余 `0`，`total: 1`，`stars: 0`，`durationSec` 为有效游玩时间（至少 1 秒）。不发课程星或卷星币，不写课程掌握度。胜局数仅保留于本次游戏挂载会话。

## 背景音乐（2026-10-02 补齐）

- 原创「星阵行军曲」：84 BPM，八小节钟琴旋律、柔和弦乐和轻缓行进低音，由项目已有 Web Audio 音乐引擎实时合成，无需下载音频文件。
- 布阵与对弈时默认一直播放，不提供音乐开关；暂停、认输确认、结算、切后台、窗口失焦或离开游戏时淡出停止。继续对弈后恢复；布阵页重新获得焦点时也可恢复音乐。
- 按用户要求，军棋背景音乐独立保持开启，即使全局音效关闭也会播放；不修改全局声音设置，不影响其他游戏的声音偏好。点按游戏区、使用键盘、开始对弈或继续时，在用户手势中恢复 AudioContext，兼顾 Pad 浏览器的音频限制。
- 返回游戏列表会清理音乐调度与焦点监听，不与后续游戏叠曲。
