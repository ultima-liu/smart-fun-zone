# 语文课程重构（2022 年版课标教材）

## 教材依据与边界

本轮以用户提供的《义务教育教科书·语文一年级上册（根据 2022 年版课程标准修订）》为唯一课程内容依据，不继承项目原语文课程的课序、环节或练习设计。新课程使用独立目录 `#/subject/chinese` 和单课地址 `#/chinese-course/<课时 id>`。

教材目录按“我上学了—识字—汉语拼音—阅读—识字—阅读”组织。数字化实现保持教材篇目与页序，但不复刻纸页排版，而是把画面观察、声音、操作和真实表达组合为学习任务。

## 整册实现

整册现按教材页序开放 45 个独立学习页面：入学主题 4 课，第一单元 6 课，第二单元 5 课，第三单元 6 课，第四单元 6 课，第五单元 5 课，第六单元 5 课，第七单元 4 课，第八单元 4 课。目录通过横向单元标签切换，每次只显示当前单元，不把 45 张课程卡堆成一个长页面。

整册共有 23 课使用专门设计的数字化主题插画。前 5 课的设计重点如下：

1. 《我是中国人》（P2-P3）：发现五星红旗、北京天安门和各民族小朋友；逐句点读“我是中国人”等三句话；按语义拼出“中华民族是一家”；在新情境中完成身份与句意表达。
2. 《我爱我们的祖国》（P4-P5）：保持五星红旗、北京天安门、长江、黄河的教材顺序；通过祖国名片、图名匹配、逐句点读和迁移问答建立图文联系。
3. 《我是小学生》（P6）：完整保留《上学歌》的行序；逐句点读并关注重复词的节奏；通过“整理书包—按时出门—到校问好”的真实行动顺序理解“不迟到、爱学习、爱劳动”。
4. 《我爱学语文》（P7）：对应教材中的读书、写字、讲故事、听故事四幅活动图；用情境指令让孩子真正区分读、写、讲、听。
5. 《天地人》（P8）：保持“天地人、你我他”两组识字内容；从天空、大地、人物的观察建立字义联系，再根据说话位置区分你、我、他。

其余内容已经覆盖第一单元余下识字课、快乐读书吧、三组汉语拼音单元、第五至第八单元的识字与阅读、八个语文园地、口语交际和“和大人一起读”。其中《金木水火土》《口耳目手足》《日月山川》《读书真快乐》《秋天》《江南》《雪地里的小画家》《四季》《对韵歌》《日月明》《小书包》《升国旗》《小小的船》《影子》《两件宝》《比尾巴》《乌鸦喝水》《雨点儿》也分别使用独立原创教学插画。课程类型分为入学主题、识字、拼音、阅读和语文园地，不共用同一套空泛文案：

- 识字课重点处理图形—字形—字义、身体动作、象形字、会意字和生活识字。
- 14 节拼音课按“听音辨形—声调与拼读—图文识字—规律验证”组织，覆盖教材四线三格、带调音节、图文词、认读字、三拼、整体认读、ü 省点以及前后鼻音等重点。教材《读一读》的儿歌和短文已恢复完整文本，不再只取开头句。
- 阅读课按“画面预测—逐句听读—关系/过程操作—迁移表达”组织。
- 语文园地综合识字规律、字词句运用、书写提示、日积月累、口语交际和共读内容。

每课都可以展开“教材完整页对照”，查看该课覆盖的全部原教材页；长课文和跨页语文园地可按页码切换。教材页只用于完整性核对，主要学习路径仍是观察热点、声音、操作和迁移任务。

## 稳定教学流程

### 聪聪语音导览（2026-09-15）

一年级儿童尚不识字，全课要做到**"只靠听声音就能走完一节课"**。交互规则只有一条：**听聪聪的话；想再听，点聪聪**。粒度为"阶段进入自动播报 + 小节/题目手动 🔊 重听"（避免自动声音轰炸）：

- **每页进入自动播报（2026-09-15）**：聪聪导览条抽成语文课本共用组件 `components/TeacherGuideNote.tsx`（含 `narrate` 自动播报），**课程页每个"课 × 阶段"页面进入时自动播报该阶段引导词**（`key={lesson.id}:${phase}` 重挂载，上一课/下一课即使阶段号相同也会重讲；每次重新进入同一阶段也会再讲一次）。**目录页不再有聪聪讲解（2026-09-16，用户确定移除）**：原"先选单元、再点一节课"的目录自动播报与导览条已删；课程页标题栏的「🔊 听聪聪讲」按钮也一并移除——课程导语仍保留在第一阶段的引导词里（`phaseGuides[0]` 以 `teacherIntro` 开头）。自动播放门控为**应用级**：模块加载时注册一次 `window pointerdown（once+capture）`，从目录点进课程的那次点击即算交互，首次进课的引导不被吞掉。目录页离开时 `stopSpeaking()`，不把声音带去别的页面。
- **阶段自动引导**：进入五个阶段时，聪聪老师条自动朗读该阶段引导词。引导词集中在 `phaseGuides(lesson)` 一份 5 元素数组（做什么 + 完成标志 + 下一步），**显示与播报同源**，改一处看听同步。
- **聪聪条即遥控器**：右侧"🔊 再听一遍"重听当前页面引导；监听 `volc-tts-degraded` 显示"🔇 语音服务暂时不可用"提示（原语文页缺失）。
- **完成确认播报**：当前阶段必做项全部完成时，播放 correct 音效并播报"这一步全部完成，真棒！点下面亮起来的按钮，继续下一步"（`saidPhaseDone` ref 每阶段一次），不识字的孩子知道可以往下走。**接续播报、不打断（2026-09-16）**：完成提示走 `narrateAfterCurrent`（TeacherGuideNote 导出，底层是 speech.ts 新增的 `speakAfterCurrent` 接续队列）——刚触发完成的那条内容语音（最后点亮的看图卡片、最后一句跟读点评、最后一个教材任务确认音）先播完，完成提示自动排在它后面再读，不再中途截断；点阶段按钮/翻课时 `stopSpeaking()` 会清空接续队列，提示不会串页。
- **题干/线索自动读**：迁移挑战每题进入自动读题干（数学 PracticeArena 同款）；动手表达每条线索自动读，均配 🔊 重听。知识延伸"换个情境试一试"同款（2026-09-16）：进入知识桥自动播报题干与选项（`narrateAfterCurrent` 接在当前语音后面，不截断刚完成的上一条；ref 防 StrictMode 重复排队），题干旁配 🔊 重听；"金木水火土"的田字格小工坊不在此列（三段各自有点读播报）。读题与阶段引导词的顺序（2026-09-16 修复）：动手表达/迁移挑战进入时读题原本在挂载即刻触发，会被 420ms 后的阶段引导词打断，孩子只听到引导词、听不到题目和选项；现在读题一律 `narrateAfterCurrent` 排队——顺序为阶段引导词 → 题干 → 选项，答题点评播完再接下一题；播报文本用 `promptWithOptions` 统一拼接（题干末尾句号去重，避免"……词。。选项有"）。
- **选项统一 A/B/C 编号**（2026-09-16）：全课程 7 处选择题选项组（动手表达拼句、教材练习选择任务、迁移挑战、知识桥"换个情境试一试"、田字格工坊"动脑试一试"、拼音实验室拼读选择与规律验证、拼音园地问题）按钮统一带 A/B/C 字母徽标——`data-key` + CSS `::before` 实现（`src/options.ts` 的 `optionKey`），不进按钮文本，读屏与测试按选项原文匹配。播报选项时同步读字母（`optionKeysText` 拼成"A是××，B是yy"），`zhSpeakNormalize` 把独立大写单字母读成英文字母名（诶/必/西/第…），不读成拼音声母；答对/答错态徽标反白。徽标与文字对齐（2026-09-16）：选项按钮本身 `inline-flex` 垂直居中，不再用 `vertical-align` 估偏移，任何字号下徽标与文字都在同一水平线。
- **小节手动 🔊**：`SpeakChip` 通用小喇叭挂载在教材练习各 section 标题（朗读课文/词语积累/说一说/会认的字/田字格写字/教材任务/知识延伸分隔）、拼音实验室四个 panel、园地任务标题——点击读该节标题+说明，不自动出声。
- **语音开关**：沿用全局 `voiceOn/sound`（家长设置），speech.ts 统一拦截，静音时自动播报全部失效且不阻塞流程。

每课使用五段数字化学习流程：

1. **看图发现**：进入课文前先观察主题图。孩子必须主动点出关键画面线索，系统同步朗读名称和观察提示；不脱离画面直接问抽象问题。
2. **逐句点读与跟读**（2026-09-15 起）：课文按教材原顺序呈现，每行两个动作明确区分——**🔊 点读**是听老师读（点击即朗读并计"已点读"）；**🎤 跟读**是孩子读给聪聪听：点击弹出收音弹层（红麦克风 + 扩散圆环 + 声波柱动画，浅深主题同款），过程中可反复点「🔄 重新读」，每次识别都记录分数；点「完成，让聪聪判一判」后按跟读相似度（汉字 LCS，与数学课跟读同一口径，≥0.5 通过）AI 判定，通过即计"已跟读"，未通过留在弹层鼓励重读。全部句子"已点读 + 已跟读"才解锁下一阶段。设备不支持语音识别时降级为"听完示范也算读过"，不阻断学习（与数学课跟读一致的兜底）。重点词可再次单独听。以清楚、自然为第一目标，不用速度评价一年级儿童。
   - **弹层即开录、动画即亮（2026-09-16）**：跟读弹层挂载即自动开始收音，收音动画（麦克风呼吸 + 声波柱）由 `useAsr` 的 `listening` 驱动。修复：StrictMode 下挂载 effect 执行两次，连续两次 `rec.start()` 令识别会话互踩 abort，`listening` 被迟到的 onerror 打回 false，弹层刚打开动画不亮（点「重新读」才有）。现在 `useAsr`（speechAssess.ts，与数学课共用）持有当前会话引用：`start()` 先摘回调再挂断上一段，从干净会话开始；卸载/关闭弹层即挂断收音，不留后台会话；旧会话迟到的 onend/onerror 不再影响新会话状态。
   - **拼音注音开关**：逐句点读页的工具条上有「🔤 拼音注音」开关（激活为紫蓝渐变），打开后课文按字上标带调拼音（ruby，蓝色小字，"一/不"按 pinyin-pro 默认变调，与部编教材标注习惯一致），帮助尚不识字的儿童对照拼读；关闭恢复纯文字。实现复用 `pinyin-pro`（与字卡/课文阅读器同一依赖），数组按字符对齐渲染。
3. **教材练习与知识延伸**：不直接把扫描原页挂在学习页面。识字/阅读课结构化呈现会认字、田字格写字、朗读背诵、教材提问、词句练习、变调和停顿知识；拼音课使用专属四步实验室；拼音园地二至四把识字、声音比较、生活词句、积累和共读重组为五项栏目任务。原教材任务之后再用一个“知识桥”讲清相关方法并换情境应用；首次田字格知识则先讲后观察写字。详细首次出现与复现方案见[语文知识延伸](语文知识延伸.md)。教材问题必须完成，不能用“看过教材页”代替。"我上学了"四课（我是中国人/我爱我们的祖国/我是小学生/我爱学语文）没有练习包，走兜底结构：朗读课文逐句打卡 + 词语积累点读 + 说一说句式表达（2026-09-16）——
   - **词语积累不折行**：词格列宽按最长五字词（如"北京天安门"）调到 132px 并对词语加 `white-space: nowrap`，任何词都单行展示。
   - **说一说改为句式支架**（原实现只显示"动手表达"阶段的 mission、点按钮即过，意义不明）：页面内置 `SAY_FRAMES`（每课三句带空的句式 + 聪聪示范句），点句子听示范并计"已说"，三句全说过才解锁「我说完了」；此前错误展示的 `lesson.mission` 不再出现在本节（它属于第 4 步动手表达）。
4. **动手表达**：每课只有一个明确、可核验的关键任务，例如拼句、图名匹配、行为排序或按情境选择“读写讲听”。未实际完成不能进入挑战。
5. **迁移挑战**：不复问刚才的原题，通过新人物、新说话场景、反例和概括题检查孩子是否能理解并使用课文信息。答错给方向提示后可重试，不直接公布答案。

结构化教材练习已覆盖 18 节具有独立生字/写字/课后要求的识字与阅读课、14 节拼音课和拼音语文园地二至四。《秋天》严格对应 P61：10 个会认字、4 个田字格字、借助拼音朗读与背诵、三个自然段检查，以及”一”在”一、一片片、一会儿、一群”中的读音变化。拼音练习必须观察全部本课字母和带调写法，完成代表性拼读、图文词与规则检查；园地逐项点读材料并完成理解检查。原教材完整页只作为”看图发现”阶段的可选核对，不作为”教材练习”的主要页面。

**生字卡**（2026-09-15 恢复老课本功能到新课）：教材练习页「会认的字」「田字格写字」标题右侧各有一个「🃏 生字卡」入口，点击打开整课生字卡浏览（会认字 + 写字字去重合并，位置显示 n/N，可”上一个/下一个”翻页）。卡片复用老课本 `CharCard` 组件：田字格大字、带调拼音、🔊 听读、HanziWriter 笔顺动画、字典释义与组词、课文原文中提词。**触发方式**：入口放在区块标题右侧而非字块本身——儿童单击字块=点读保持单一动作不被干扰；生字卡是需要明确意图的”深究”动作，放在标题处随时可达、不阻塞流程。课程完成（迁移挑战记录星级）时按《汉字图鉴卡》规则把本课生字自动收进字卡袋（`collectChars`，新字 +1 积分、重复不重复计），供后续图鉴/复习使用。

语音使用项目统一中文语音链路。所有核心信息同时以文字呈现，语音服务不可用时不阻塞课程。动效遵守系统“减少动态效果”设置。

中文 TTS 会将多字母带调拼音归一成汉字，因此拼音实验室不能把它当作原音节的准确示范：拼读正确时播报同音汉字示例，图文词直接播报对应汉字。**四声示范行直接读纯韵母本音（2026-09-16）**：`zhSpeakNormalize` 检测到同韵母≥2 个带调字母相邻（如"ā á ǎ à"）时，保留带调字母、空格换成逗号并占位跳过字母归一化，原样交给引擎——实测 seed-tts-2.0 能读准纯韵母的四个声调（F0 轮廓分析验证：一声高平、二声升、三声低、四声降）；旧方案读同韵母汉字（妈麻马骂/哥格葛个），孩子听到的是"ma"等整音节而非韵母本音，已废弃。系统不批改儿童实际发音；如需纯拼音音素的精确示范，应另接教师录制或专门的拼音音频资源。

## 视觉与交互规范

- 目录采用书卷、印章与课本插图感相结合的视觉语言，与卷卷星主题保持一致，但不把语文课做成普通游戏关卡。
- 每一课拥有与教材主题对应的独立观察场景，不用无关通用插图代替。
- 23 课使用 23 张独立的 16:9 儿童绘本插画，不再使用 Emoji 或 CSS 几何图形模拟教材场景。插画不内嵌文字，避免错字；课文名称、线索和朗读仍由页面原生文字承担。
- 14 节拼音课和 8 个语文园地保留教材原页的结构图、口形、字母占格和综合栏目画面，避免原创插画削弱这些内容的教学准确性。整册同时保留 P2-P104 共 103 张完整页对照资源；观察图与完整教材页分工明确，前者用于任务，后者保证内容不丢失。
- 插画必须直接呈现本课关系与动作，而不是只做气氛图。例如《雪地里的小画家》同时呈现四种脚印与冬眠青蛙，《四季》明确分成四个季节场景，《乌鸦喝水》只出现一只乌鸦和一个窄口瓶，并清楚显示瓶内外石子与水位变化。
- “看图发现”的线索按钮直接锚定在画面对象旁，点击后朗读对象和观察提示；移动端缩为编号热点，防止标签遮住主体。热点药丸右侧带 🔊 小图标，提示"点了会读"。
- 点读入口统一带 🔊 图标（2026-09-15，用户反馈儿童分辨不清）：逐句点读行未读时圆形图标为 🔊（读过后为 ✓）；重点词、任务材料卡、兜底朗读/词语卡、会认字、写字听读、拼音字母"点听发音"、图文词语、认读字、儿歌句、园地材料等未完成态一律由 CSS（`chinese-textbook.css` 末尾"点读入口统一加 🔊"规则块）自动加 🔊 前缀，完成态只显示 ✓，不再重复加图标。
- 课文文字采用适合阅读的宋体体系；操作说明和状态信息使用清晰的界面字体。
- 深色主题使用夜读纸面，浅色主题使用暖白纸面；正文、弱文字、按钮和完成态分别定义对比度。
- 电脑、平板和窄屏均保持单一主任务，不横向溢出；阶段导航在滚动时保持可见。

## 进度规则

- 看图线索全部发现后，才可进入逐句点读。
- 所有课文句子都主动点读后，才可进入教材练习；“连起来听”不能替代逐句关注。
- 整册 45 课均配置知识桥。首次田字格工坊要求点选中线、四格、四个范字和三类结构，并答对三次位置/结构问题；其他课程完成教材任务后听方法、完成一次新情境检查。两部分均完成后才能进入动手表达。
- 有独立课后页的课文必须完成会认字、田字格字和全部教材任务；书写环节只记录观察和练习，不因触屏书写困难判断为不理解课文。
- 拼音课必须完成字母发音/字形观察、带调写法和四声走向观察、拼读组合、图文词点读及专属规则检查；园地二至四必须完成全部栏目材料点读和理解检查。
- 完成关键操作任务后，才可进入迁移挑战。
- 三道迁移题完成后记录该课已完成。记录按当前儿童隔离，重复学习不会产生重复条目。
- 新目录已覆盖整册，但仍保持独立进度存储，暂不覆盖旧语文课程的商店奖励、星级或识字卡逻辑。接入统一课程奖励时，应以本课程完成记录为唯一来源，避免与旧课时重复发放。

后续不再补课目数量，重点转向课堂质量：为拼音课增加可视化口形动画和真实音素录音，为写字内容增加分笔轨迹与方向反馈，为口语交际增加录音回听与音量提示，并把整册完成记录接入统一星级、识字卡和家长报告。
