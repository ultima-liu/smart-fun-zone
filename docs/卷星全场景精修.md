# 卷星全场景精修

更新：2026-10-04。包含四种球面、全设施精修，以及最新定位栏、尺寸、间距和星系背景调整。

## 最新确认与范围

用户先确认优先气态，随后要求四种星球都达到参考图类似的精细程度、星环同步调整，并将精修扩展到星球与星环之外的所有场景对象。本轮覆盖四种球面、四套星环、学校魔法书、总部悬空城、档案三卡、船坞、补给站、红蓝掌机、雷达收件站、维修／投递飞船、漂流瓶与太空背景。

所有建筑只有各自的一套精修外观，保持现有造型与配色，四主题不会重绘设施材质。保留[首页建筑布局](首页建筑布局.md)、地点路由、邮件／奖励／远征数据、竖轴环绕、Web／Pad 横竖屏适配。已移除的首页远征战舰不重新加入；飞船细节用于现有船坞与投递模型。

颜色图集贴在真实球体上；光照、法线、遮挡、昼夜交界均由实时球面实现，不用球体图片替代模型。经纬采样、极区夹取、经线边缘窄幅混合减少接缝。岩态／冰态保持地形静止，气态纬度差速流动，恒星低幅磁流扰动。没有改变主光、轮廓光、曝光或 Bloom 来给所有设施染色。

使用共享场景时间，正常主题过渡约 700ms。阅读冻结、减少动态效果静止与后台停绘规则继续生效。纹理失败时使用各主题程序底色，不显示白球或空纹理。

`surfaceDetail.ts` 在工厂完成原始材质后接入，串联而不覆盖已有宝石着色器、封面图和特效。区分金属、皮革、矿物、纸、玻璃与聚合物。微纹理根据像素导数渐隐，工业面板缝也做抗锯齿，降低 Pad 小尺寸上的摩尔纹。所有细节与星球主题权重无关；发光功能色保留。

静态硬件继续按原材质合并，可动关节保留。共享工坊管理贴图、几何和材质，离页统一释放；没有每帧纹理上传、独立计时器或四份建筑场景。
