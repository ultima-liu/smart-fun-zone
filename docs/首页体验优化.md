## 来信状态

信箱提示按以下优先级展示：

1. **奖励待领取**：当前来信或以前未完成分类中存在已完成、尚未领取奖励的课程邮件。显示奖励份数，点击信箱选中该邮件。
2. **新来信**：存在尚未实际阅读的来信。显示未读封数，播放局部收信动效，点击优先打开一封未读信。
3. **继续上课**：没有奖励或未读信，并且存在已经开始、尚未完成的课程邮件。显示课程名称，点击选中该课程来信。
4. **待处理**：信件已经阅读，但任务尚未完成；包括等待家人确认的约定。保留任务数量，停止新信动效。
5. **新回信 / 自由探索**：没有待处理来信时，分别展示最近的完成回信或自由探索提示。

只有真正显示在详情区的信件才被标记为已读；打开信箱不会批量把其余信件设为已读。左侧未读条目保留小圆点，查看详情后消失。已读不会开始课程、删除任务或领取奖励。已经开始的课程和已完成的课程不会被重新提示为新来信。

已读信息按孩子 ID 保存到当前设备浏览器的 `sfz-mail-read-v1:<childId>`，不加入课程事实或云同步；更换设备时尚未开始的来信可以再次显示未读。浏览器存储不可用时，当前页面内仍记录阅读状态。

## Web、Pad 与动效层级

Web 和 Pad 共用真实 3D 卷星，按可用宽高调整构图；竖屏保留卷星尺寸，通过环绕与地点定位查看侧翼和背面设施。窗口过低允许滚动，不裁切入口。环境低速动画、一次送达、领奖星、归航开舱、短镜头导航和欢迎均见[卷星3D首页](卷星3D首页.md)。阅读和切换档案暂停环境动效，减少动态效果与 WebGL 回退保留实际操作。
