# 首页体验优化

日期：2026-10-02｜状态：来信与提示功能已实施；卷星主视觉排版正在重新设计。

本次确认实施来信状态、地点用途提示、Pad 横竖屏适配和动效层级四项。保留卷星场景、原有目的地、课程邮件三分类及任务完成和奖励规则。

## 排版复核：卷星必须是首页主角

2026-10-02 用户截图反馈：上一轮调整后的首页元素分散，卷星明显缩小，未能保持最主要的视觉地位。此反馈覆盖上一轮已实施的尺寸与空间安排；来信状态、地点提示等功能继续保留。

已确认要求：卷星是首页主角，首页其他元素的尺寸、位置与视觉强度必须服从卷星。Web 和 Pad 都不能通过缩小卷星来给辅助模块腾空间。

以下为本轮建议，尚未修改应用排版：

- 采用以卷星为中心的环星布局。球体按可用高度和宽度共同确定尺寸，撤销当前桌面 380px、紧凑横屏 300px 的固定上限；充分利用主场景高度。
- 学校、档案库、总部与船坞继续依附球面；补给站和空中乐园靠近星环两侧，组成一个完整场景。
- 收件站与远征补给缩为星环下沿的两个停靠点，不再分别占用右下大区域与中央大卡片。
- 地点常驻名称；用途通过点选和“认识地点”展开，避免六块双行牌匾同时争夺注意力。用途点读保留。
- 星屑余额只在顶部显示，取消补给上方的重复余额；小卷形象只保留学习助手一个。
- 压低背景飞船、流星、装饰卫星的数量与亮度，把入口与装饰分清。
- Pad 横屏保留集中场景；竖屏优先给卷星宽度，收件站和补给在同一条下沿排列。三种尺寸共享相同视觉层级，不增加独立任务栏。

本轮先提供 Web、Pad 横屏与竖屏的排版示意；球体的具体像素尺寸与实际建筑落点在应用修改时再根据视口巡检确定。

## 来信状态

信箱提示按以下优先级展示：

1. **奖励待领取**：当前来信或以前未完成分类中存在已完成、尚未领取奖励的课程邮件。显示奖励份数，点击信箱选中该邮件。
2. **新来信**：存在尚未实际阅读的来信。显示未读封数，播放局部收信动效，点击优先打开一封未读信。
3. **继续上课**：没有奖励或未读信，并且存在已经开始、尚未完成的课程邮件。显示课程名称，点击选中该课程来信。
4. **待处理**：信件已经阅读，但任务尚未完成；包括等待家人确认的约定。保留任务数量，停止新信动效。
5. **新回信 / 自由探索**：没有待处理来信时，分别展示最近的完成回信或自由探索提示。

只有真正显示在详情区的信件才被标记为已读；打开信箱不会批量把其余信件设为已读。左侧未读条目保留小圆点，查看详情后消失。已读不会开始课程、删除任务或领取奖励。已经开始的课程和已完成的课程不会被重新提示为新来信。

已读信息按孩子 ID 保存到当前设备浏览器的 `sfz-mail-read-v1:<childId>`，不加入课程事实或云同步；更换设备时尚未开始的来信可以再次显示未读。浏览器存储不可用时，当前页面内仍记录阅读状态。

## Web 与 Pad

- 宽屏 Web 保留集中式卷星观测台，收件站与右下学习助手留出独立空间。
- Pad 竖屏：身份和余额在第一行，控制区在第二行；中央卷星、远征补给与下方收件站顺序排列。余额不再隐藏。
- Pad 横屏与紧凑 Web：顶部尽量排列为一行，场景压缩高度，收件站放在场景下方；漂流讯息放在收件站左侧安全区。
- 触屏、竖屏及低高度窗口允许滚动，避免入口被裁切；只有符合尺寸要求的横屏鼠标设备启用单屏滚动锁定。
- 顶部控制区和地点入口至少提供 48px 触控高度；信纸保持左右双栏，主操作至少 72px。
- 首页新增样式集中在 `src/pages/home-improvements.css`，不改动其他页面布局。

## 动效层级

- 每个孩子当前浏览器会话首次进入：保留完整飞船到达流程。
- 同一会话再次回到首页：使用约 1.8 秒短欢迎，不重复飞船或欢迎语音。
- 会话欢迎标记按孩子存放于 `sfz-home-welcome-v1:<childId>` 的 `sessionStorage`；存储不可用时使用短欢迎。
- 开启系统减少动态效果：使用短欢迎，首页装饰 CSS 动效关闭。
- 阅读来信或漂流讯息：结束当前欢迎，暂停卷星自转、公转及首页和星空的背景 CSS 动效，淡化装饰舰队；阅读界面和按钮继续响应。
- 合上来信：恢复背景动效；已读信的收信循环不恢复，除非出现另一封未读来信。
