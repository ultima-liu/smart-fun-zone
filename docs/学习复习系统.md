# 学习复习系统

## 入口与节奏

- 首页顶部的「📚 复习」是总入口；有待复习课程时显示数量。
- `/review` 按当天到期顺序汇总语文、数学、英语，不要求孩子记住自己上过哪些课。
- 每节完成的课程自动加入 **当天、第 2 天、第 4 天** 三次复习；错过前一节点时，完成较晚的节点会一并消化此前待办，不产生同一课的重复卡片。

## 卡片信息与完成

- 每张卡明确给出学科、课名、本次节点与「这次回顾」的核心内容；「去课程复习」回到对应课时，「已完成回顾」用于完成课内回顾后勾掉本次节点。
- 英语课内的词句复习完成后会同步勾掉总入口的对应节点；语文、数学在完成课时后也会自动纳入总入口，可在回到课时完成针对性回顾后，从总入口勾掉本次节点。
- 复习计划只保存节奏、入口和完成状态，正文内容仍由课程页面维护，避免在总入口复制一套教材内容。
