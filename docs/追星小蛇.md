# 追星小蛇

## 2026-10-04 即时转向与棋盘放大

根据再次游玩反馈，上一版最长 80ms 的转向步等待和 80ms 的滑行动画仍会造成明显滞后。取消输入后的移动等待：合法键盘按下、方向盘按下或滑动达到阈值时，直接执行转向并移动一格，立即发布画面；转向步按当前移动档位完成整格滑行，蛇头同步连续旋转 90°；默认认真档约 194ms、该档冲刺约 87ms，让中间转头过程可见。位移线性插值，蛇头旋转用快速起步、缓慢收尾的曲线，没有输入后的等待时间。直行保持原有等级速度与平滑滑行动画，转向后重置累积移动时间，避免紧接着又走一格。

最多缓存两条不同且合法的转向。同一帧首条指令立即执行，快速连按的后续指令每个动画帧执行一条，不再等待 80ms 或一个等级移动间隔。相同方向和原地掉头被忽略，键盘自动重复不追加转向；每次转向实际移动后才消费下一条，避免连按穿过禁止掉头规则。撞墙 / 咬到自己时停止后续步进并按原有流程结算。

Pad 方向盘在 pointerdown 接收指令，不等 click / 松手；键盘激活按钮及辅助技术点击仍可转向。棋盘捕获触点，滑动超过横 / 纵任一方向 18px 时按主轴接收一次转向，无需松手；手势结束或取消后清理。暂停和结束阶段不接收转向。

棋盘继续为 15×15 格，本轮放大显示尺寸。Web 最大边长 352px → 600px，棋盘容器上限 430px → 640px，侧栏 286px → 260px。一般视口棋盘最多占 68dvh；Pad 横屏等低高度横屏采用 60dvh，压缩外框与标题间距，兼顾下方触控操作。Pad 竖屏采用单列，棋盘与操作在前，信息区在下。窄屏最大边长 292px → 360px，同时收窄外框左右留白与内边距，充分利用可用宽度；深浅主题共用尺寸，不产生横向溢出。

## 先前记录：60ms 转向动画微调

用户反馈直接跳格过于突兀，恢复短滑行动画：普通转向 60ms、冲刺 42ms，线性插值且无 transition-delay。按下时仍立即执行转向，输入锁、连按缓冲、移动计时与格数、碰撞和计分不变。棋盘尺寸沿用放大版本，Web 与 Pad 使用相同动画参数；系统减少动态效果时按原有 CSS 关闭动画。

同步调整既有转向 E2E 的画面断言，允许短动画到达目标格。本轮仅调整动画呈现，遵循项目约定不执行 E2E 或引擎测试，采用定向 ESLint、TypeScript、生产构建和浏览器动画采样 / 截图验证。

## 2026-10-04 完整转头动画

再次反馈转向仍太快，检查发现眼睛随方向 class 瞬间换位置，之前的 60ms 只平滑了位移，没有真实的转头过程。现将蛇头外观放入独立的 `.sn-head-face`，背景与眼睛整体连续旋转；外层继续负责沿棋盘移动，避免旋转影响位置。每次按顺 / 逆时针累加 ±90°，跨 0° / 360° 也仅转一个直角，连续转弯不倒转 270°。

转向位移和转头均恢复为当前移动档位时长：轻松初始 250ms、认真初始 194ms、高手初始 150ms；冲刺沿用对应 0.45 倍间隔及 42ms 下限。合法按下仍立即更新目标并启动动画，不增加输入等待，不改移动规则、缓存消费、碰撞或得分。减少动态效果时同时关闭位移与蛇头旋转动画。

本轮只有动画呈现变化，按项目约定不跑 E2E 或引擎用例；验证包含定向 ESLint、TypeScript、生产构建与 Web / Pad 实际中间角度采样。

本轮实际验证：Web 1440×1000 与 Pad 1024×768 均采集到连续中间转角，例如 0° → 23.8° → 43.4° → 57.9° → 75.5° → 90°；默认时长 194ms，无 transition-delay。连续顺时针四次的目标为 90° / 180° / 270° / 360°，再逆时针回到 270°，没有跨零长转。减少动态效果下旋转过渡为 0s。新局重新创建蛇头外观，避免旧局累计角度回零时额外转圈。报告保存于 `assets/snake/head-turn-verification.json`。定向 ESLint、TypeScript、生产构建、包体预算和 diff 空白检查通过；未运行 E2E 或引擎用例。
