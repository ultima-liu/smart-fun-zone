# 页面导航与语音播报

更新：2026-10-01

## 返回入口

子页面返回键统一使用箭头加文字、柔和半透明底色和细边框；Web 与 Pad 共用组件，触控高度至少 48px，820px 及以下视口至少 50px，支持键盘焦点及减少动态效果偏好。浅色和深色主题各自保持文字对比度。按钮采用 1px 淡色边框、600 字重和 20px 箭头，去掉立体底边及厚重阴影；悬停、按下仅轻微改变底色，不位移。西游及葫芦娃图鉴分别沿用暖金和草绿色调，融入各自页头。

- 学校、乐园：返回按钮替换标题左侧的装饰徽记，与标题同排。
- 图鉴、船坞、补给站：返回按钮放入已有页头，与标题、统计同排；西游图鉴与“西行绘卷”标题同排。
- 总部：返回按钮与角色姓名、设置按钮共用人物卡中的姓名行。
- 课程目录：返回学校；课程学习：返回对应课程目录。
- 总部设置：返回总部；复习和任务：返回首页。
- 错题本及数学生活场景：沿用来源页面的返回目标；水果店返回原课程、复习或首页。
- 展开的乐园游戏：返回按钮替换游戏标题左侧的装饰徽记，可访问名称为“返回游戏列表”，关闭游戏并回到列表。

底部列车仅在学校、总部、图鉴和船坞显示，乐园整页及课程、练习页面不显示。返回按钮不单独占用一行，也不使用固定覆盖层。短标题或游戏区显示“返回”，可访问名称保留完整目的地；触控面积沿用原有标准。窄屏优先保持返回与标题同排，统计信息可放到标题栏中的下一行。

## 语音播报

人声继续使用服务端代理的火山 TTS 唯一通道，密钥保存在 `server/.env`，不进入前端包。前端以 `/api/health` 返回的 `ttsConfigured` 为准；构建期默认 `false` 仅作为尚未探测时的默认值，不能覆盖运行时 `true`。

首次播报或预热若配置尚未知，会等待与应用启动共用的健康检查（最多等待 4 秒）。健康结果通知点读界面即时更新服务状态。等待期间翻页或发起新的朗读，会取消旧欢迎语，避免在新页面播放过期内容。

页面切换在新页面欢迎语的 effect 之前停止旧语音。学习助手默认关闭时不停止页面播报，用户关闭已经打开的助手时仍停止助手朗读。声音总开关和语音开关继续生效，不自动修改用户偏好；服务未配置或失败时继续保留流程结束回调。

## 验证范围

UI 改动遵循项目约定，不运行对应 UI E2E 用例。语音验证只覆盖运行时配置、启动等待、取消、未配置回调、预热，以及欢迎语、页面切换和 NPC 点读相关 E2E。真实服务合成另行检查，浏览器端流程回归使用模拟音频以避免每次测试消耗上游额度。
