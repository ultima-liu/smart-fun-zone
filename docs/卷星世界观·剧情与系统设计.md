## 一、世界观总览

**卷星**是一颗会"卷卷生长"的星球：它靠卷星人每日的学习、创造与欢笑获得能量，越长越大、越长越漂亮。

- 卷星人（主人公）都驾驶自己的**小飞船**，白天去**学校/乐园/总部**学习与游玩，晚上穿过**星门**前往星系边缘，与宇宙里的"乱流"作战。
- 卷星的能量以 **星星** 计量：每掌握一个知识、完成一项任务，卷星就多亮一颗星；星星足够多，卷星会"进阶"，地表长出新的大陆、新的建筑、新的剧情区域。
- 宇宙里有一个古老传说：卷星的中心封印着一座 **「星核档案库」**，里面藏着历代卷星人的故事卡片——谁能集齐图鉴，就能唤醒卷星沉睡的力量，解开"卷星之谜"。

**核心冲突（主线悬念）**：最近，卷星边缘出现了一群叫 **「乌乌怪」** 的小黑怪，会在夜里偷偷吞掉卷星的星光。卷星长老发现，只有"知识之光"（学习）+ "勇气之光"（游戏与远征）结合成 **光核**，才能赶走乌乌怪。于是主人公踏上了"点亮卷星"的旅程。

## 三、主线剧情（章节制，随成长不断推出）

### 章节结构
每章 = 一段故事 + 若干任务节点 + 章末奖励 + 新系统开放。**解锁条件全部绑定成长**（星星/等级/成就），无需等待。

| 章 | 名称 | 解锁 | 剧情梗概 | 新开放系统 |
|---|---|---|---|---|
| 序章 | 苏醒 · 星门之光 | 首次登录 | 星门验证身份，飞船送主人公到卷星总部，认识卷卷与铁砣 | 登录、档案、基础导航 |
| 第1章 | 星环学校 | 完成序章 | 星校长阿光发现"乌乌怪"吞噬学校的光，主人公用学习点亮课堂 | 学校四步骤课程、星级、每日任务 |
| 第2章 | 空中乐园的勇气试炼 | ⭐ 6 | 泡泡的乐园能量不足，需要用游戏找回"勇气之光" | 乐园游戏、游戏币、连胜 |
| 第3章 | 补给站与卷星币 | ⭐ 10 | 铁砣发放卷星币；铛铛的补给站缺货，教主人公兑换 | 商城、装扮（人/飞船）、道具 |
| 第4章 | 星核档案库 | ⭐ 16 | 晶晶打开档案库，传说卡牌散落在全卷星 | **星际图鉴**（碎片合成卡，档案库点亮） |
| 第5章 | 夜幕远征 | ⭐ 24 | 乌乌怪夜间来袭，远征队夜幕出征 | **常驻远征**（挂机累积战利品，随时间长、有上限） |
| 第6章 | 认识小卷 | ⭐ 36 | 小卷自我介绍，介绍语音助手功能 | 小卷助手功能引导（语音/问答） |
| 第7章 | 星环竞技场 | ⭐ 50 | 卷星人举办星环联赛 | 周活动：竞技/排行榜（友好榜） |
| 第8章 | 乌乌怪之谜（上） | ⭐ 70 | 在档案库发现乌乌怪与"卷星之谜"有关 | 剧情关、世界BOSS（周末） |
| 第9章 | 家长守护者 | ⭐ 90 | 守护者加入，教主人公“完成任务换心愿” | 家长任务 → 兑换卡、家庭目标 |

## 四、剧情呈现方式（孩子如何"逐渐了解剧情"）

1. **首次进入页面**：每页头出现 1~2 句 NPC 语音旁白（如已有"欢迎来到卷星学校"），逐步加"剧情化前缀"。
2. **过场动画**：沿用已验证的「星门→舱门→飞船」动画语言；重大章节解锁时播 10~15 秒小动画。
3. **剧情气泡**：任务完成/解锁新系统时，小卷弹出气泡 + 语音简述故事。
4. **剧情任务页（独立页面 /story，入口在首页大卷星旁 + 底部导航）**——剧情任务的专属查看页面：
   - **主线任务列表**：当前章节所有节点，显示 进行中 / 可领取 / 已完成，含解锁条件（星星数/前置节点）
   - **支线任务列表**：隐藏支线按触发条件显示（如"连续 3 天进入乐园"触发乐园支线）
   - **剧情回看（编年史）**：按时间轴记录已触发的对话/过场，可重看；未解锁的显示为剪影
   - **章节预告**：显示下一章的剪影与解锁条件，激发好奇
5. **每章预告**：在首页"今日任务"顶部显示当前章节名与下一节点预告。

## 五、货币与经济系统（三币 + 兑换卡）

| 货币 | 名称 | 获取 | 用途 |
|---|---|---|---|
| ⭐ 星星 | 星光 | 两类来源：**学习任务** / **剧情任务（主线 + 支线）** | 成长/解锁章节、点亮卷星进阶（累计成长值） |
| 🪙 卷星币 | 积分（现有 points/beans 体系复用） | 每日任务、远征战利品、活动、成就 | 商城兑换：装扮（人/飞船）、游戏道具、抽卡 |
| 🎮 游戏币 | 乐园币 | 仅在小游戏内掉落（连击/彩蛋） | 小游戏内皮肤、局内道具、游戏内排行榜装饰 |

**防通胀规则**
- 星星只增不减（成长值），获取途径 = **学习任务**、**剧情任务（主线、支线）**；卷星币有每日软上限 + 家长可设上限；游戏币仅限乐园内闭环。
- 商城价格随"章节"解锁分批开放，新章新商品。

## 六、奖励体系：徽章 + 头衔 + 四维属性

### 四维属性（主人公成长，贴学习叙事）
- **智慧** ← 学习类任务/课程（语文/数学/英语）
- **勇气** ← 乐园游戏/远征
- **创造** ← 收集图鉴、装扮搭配、活动创作
- **协作** ← 每日连续、家庭目标、活动组队

属性值参与：远征战斗力换算、部分剧情节点门槛、头衔评定。

### 徽章（现有 6 枚基础 → 扩展为系列）
- 学习系列 / 乐园系列 / 远征系列 / 收集系列 / 活动限定系列
- 徽章可"点亮升级"（铜→银→金），条件 = 星星 + 任务次数 + 属性。

### 头衔
- 由徽章组合 + 四维属性自动评定：如「星环学徒」「乐园骑士」「光核守望者」
- 头衔挂在名字旁（首页/总部展示），并给远征/活动提供小幅加成。

## 七、商城与兑换卡（兑换卡=家长任务奖励，不进商城）

> 本节为设计基线；各类物品的完整定义、价格、稀有度、数据模型见 **《物品体系设计.md》**。

商城（/store 补给站）分类：
1. **装扮 · 人**：发型/肤色/服装/徽章佩戴（现有 dressing-room 扩展）
2. **装扮 · 飞船**：飞船涂装/尾焰/光环——**直接反映到首页到达动画与远征画面**
3. **游戏道具**：乐园小游戏内使用
4. **兑换卡**（不在商城，**不可用任何货币兑换**）：家长在 /parent 定义「家庭任务」（如"连续 3 天完成学习""自己整理书包""练琴 20 分钟"），孩子完成任务并打卡 → 自动获得对应兑换卡（如"看一集动画 30 分钟""周末公园券""一本书"）。兑换卡只能由完成家长任务获得，用于激励孩子；家长在家长端确认任务完成并发放。

## 八、战力系统（作战能力的数值核心）

> 战力是主人公驾驶飞船作战的综合数值，用于**离线远征结算、世界BOSS、剧情战斗关**。只用于 PVE 推进，不做孩子间对抗排名。

### 8.1 战力构成（公式）
```
战力 = 基础战力 + 属性战力 + 飞船战力
基础战力 = 50 + 主角等级 × 8            （等级 = 由星星/章节进度换算）
属性战力 = 智慧×0.9 + 勇气×0.6 + (创造+协作)×0.25
飞船战力 = 飞船等级×20 + 引擎加成 + 光炮加成 + 护盾加成
最终出战战力 = (基础 + 属性 + 飞船) × (1 + 头衔加成% + 徽章系列加成% + 卡牌羁绊%)
```

### 8.2 各系统对战力贡献

| 系统 | 贡献方式 |
|---|---|
| 四维属性 | 按公式换算（学习/游戏/收集/家庭任务养成的属性都会变强） |
| 飞船 | 等级 + 三大部件（引擎/光炮/护盾），材料来自远征与剧情节点；涂装/尾焰为纯外观 |
| 头衔 | 百分比加成（如「光核守望者 +8%」） |
| 徽章系列 | 集齐系列点亮后 +5%/系列（鼓励收集） |
| 卡牌羁绊 | 同系列 3/5 张激活 +4%/+10%（图鉴收集反哺作战） |

### 8.3 飞船升级（飞船战力怎么升）

> **落地现状（以实际代码为准）**：当前已实现 **`/dock` 船坞页**（首页卷星·船坞建筑进入），飞船等级 **Lv.1~10**，消耗 **星屑 + 卷星币**，每级远征产出 **+10%**。下方为设计基线的"部件/涂装扩展"（🚧 未实现）。详表见《物品体系设计.md》第三章。

**升级入口**：总部（/profile）新增「飞船机库」Tab（沿用换装展厅样式）：展示我的飞船、等级、三部件、涂装/尾焰。

| 项目 | 升级方式 | 消耗 | 上限 |
|---|---|---|---|
| 飞船等级 | 机库「升舱」按钮升级 | 星屑（远征战利品/剧情节点/周末BOSS 掉落）+ 少量卷星币 | Lv.50，且 ≤ 主角等级 + 5（防跳级） |
| 引擎 / 光炮 / 护盾 | 各部件独立升级 | 对应零件：引擎环 / 光晶 / 护盾板（远征按区域掉落三类零件） | 各 0~10 级 |
| 涂装 / 尾焰 / 光环 | 商城购买，纯外观（不加战力） | 卷星币 | 收藏品 |

- 升级反馈：升舱播放小动画（引擎点火/甲板展开），战力数值即时刷新。
- 剧情挂钩：第5章「夜幕远征」开启机库；每 10 级触发一次“飞船验收”剧情节点（隆隆验收 + 送涂装）。

### 8.4 应用场景
1. **离线远征**：战力决定单次出征的“扫荡速度”与战利品品质（见第九节）。
2. **世界BOSS（周末）**：家庭/班级共同输出，按贡献发奖；展示“合力赶走乌乌怪”的剧情。
3. **剧情战斗关**（第8/10章）：战力门槛 + 教学关卡，通过后解锁剧情动画。

### 8.5 成长曲线与平衡
- 战力随“学习天数”平滑增长，无付费加速；
- 家长可查看战力构成（家长端），并可选关闭远征/BOSS；
- 战力只用于解锁进度与产出，**不设 PVP 排行榜**，只显示“个人成长记录”。

## 九、离线远征（每日下线→上线循环，强烈剧情向）

- **设定**：每天学习/游戏结束后（或每日首次下线时），主人公驾驶飞船穿过星门，前往「乌乌怪前线」作战。
- **玩法**：家长可在 /parent 设置"允许出征时长"（默认整夜）。出征战力 = 智慧+勇气属性 + 飞船装扮加成 + 头衔加成。
- **战利品**：卷星币、稀有材料（升级飞船/卡牌）、**卡牌碎片**、活动代币。
- **上线收取**：首页顶部"远征返回"动画（飞船从卷星飞回）→ 战报卡（战斗日志 + 战利品列表 + 一段随机剧情短句）。
- **防御剧情**：连续出征 N 天，会遭遇"精英乱流"，战报附剧情片段，集齐片段解锁章节支线。

## 十、抽卡系统：主题 = 《星际图鉴》

> 卡牌主题定为 **「星际图鉴」**：卡面即"卷星宇宙里的角色、地点、事件、飞船"的图鉴卡，与剧情强绑定。

### 卡牌类型（5 大套）
| 系列 | 内容 | 示例 |
|---|---|---|
| 卷星人卡 | 主角/NPC/家长守护者 | 阿光、泡泡、铁砣、隆隆 |
| 星域卡 | 卷星各大陆/建筑 | 星环学校、空中乐园、星核档案库 |
| 舰船卡 | 飞船与装备 | 星跃号、墨黯猎手号 |
| 事件卡 | 剧情名场面 | 「星门开启」「夜幕首战」 |
| 神秘卡 | 乌乌怪/传说 | 光核、卷星之谜 |

### 稀有度与卡面
- 稀有度：**N / R / SR / SSR / SP**（SP=传说级），卡面用已建立的深空玻璃 + 行星风格绘制。
- 每张卡带一句剧情短述 + 所属章节；**收集齐某章套卡 → 解锁该章"隐藏剧情"**（补完剧情闭环）。

### 获取方式（去赌博化、教育向）
1. **学习/任务掉落**：完成章节节点、三星课堂保底给卡/碎片；
2. **远征战利品**：每日离线远征结算开"远征箱"；
3. **图鉴拼装**：碎片合成（避免纯随机）；
4. **剧情卡券**：活动产出；
5. 抽卡本身 = "档案库召唤"，用卷星币购买"星尘"进行；**家长端可关闭抽卡或设每日上限**。

### 卡牌玩法（轻量，不逼氪不诱导）
- 图鉴收集（主玩法）：集齐得属性加成 + 解锁剧情；
- 卡组羁绊：同系列 3/5 张激活远征 buff；
- 剧情重演：拥有事件卡可在档案库重看对应动画。

## 十一、活动系统（不断出新）

**模板化的活动日历**（每周/每月循环，配合真实时间）：

| 周期 | 活动示例 | 奖励 |
|---|---|---|
| 每日 | 每日任务（已有）→ 剧情化"星环日常" | 卷星币 |
| 周末 | 「乌乌怪来袭」世界BOSS（周末晚，学习结束时段） | 限定卡、装扮 |
| 每月 | 主题月：卡牌月/远征月/学习月 | 月限定徽章 |
| 节日 | 结合真实节日出限定剧情（春节=卷星灯会…） | 节日装扮 |
| 赛季 | 每 3 个月一个新章节（第二季起） | 新大陆/新卡套 |

**活动框架 = 一个 JSON 配置 + 通用组件**：`{id, title, story, tasks[], rewards[], banner}`，服务端下发，前端通用渲染——新活动只是数据，可持续上新。

## 十二、玩法循环（孩子的一天）

1. 上线：**远征结算**（收战利品/战报剧情）→ 首页"今日星环日常"
2. 学习：学校上课（看/学/记/练）得星 → 触发章节剧情
3. 娱乐：乐园小游戏得游戏币与勇气
4. 消费：总部换装、商城购买（兑换卡来自家长任务，见第七节）
5. 收集：档案库抽卡/合成，集齐看隐藏剧情
6. 下线：**发起远征**（装备飞船、选择航线）→ 星门动画送别
7. 次日循环，剧情随章节推进

## 十四、家长与安全

- 所有货币仅限 App 内，无真实付费；兑换卡是"把数字奖励兑换成家长同意的现实奖励"的桥梁。
- 家长可关闭：抽卡、远征、活动弹窗；可设置每日卷星币上限、出征时长。
- 剧情按"学习成长"解锁，不依赖付费与抽卡运气（主线卡牌保底掉落）。
