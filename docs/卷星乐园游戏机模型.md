# 卷星乐园游戏机模型

日期：2026-10-04｜状态：已实施。

## 确认的造型

用户将首页空中乐园修改为 Switch 左蓝右红样式的悬浮游戏机，取代摩天轮和环内花园方案。地点名称保留“空中乐园”，场景名为“红蓝游戏机 / Red & Blue Console”，点击进入原来的 `/lobby`。

## 主体与细节

横向圆角掌机采用青蓝左手柄、珊瑚红右手柄、深色屏幕边框和金属导轨。摇杆、方向／动作键、加减键、截图键、主页键、肩键、扬声器孔、散热孔、充电口、背板支架和螺钉均为三维几何。屏幕独立自亮，使用小宇航员在浮岛收集金星的高清画面。

模型、首页定位按钮和列车导航采用统一红蓝掌机识别。四套星球外观不改变游戏机配色。模型保持低幅悬浮，随视角保持画面可读；阅读和减少动态效果遵循场景时钟。

## 素材与实现

- `src/components/juan-world/gameConsole.ts`：掌机与屏幕材质。
- `src/components/icons.tsx`：`IconGameConsole`；旧 `IconFerris` 名称兼容指向掌机。
- `public/assets/juan-world/park-game-screen-v1.webp`：内置 ImageGen 生成，1672 × 941，质量 94 转存 WebP。
- 模型纹理纳入既有异步加载与资源释放机制，静态部件按材质合并。
