## 调度、失败与历史记录

- 三科共用调度器负责自动播放、重播和停止；纯讲解用 `data-lesson-explanation` 提供完整脚本。讲解开始/结束/取消事件让页面在真实播放结束后推进，无需再开一个独立播放器。
- 中文与英语分段使用对应声音；拼音继续用已有真人音节录音。没有录音的拼音不改用英语字母读音补齐。
- 切换 Tab、隐藏父活动、切换孩子或课文、离开页以及声音开关变化时取消旧播放；代次校验确保旧播放结束不会解锁新任务。重做即使停在同一个讲解页，也有新一轮标识，会自动重新播放。
- 数学首次完整听完才自动推进；已听内容的回看、手动重播、已完成旧记录停留原页。重做使用独立草稿，保留历史完成和奖励。
- 声音关闭或播放失败时保留全部文字，直接给阅读后继续入口，不要求先点击一个无声的播放器；不反复自动重试。启用声音或主动重播仍可再听。
- 浏览器尚未允许音频的直接链接入口，在首次点击/触摸/键盘交互后播放当时的讲解；通过站内导航进入可直接自动播放。启动画面退出后才播放。
- 答题输入、判断题及其选项不因讲解回看改变答案。语文规则播放不作为额外作答门槛。

## 验证

- 93 个相关单元检查通过，其中逐一检查数学 47 课讲解的完整内容、自动一次、重播/回看、首次推进、静音、失败、重做和旧播放隔离；另检查三科讲解脚本与普通任务朗读。
- 23 个不同的相关浏览器专项通过：数学知识桥自动播放与完成回调、纯观察推进、重播与历史重做、播放失败、7 个数线课时、普通任务朗读，以及语文知识桥/拼音规则的声音开启与关闭、英语完整/复习占格规则和中英分声重播。失败的旧断言（仍要求静音时先点播放器）已按新阅读入口更新并重跑通过；英语课时 id 和本机浏览器配置错误也已修正重跑通过。模拟语音服务与播放器用于确认文本、次数与播放完成回调，不调用真实语音服务。
- 定向 ESLint 通过。使用临时配置排除工作区已有类型错误的两个测试文件后，TypeScript 检查通过，项目配置未改动。全量检查仍报 `chineseListeningChoice.test.ts` 的 ES2021 不支持 `.at()`（2 处），以及 `chineseReadingAudio.test.ts` 缺少 `node:fs` 类型；这些不是本次改动引入的错误。
- 查看数学讲解、英语首次占格规则与复习规则的 1024×768 截图：自动播放时当前内容可见，只有一个当前讲解重播入口，未发现横向溢出。使用桌面 Chrome 模拟 Pad，未检查实体设备。
- 额外旧「拼音静音时提供实际线下听辨，自己拼读与表达分别必做」用例的规则阶段已经走通；之后停在已经不存在的「请家人帮助，或线下听辨」按钮，属于旧脚本未适配项目现有「我来拼读/自动检查」流程。本次不修改该流程，用新增的声音开启/关闭两条规则专项验证本次门槛改动。
