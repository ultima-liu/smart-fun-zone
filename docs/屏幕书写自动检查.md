# 屏幕书写自动检查

2026-10-09 确定：只在屏幕上书写，不提供纸上书写照片识别。语文汉字、拼音字母及英语大小写书写均由程序根据本次笔画自动检查，无需孩子或家长确认，也不依赖大模型、OCR 或图片上传。

## 汉字

保留本地笔顺范写，在田字格中逐笔输入。Hanzi Writer 使用本地汉字笔画和中线轨迹，对照当前应写的笔画检查方向、起止点、形状与位置。关闭倒写接受、错若干次强行通过和自动描写提示。写错后留在当前笔，全部笔画通过才记录本字完成并进入下一个字。模板加载失败不记完成，可重试。

## 拼音和英语字母

四线三格模板覆盖大小写 A–Z 和 ü。拼音组合如 zh 拆成 z、h 分别写。逐笔采集屏幕轨迹，以固定格坐标对照模板；按轨迹长度重采样后检查起止点、方向、长度和形状偏差，点单独检查位置与长度。没有将乱画缩放成正确字母。采用适合初学者的容差，检查本课范写方式，不作为书法评分。

## 重复练习与记录

书写通过自动记录 `source: check`；这是实际屏幕笔画的自动检查，和开放回答的 `source: ai` 分开保存。仅观看范字、空白或不符合当前笔画的输入都不记书写完成。

清空或重新练习不撤销历史完成状态。汉字逐字断点继续兼容旧 `paper-writing` 存储键；该名称只用于读取历史进度，界面统一称屏幕书写。拼音保存已写字母集合，英语保存已通过大小写字母集合。旧记录不冒充新的自动检查证据。

笔画留在本次页面，无照片上传、无书写评测服务请求；学习档案仅保存检查结论。范围只包含课程汉字和字母书写，数学填数仍使用现有输入答案检查。
