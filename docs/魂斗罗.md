# 魂斗罗 · 一代

更新：2026-10-04。

## 用户要求与当前实现范围

用户要求：新增 FC《魂斗罗》一代，玩法、音乐、关卡高度复刻；场景和人物通过内置 ImageGen 重新设计，支持 Web 和 Pad。

当前接入的是 **原生 Canvas 重制版**。已经实现八关顺序、横向/纵向/纵深三种关卡形式、单人和本地双人、八向射击、俯卧、翻滚跳跃、武器和补给、关底核心战斗，以及从原始 NSF 渲染的 FC 音乐。人物、敌人、Boss 和场景使用新的 ImageGen 资产。

**还原度边界：当前地图平台、敌军出场表、基地房间布局、Boss 攻击和命中点均为重新编排，没有直接读取原版关卡数据；物理和敌军 AI 也没有逐帧模拟原版程序。因此尚未达到用户要求的关卡逐屏高度复刻，不能表述为原版八关地图或完全一致的手感。** 后续还原工作需要逐屏校对平台、水面、爆桥、机关和出场表，并分别校对八个 Boss 的攻击阶段；音乐为原始旋律和音色，循环边界通过音高特征及 PCM 比较测量，未宣称模拟器周期完全一致。

## 战斗规则

- 每人三条生命，生命/得分/武器独立；一位队友生命耗尽后另一位仍可继续。
- 移动速度 90 逻辑单位/秒、陆地跳跃初速 -280、出水跳跃 -320、重力 640，采用 120Hz 固定小步计算。逻辑坐标 384×224，Canvas 1152×672。这些是当前重制参数，并非已核验的原版参数。
- 镜头只能向前或向上推进。上层平台只在下降时落地；下+跳跃可从上层平台和桥面向下穿过，实土地面不可穿透。河道有独立区域，与绘制水面共用坐标；入水浮到水面，按下潜水、松开浮出，靠近岸边后按跳跃，依靠真实弹道越过岸顶才能上岸。潜水时停止横移和射击、避开敌弹及敌人接触，潜水状态不能跳跃，先松开下键浮出；游泳状态允许主动起跳。掉出其他区域扣命。
- 敌弹、敌人接触、喷焰和碾压机关会伤害玩家。命中基于规则引擎中明确的身体范围，图像阴影和特效不扩大碰撞。
- 受击后损失一命，回到当前镜头内可用位置或存活队友附近，获得 2.5 秒保护；失去武器与 R。过关保留生命、武器和得分。
- 普通枪 N；M 机枪提高连射，S 散弹分为五条轨迹，F 火焰弹围绕前进中心作半径 6 的圆周运动，L 激光造成三点伤害且新发射替换旧光束。R 提高弹速，B 提供 20 秒护盾，★ 清除已出现普通敌人与敌弹，不伤害 Boss。
- 武器来自可击落的飞行补给舱；击破后补给下落，必须接触才能收集。不会靠接近尚未击破的补给直接升级。
- 普通敌人 100 分、炮台 300 分、装甲车 500 分；领取补给 1,000 分、击破核心 1,000 分、过关 5,000 分。20,000 分、50,000 分及之后每 50,000 分补命。
- 每个关底有实际可命中的发光核心，摧毁全部核心才可过关；装饰主体不承受伤害。关底战斗、敌军移动速度和攻击周期属于当前重制设计。

## Web / Pad

| 操作 | 单人 / 1P | 双人 2P |
| --- | --- | --- |
| 移动、瞄准 | WASD，单人也支持方向键 | 方向键 |
| 射击 | J / Z / 空格，按住连射 | Enter |
| 跳跃 | K / X | 右 Shift |
| 暂停 | P / Esc | 共用 |
| 触屏 | 各自方向十字键 + B 射击 / A 跳跃 | 独立第二套控制器 |

触屏使用 Pointer Events 和指针捕获，支持同时移动、瞄准、射击和跳跃。松开、取消、失去指针捕获均清除对应输入。控制按钮至少 44px，也可以通过键盘按住激活。切后台或窗口失焦自动暂停、清空输入并停止声音，恢复需要主动继续。

Web 使用战场/战区地图两栏；Pad 和窄屏根据宽度调整侧栏与双人控制器。舞台保留固定战斗配色，全站浅色主题有独立阴影适配。游戏打开时收起悬浮 NPC 和学习伙伴，返回后恢复。减少动态效果关闭装饰粒子、闪烁和步态切换，不改变战斗逻辑。

## FC 原版音乐

原始数据来自 [Zophar 的 Contra NSF 档案](https://www.zophar.net/music/nintendo-nes-nsf/contra)，原始文件 `Contra [Probotector] (1988-02-09)(Konami).nsf`，17,488 字节。原始音乐权利归 Konami；可公开下载的档案不等于开放许可，不将其标成原创音乐。

使用 [Game Music Emu](https://github.com/libgme/game-music-emu) 的 NSF / 2A03 驱动，以 NTSC、tempo 1.0、44,100 Hz PCM 渲染，FFmpeg 编码为 96kbps 单声道 MP3。未替换旋律或编曲，音乐源不需要游戏 ROM。原文件及输出 SHA256、NSF 条目、循环位置记录在 `public/assets/games/contra/audio/sources.json`；运行配置为 `src/games/contraSoundtrack.json`。

| --- | --- | --- |
| 标题素材（预留） | 1 | title-fc-v1.mp3 |
| 丛林、机库 | 2 | jungle-fc-v1.mp3 |
| 基地一、基地二 | 7 | base-fc-v1.mp3 |
| 两个基地关底 | 8 | boss-fc-v1.mp3 |
| 瀑布 | 3 | waterfall-fc-v1.mp3 |
| 雪地 | 4 | snow-fc-v1.mp3 |

| 异形巢穴 | 6 | lair-fc-v1.mp3 |

| 最终胜利 | 10 | ending-fc-v1.mp3 |
| 失败 | 11 | over-fc-v1.mp3 |

关卡对应关系交叉核对 [原版声音代码说明](https://github.com/vermiceli/nes-contra-us/blob/main/docs/Sound%20Documentation.md)。本地保存全部 11 首音轨，其中标题轨预留，其他轨随关卡和事件播放。循环先比较含音高的完整乐句特征，再用 PCM 校正时间边界，避免把反复鼓点误识别为整首循环。

声音遵循全局开关；暂停、后台、静音、重开与退出立即停止并撤销延迟加载。恢复不会叠加音乐。开枪、命中、击破、爆炸、入水、拾取、掉命和补命已替换为原版 NSF 声音驱动渲染的录音。15 个音效文件及声音代码、校验值见 `effects-sources.json`，运行映射为 `src/games/contraEffects.json`。开始时预加载，命中音量高于开枪音，命中不会打断背景音乐；暂停、静音和退出同样取消待加载音效。

音效准备脚本：`scripts/assets/prepare-contra-effects.py source.nsf render-nsf`，校验 NSF 初始化指令与原选择表后，仅将 `$c3c5` 的曲目选择值改为原版音效代码，原音效指令及数据不变；44,100 Hz 渲染、裁去静音并编码 MP3。声音代码对应关系来源同上原版声音文档。

准备脚本：`scripts/assets/render-contra-nsf.cpp`（需 Game Music Emu NSF 构建）、`scripts/assets/prepare-contra-audio.py`（需 NumPy、FFmpeg）；只有重新准备素材时需要，用户游玩不需要这些工具。

## 五处反馈修正（2026-10-04）

1. **弹型与动效**：N 小圆弹、M/S 红橙弹、F 回旋火球、L 红色分段光束；弹口和枪口闪光共用坐标计算，上射和斜射从相应方向的枪口发出。F 使用有界圆周偏移；L 的可见 18 单位光束参与碰撞。实际命中产生火花，击破产生短爆炸，减少动态模式隐藏装饰粒子。
2. **击中音**：非致命命中使用 `$16`，击破 `$19`，异形心脏命中 `$18`，爆炸 `$24`，各武器使用各自原音效。开始时预载，效果声单独播放，不重启音乐；15 个 MP3 浏览器解码均有非零波形，E2E 从实际击中敌军验证命中与击破音源播放。
3. **河道与潜水**：第一关河道 `[512,1024)`、`[1226,1280)`、`[2250,2304)`，水面 y=195、游泳脚部 y=214。陆地碰撞不会被全关水线覆盖；游泳上半身在水面上，水中枪口 y=191；按下隐藏身体并避弹。取消自动上岸，靠岸主动起跳后才能越过岸顶，实土侧壁阻挡普通横移。当前区域仍属于重制关卡布局，未宣称原版地图坐标。
4. **桥**：第一段桥 x=512～1024，64 单位一段，独立倒计时与塌落；木板、绳索、木柱和下方支撑，与连续岩土断面区分。移除原先桥上错误的悬空岩台，桥下是真正的河道；塌落带爆炸和音效。
5. **墙式炮台**：第一关移除地面坦克，改用 ImageGen 圆形岩壁固定炮座；炮管朝向玩家，子弹从炮口发出，受击范围对应固定炮座，不再使用站立炮台或履带车贴墙。所有静止武器要求有实际地形支撑，取消未找到地面时强行使用 y=200 的生成后备值。

本次验证：34 项规则/音频测试、上述 5 项相关 E2E、TypeScript、相关 ESLint、生产构建及包预算通过。`verify-contra-ui.mjs` 检查四种视口；`verify-contra-fixes.mjs` 另用真实规则/绘制模块生成桥/炮台、五种弹型和潜水的静态视觉样例，仅用于渲染核对，不作为完整关卡通关证据。截图在 `docs/assets/contra/verification/`。

## 人物、地形与上岸修正（2026-10-04，第二轮反馈）

- **人物图集**：原先等宽网格把蓝/红俯卧角色的脚切入旁边跳跃图，导致离体脚部跟随人物。本轮指定实际对象边界，重新从原始 ImageGen 透明图集裁切，人物/敌军使用 v2，保留原图与旧输出。水面遮挡不再只判断 swimming 标记：游泳、起跳、下落都按实际河道面裁掉水下部分；岸壁同样遮挡进入实土范围的身体与枪管，防止腿部画进岩壁；潜水仅留水纹，空中取消贴脚阴影。
- **地形**：新增 ImageGen 八种可辨别的草土、岩石、湿河岸、瀑布岩台、雪冰、能源钢板、机库钢板和异形组织材质，丛林分段使用不同土石材质；高岸侧面有暗部，顶沿清晰。纹理对应实际承重面，背景中的插画不参与碰撞。
- **高差**：第一段河道两岸从 y=200 调到 y=160，水面仍 y=195，可见高差为 35。其他早期河岸也提升并保留台阶，桥仍 y=170；出生点与墙式炮台锚点跟随地形高度，不保留旧 y=200 后备值。
- **上岸通路**：删除横移时将玩家坐标移到岸上的逻辑。水中先松开下键，再按 K / X 或 Pad A，同时朝岸移动；出水初速 -320、重力 640，最大上升约 80，足以跨越现有河岸（脚到岸顶最高 64）。进入岸范围前脚部必须真正升过岸顶，下降时按同一平台碰撞落地。陆地跳跃仍 -280；按住跳跃不会反复起跳，超过实际跳高的墙仍会阻挡。
