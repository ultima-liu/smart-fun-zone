# 卷星收件站：雷达扫描

更新：2026-10-04。按用户最新雷达参考图，将首页水母收件站替换为青蓝全息雷达。用户本轮所说的「回收站」对应现有水母所在的收件入口；产品仍使用「收件站」，实际收件、领奖、未读统计和邮差单次送达规则保持原有逻辑。本次仅修改 UI，适配 Web 和 Pad。

## 视觉与动画

- 悬浮圆形雷达盘，深蓝半透明扫描区、青蓝同心网格、径向刻线、银白分段亮环和外圈短刻度，参考用户提供的圆形雷达图。
- 扫描扇面顺时针旋转，每 4.8 秒一周；明亮前缘后跟随渐淡拖尾。
- 十三个稳定位置的信号光点被扇面扫过后亮起、扩散小圆波并逐渐衰减，不代表实际邮件数量，不伪造消息。
- 内外分段环缓慢反向转动，与扫描速度分开；主体轻微上下悬浮。没有水母伞体、触腕、触须和生物组织。
- 存在未读邮件或待领奖时显示小信封，雷达局部亮度略加强；点击雷达或「收件站」标签仍打开原收件界面。
- 固定使用参考图的深蓝、青蓝和银白配色，四套星球外观共享同一效果。

## 实现与位置

实现：`src/components/juan-world/radarMail.ts`，通过 `models.ts` 的 `createMail` 接入；`runtime.ts` 继续提供邮件状态与场景时间。

雷达由 GPU 实时绘制同心环、扫描扇面、刻度与信号光点。无需加载整张雷达图片，因此静止与动画、默认视角与近景均保持清晰。两道窄三维边缘提供前后层次，雷达面保持世界竖直并跟随相机水平方位，左右环绕时保持可读；正常参与卷星及其他设施的深度遮挡。

空间中心沿用 `(3.75, 0.48, 3.15)`，缩放为 `0.82`，标签锚点改为局部 `(0, -1.15, 0.06)`，位于雷达下方。Web 与 Pad 横竖屏共用同一模型与状态，没有窄屏重复入口。

动画只使用首页统一场景时钟：阅读冻结、减少动态效果时静止、后台停绘；不新增独立计时器。所有几何和材质由 Workshop 与场景销毁流程统一释放。旧水母文件与贴图保留为迭代资源，不再由首页导入或请求。
