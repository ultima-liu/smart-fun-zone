# 首页底部星际列车导航

日期：2026-10-02｜状态：右侧半车头收纳与驶入展开已实施，乐园页不显示列车。

## 一、定位

底部导航是一列停靠在星轨站台上的观光列车，对应四个长期开放的一级目的地：`首页`、`学校`、`乐园`、`总部`。首页已经通过卷星场景提供这些入口，因此首页不重复显示列车；列车只在学校、总部、档案库和船坞等主要二级页面承担全局导航；乐园及游戏区域不显示列车，以免遮挡游玩操作，不加入任务领取、奖励提示等额外职责。

列车保持真实导航语义：每节车厢仍是独立链接，站名使用 DOM 文字，不烘焙进图片，便于中英文切换、清晰缩放和无障碍读取。

## 二、视觉结构

列车采用分层 SVG 绘制，而不是用 CSS 方块拼装或使用一张不可拆分的大图：

- 车头、车身、车窗、车门、目的地徽记、轮组和灯光分别成层；
- 首页是带烟囱、鼻梁、前灯和排障器的车头，其余入口是相连车厢；
- 四节车厢共享统一车体，使用金、青、紫、绿四种目的地强调色；
- 深色主题使用夜航星轨，浅色主题使用晨光高架轨道；
- 当前页面对应的车厢停靠在发光站台上，车体与站名文字同步加强对比。
- 站名不使用标题框，只保留紧凑文字；文字与目的地徽记共用同一中心坐标，固定放在徽记与轮组之间，不遮挡车门、车窗或车轮。

## 三、交互与动画

列车默认收纳在页面右下侧，视口外隐藏车厢，只露出前半截车头，轨道、站台衬景和信号灯同时隐藏。点击露出的车头只展开导航，不触发首页跳转：整列火车用约 760ms 的行驶动画从右侧驶到原来的底部中央位置，轮组、连杆、蒸汽和灯光同步播放，四个导航入口随列车出现。展开后点击页面外部区域或按 Esc 可收回右侧；按 Esc 收回后焦点回到车头按钮。收纳期间车厢链接退出键盘焦点与读屏导航，车头按钮支持键盘展开，展开后焦点进入首个导航入口。

展开后点击任意车厢立即执行路由切换，同时在持续存在的底部导航上播放约 680ms 的行驶反馈，不为了动画阻塞跳转：

1. 四节车体按顺序轻微起伏，形成连接列车的跟随感；
2. 两组轮子旋转，轨枕反向移动；
3. 车钩短暂拉伸与回弹；
4. 车头灯增强，目标车厢和站台完成到站回弹。

第二阶段增加机械与环境联动：轮组上方加入传动连杆，车头行驶时喷出三段渐散蒸汽，前灯投射短促光束，背景星光形成反向速度线；展开和车厢点击音效复用项目全局合成音效并遵循声音总开关。这些效果只在交互时短暂播放，静止状态不持续占用注意力。

悬停时车厢轻微抬升，按下时轻微下沉。系统启用 `prefers-reduced-motion` 后，驶入位移、行驶、轮转、车钩和到站动画全部关闭，展开直接显示在底部中央，并保留静态的当前站高亮。

## 四、Web 与 Pad 适配

- 列车只在学校、总部、档案库和船坞显示；首页、乐园、课程和练习页不显示；
- Web 最大宽度为 720px，默认在右下侧露出半截车头，展开后停在页面底部中央；
- 820px 以下收紧到可用宽度；Pad 横竖屏均保持右侧半车头收纳，展开后四节车厢完整显示；
- 620px 以下进一步压缩高度、站牌字号和车钩长度；
- 站名保持单行省略，链接点击区域不小于 70px 高；
- 装饰层和用于裁切的视口容器不接收指针事件，仅车头按钮与展开后的导航接收点击，不遮挡页面触控，也不产生横向滚动；
- 列车显示时，学习助手上移到独立安全区，不遮挡末节车厢；
- 底部位置包含 `safe-area-inset-bottom`，适配平板浏览器安全区。
