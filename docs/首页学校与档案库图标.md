# 首页学校与档案库图标

日期：2026-10-04｜状态：已实施。

## 当前方案

学校采用最新金色展开魔法书参考图，经内置 ImageGen 保真重绘：双页发光炼金符文、棕金厚书页与皮革装订，配合暖金环绕、流光与上升光点。学校入口仍为 `/map`，场景名为“荧光魔法书 / Luminous Magic Tome”。素材与完整提示词见[学校金色魔法书](学校金色魔法书.md)，覆盖此前深蓝闭合星核魔法书方案。

档案库改为金黄、红、蓝三张天体纹样卡，按最新金色雕花卡背参考通过内置 ImageGen 绘制；正反两面同纹样，无人物立绘，具有薄金属卡体并围绕共同中心缓慢环绕。当前资源、完整提示词及近景清晰度规则见[三色环绕卡牌](档案库三色环绕卡牌.md)。入口仍为 `/archive`，场景名为“星际收藏卡 / Stellar Collection Cards”。插画用于地点识别，不表示当前孩子已经获得对应卡牌。

## 动效与适配

魔法书的两条暖金荧光轨迹缓慢环绕，书页中央实时光焰持续升腾、摆动与闪烁，中央流光、上升火星和轻微悬浮继续播放。静态侧焰已从 ImageGen 主图移除，实际动效见[中央火焰预览](assets/学校中央火焰动效.gif)。三张卡相位相隔 120°，约 25.13 秒沿 XZ 椭圆环绕一周，带轻微起伏与摆角，取消原翻转动效。阅读暂停共享时间；减少动态效果固定在静态展示。

三处插画式地点（学校、档案库、乐园）随环绕方向保持正面朝向用户，卡牌在环绕中通过真实深度展示前后遮挡。首页定位按钮使用对应的魔法书、三卡和红蓝掌机 SVG 图标，学校列车徽记也采用荧光魔法书。

## 实现与素材

- `schoolBook.ts`：金色参考图透明插画、既有环绕／流光／上升光点／悬浮动效。
- `archiveCards.ts`：三张双面薄体卡片、椭圆环绕与独立高清卡背。
- `public/assets/juan-world/school-golden-tome-v3.webp`：去除静态侧焰的学校主图；原有 `archive-cover.webp` 和带侧焰 v2 保留为历史素材。
- `public/assets/juan-world/archive-cards-atlas-v1.webp`：内置 ImageGen 绘制，1536 × 1024，三栏各为 512 × 1024，质量 94 转存 WebP。
- 所有纹理、光效、几何纳入既有加载唤醒与离页释放机制。
