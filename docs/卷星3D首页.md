## 已确认的视觉方向

宇宙科幻、星际探索与空间设施。用户明确否定陶土微缩、塑料玩具和木质星环风格，并要求沿竖轴左右查看 360°、分散建筑、独立悬浮设施。因此保留金属装甲、玻璃舱体与局部功能灯光，星球可选择岩态、气态、冰态和恒星，配合各自的表面、大气与尘粒星环；取消云朵平台、布棚、树木庭院与粗实体星环。

卷星是唯一主视觉，真实球面、地表设施与空间设施共享透视相机、光照、深度和遮挡。顶部仅常驻身份、余额、复习、设置；语言、声音、主题、全屏、家长入口折叠。空间场景保持深色宇宙背景，应用主题切换继续作用于其余页面，不把宇宙改成粉彩背景。保留一个学习助手，取消重复星屑余额及大领奖卡。

### 连续曲面造型重设

用户明确不喜欢方正、块状拼接的建筑，要求重新设计。六处设施的主体采用闭合曲面、分层放样和真实舱壳，学校后续按用户悬浮教学楼参考图采用圆角楼体，其余设施不以圆角盒子作为主体；书柜、书脊、舱锁、散热片等功能细节保留相应形状。邮件信舱、远征开舱、学习奖励和路由继续使用现有状态，世界坐标按新的展示布局调整；迎光控制保留，360° 浏览方式不变。

### 减少线条，强化建筑体量

用户进一步反馈：线条过多，每个建筑仍然普通。以功能明确的主体和留白区分六处设施：悬浮教学楼与反重力引擎、总部的悬浮尖塔城市、档案库的魔法书柜、船坞的玻璃维修舱、补给站的环形空间站、乐园的彩色摩天轮。

移除地表地点连线、重复圆形基座光圈、屋盖描边、档案晶体描线及交叉轨道、总部细支撑管与同心雷达、船坞双肋桁架、货舱绑带、乐园重复磁轨和圆珠。保留主视觉星环，以及表达功能所需的少量投影、数据流、焊接火花和推进尾流。乐园最终改为一座彩色摩天轮，必要的轮缘和承重轮辐表达功能，避免重复装饰光圈；阅读和减少动态效果时随场景时间冻结。调整乐园自身朝向，使初始视角与地点定位后都更容易辨识轮缘和座舱。

放样体的端盖与侧壁分离法线，保留平整装甲端面；表面差异继续由陶瓷、石墨装甲、魔法木柜、透明玻璃与彩色金属承担，沿用柔和曝光和反射参数，不靠增加发光线突出建筑。

收件站现按用户提供的雷达参考图设计：深蓝半透明扫描盘、青蓝同心网格与径向刻线、银白分段亮环和十三个稳定坐标的信号光点，独立悬浮。扫描顺时针旋转，光点亮起后渐隐；未读／待领奖时出现小信封，局部亮度略加强。雷达保持固定参考色，保留邮差单次送达与实际收件规则，详见[收件站模型](卷星收件站模型.md)。

投影、扫描和粒子共用场景时间：阅读时冻结，减少动态效果时静止，不另启计时器或动画循环。局部粒子在 GPU 中计算，每套一次绘制；按深度被设施和卷星遮挡，避免全屏泛光。离场同时释放粒子、着色器和程序纹理。

### 空中乐园：彩色摩天轮（2026-10-03）

按用户要求，以彩色摩天轮替换过山车和登乘舱，完全移除乐园的大椭圆圆盘底。向下加长的前后开放 A 字支架、中央轴与两个窄滑橇脚支撑轮体，保留底部留空；不新增云朵底台、托盘或发光底圈。

轮缘由八段彩色实体弧组成，后轮缘与八根轮辐提供厚度和承重关系。八个独立吊舱有不同颜色的舱壳与顶盖、蓝色玻璃和窗柱；轮体缓慢转动，座舱以相反角度补偿，保持正立。乐园继续独立悬浮并低幅起伏，沿用阅读冻结、减少动态效果静止与后台停绘。

### 支架、远征舰与竖轴环绕（2026-10-03）

用户要求摩天轮支架加长、远征变为长型超级战舰、卷星只绕竖轴左右转。本次摩天轮轮心与轮径保持原位，支脚向下延伸约 0.6 场景单位；开放支架的轴心到支脚垂直跨度由约 1.1 增至 1.7，轮体下方留出更长的空间，仍无大圆盘底。

远征主体由短货船改为约 3.56 场景单位长的装甲超级战舰：连续尖舰艏、双侧装甲、背部指挥塔、侧翼、成组炮塔、双引擎与低幅蓝色尾流形成长舰轮廓。原远征补给包、货舱开合、收取反馈与掉落规则继续使用；侧面货舱由装甲门与内部补给箱承接，抵达动画沿用同一舰体。远征舰中心向画面中央移动并上移，补给标签改放舰身后半部下方，确保加长后的默认视角能露出完整舰体并避开底部导航。

### 六处设施重新设计与近景修复（2026-10-03）

按用户确认实施上述新模型：船坞透明玻璃和战舰充电、远征战舰强化与反向、带无线电波的收件站、星顶书院与航标总部、环形补给空间站、魔法书柜档案馆。保留彩色摩天轮与只能绕竖轴左右查看的镜头约束。

- 船坞玻璃不用面板贴图、不写入深度、不投射实体阴影，并独立保留透明部件，避免静态合并后重新变成遮挡内部战舰的实心罩。维修战舰沿用远征装甲舰造型，停靠时关闭航行尾流；维修火花与绿色充电流同时存在。
- 远征舰加长分叉尖艏装甲、局部能量单元和尾部反应器，整体绕 Y 轴翻转 180°，默认视角舰艏朝左。货舱改到对应另一侧，保留可见的开舱与收取反馈。
- 收件站从 Y=-1.95 上移到 Y=0.2，并调整标签锚点；修复环绕到近处时掉出画布底部的问题。修复的是实体位置，镜头俯仰仍固定。收件站、船坞和补给站正面朝向各自轨道外侧，靠近定位时可以看到完整信封、维修舱入口和转运舱。

实际 3D 画布海报作为 WebGL 不可用、渲染加载失败或上下文丢失时的回退；HTML 名称、全部六个地点入口、收件和收取仍可操作。回退时定位按钮直接进入目的地。

### 首页画布空白修复（2026-10-04）

现象：首页已经进入 `world-ready`，地点标签和导航正常，但星球与设施整幅画面消失，控制台没有页面错误。检查离屏像素后发现，船坞无线充电电弧的边缘透明度、档案库魔法流光的端部透明度可能产生 NaN；Bloom 多级模糊把局部无效像素扩散到整张画面，因此图片资源成功加载也会出现空白。

- `facilityEffects.ts`：对电弧插值边缘的分数次幂底数限定到 0～1，避免插值误差使底数略小于零。
- `magicArchive.ts`：流光边缘和两端的正弦衰减在分数次幂前限定为非负数。
- `facilityAppearance.ts`：晶纹波形在幂运算前限定到 0～1，同步避免同类数值越界。
- `models.ts` / `jellyfishGlass.ts`：真实贴图到达后释放 1px 占位纹理的 GPU 分配，下一帧按真实尺寸重新上传，消除 `Offset overflows texture dimensions` 错误；共享图片源的克隆贴图也一起处理。
- `runtime.ts`：使用当前 Three.js 支持的 `PCFShadowMap`，避免已移除的软阴影类型警告。保留原曝光、辉光、多重采样、模型和入口。

默认视角直接读取场景与辉光亮部缓冲，修复后 NaN／Infinity 像素为零，画布正常输出。验证范围为 Web、Pad 横竖屏四套外观、刷新恢复、正常动态模式、档案库定位和 WebGL 静态回退；执行类型检查、定向 ESLint、生产构建及包体预算。仅展示修复，按 AGENTS.md 不运行 E2E 用例。

### 贴图加载警告修复（2026-10-04）

用户提供的日志中，`Texture marked for update but no image data found` 来自尚未下载完成就被使用的档案馆／水母纹理。模型工坊统一为远程纹理提供 1px 中性占位：颜色图为白色，法线为中性蓝色，光学参数保留原默认值。真实图片到达后，重新分配全部共享该图片源的 GPU 纹理，包括书封和书脊，随后更新材质并唤醒静止场景。图片请求失败时保留有效占位，结束加载状态，不再产生空图片纹理警告。

`index.html` 补充 `mobile-web-app-capable=yes`，保留 iOS 配置，消除浏览器的移动端 meta 提示。React DevTools 提示和 Clearly 扩展日志不由项目修改。

Web 正常加载与 Pad 延迟加载巡检均无控制台警告／错误，静态模式能在贴图到达后完整显示；模拟四张模型图片请求失败时，场景仍进入 `world-ready`，只有预期的网络失败日志，没有 Three.js 纹理警告。定向 ESLint、类型检查、生产构建及包体预算检查通过；按 AGENTS.md 不运行 UI E2E。

### 动态整屏闪黑修复（2026-10-04）

用户继续反馈整个 3D 画面反复闪黑／消失。此前静态帧与短时动态检查未覆盖全部异常帧；连续动态采样复现了辉光亮部缓冲偶发 NaN（首次 10 秒采样的 76 次检查中有 12 次异常），局部异常随 Bloom 多级模糊扩散，导致整屏闪黑。贴图请求没有反复加载，页面和控制台也不报错。

- 对全息扫描、雷达、粒子、电弧、尾焰、档案馆、水母和星球光晕的幂运算补齐底数范围约束，避免正弦、余弦、点积与插值误差使底数越界。
- 星环高斯衰减的有符号距离平方改用乘法，保留原形状，避开 GLSL 对负底数 `pow` 的未定义行为。
- Bloom 亮部提取入口过滤 NaN／Infinity，只剔除异常像素的辉光贡献，防止它们污染整条模糊链。保留原曝光、辉光参数、多重采样、动态效果和交互。

Web 1440×900、Pad 768×1024／1024×768 的四套外观分别连续采样动态帧，并检查档案库定位。共 471 次外观帧检查，辉光异常帧、中心黑帧及 GPU 错误均为零，页面／控制台无警告或错误。Pad 横屏恒星的一次源缓冲异常被辉光入口成功隔离；这项保护也覆盖底层材质或 GPU 后续产生的局部无效值。浏览器巡检不能代表真实 Pad GPU 性能。执行定向 ESLint、类型检查、生产构建与包体检查；按 AGENTS.md 不运行 UI E2E。
