# 坦克大战 · Battle City

## 确定的范围（2026-10-04）

空中乐园 → 敏捷 → **坦克大战 → 进入坦克大战**。以 Namco 1985 年 FC《Battle City》为基准，保留基地防守、原版 35 关、单人 / 本地双人合作、四类敌车、三段星星升级、六种道具与原版录音；重新设计场景、坦克、道具和指挥台 UI，适配 Web、Pad 横竖屏及窄屏。没有加入《坦克 1990》的船、手枪等扩展道具。

本项目是浏览器重制，采用连续坐标和固定小步模拟，并非运行原版 ROM。关卡布局和敌军出场表直接读取原版数据；敌军采用向下推进、障碍转向的四向行动逻辑，未逐指令模拟原版 CPU 的随机行为、转向时机与动画帧。

## 关卡与胜负

- 战场为 13 × 13 个大格，逻辑大小 416 × 416。每个大格 32 像素，内部拆为 8 像素小格，保留原版半砖、半钢墙及分层破坏。
- 底部中央固定鹰徽基地与 U 形砖墙。顶部三个敌军入口；玩家出生在基地左右两侧。基地被任一方炮弹击中立即失败，友军开炮也可能误毁基地。
- 每关 20 辆敌军；单人最多同时 3 辆，双人最多 6 辆。双人刷新间隔按原版 `(190 - 关卡 × 4 - 20) / 60` 秒设置；单人按 `(190 - 关卡 × 4) / 60 × 1.6` 秒设置，最短 2.5 秒；入口被占用时等待，避免坦克重叠生成。
- 玩家初始每人 3 条生命（含当前坦克）；死亡后丢失星级，回到固定出生点并获得出生保护（单人 6 秒、双人约 3.2 秒）。双人只有双方生命均耗尽才因生命失败；基地被摧毁则双方失败。
- 消灭整关敌军进入结算，显示各玩家四类击杀数。生命、得分、升级保留到下一关。原版 35 关之后重新循环地图，第二轮采用第 35 关的敌军配置和各模式最短刷新间隔；再完成 35 关回到首轮配置，支持继续循环。
- 可从准备界面选择任意原版关卡练习；每局开始仍为 3 条生命与初始火力。没有跳关按钮或自动无敌。
- 不依靠爆炸视觉判定伤害。只有真实炮弹与坦克可见车体相交才命中；炮管和爆炸装饰不扩大判定，消失的特效不会残留伤害。

## 操作与合作

| 操作 | 单人 / 1P | 双人 2P |
| --- | --- | --- |
| 移动 | WASD；单人也支持方向键 | 方向键 |
| 开炮 | J / K / 空格 | Enter / Shift |
| 暂停 | P / Esc；界面暂停按钮 | 共用 |
| Pad / 触屏 | 各自方向十字键与 A / B 开炮；可同时按方向和开炮 | 独立第二套按键 |

A / B 均为原版同一种炮弹，可按住连续射击。手指松开、取消、丢失指针捕获时清除对应输入。窗口失焦 / 页面进入后台自动暂停并停止声音，返回需手动继续。方向转弯对齐到小格，炮弹小步推进避免高速穿墙。

合作共享一个基地。友军炮弹不扣队友生命，而使队友暂时熄火约 4.4 秒；护盾会挡下友军弹。互相对射的炮弹抵消。敌军炮弹不会伤害其他敌军。双人结算击杀较多者获得 1,000 分奖励，平局不额外奖励。

## 地形与坦克

| 地形 | 规则与表现 |
| --- | --- |
| 砖墙 | 每发打掉一层 8 像素深、约一辆坦克宽的砖；升级后破坏两层。多发可打通可行驶通道 |
| 钢墙 | 阻挡坦克和普通炮弹，三颗星后可击穿 |
| 水域 | 阻挡坦克，炮弹可以越过 |
| 草丛 | 可以穿越；草丛覆盖在坦克、炮弹上方，形成遮挡 |
| 冰面 | 可以穿越；松开方向后有短暂惯性滑行 |
| 鹰徽基地 | 不可行驶，任何一方炮弹都能摧毁；不能用生命替代基地 |

普通敌车 1 次命中、100 分；快速敌车移动速度约为普通车的 2 倍、200 分；火力敌车炮弹更快、300 分；装甲敌车 4 次命中、400 分，车下显示剩余装甲。玩家移动速度为 90 逻辑像素 / 秒，普通炮弹 240、升级炮弹 480；双人敌车普通移动 60、快速移动 120，单人分别为 45 / 90。单人敌军炮弹速度为双人的 80%（普通 192、火力 384），再次开炮冷却 1.6–2.8 秒，双人冷却 0.8–1.4 秒。玩家移动、炮弹速度和升级效果一致。

玩家升级顺序：一颗星提高弹速；两颗星允许同时两发炮弹；三颗星可以破坏钢墙，并加深砖墙破坏。最高三级，死亡归零，过关保留。

## 道具与计分

原版第 4、11、18 辆敌车携带道具，闪烁红色光晕。携带装甲车第一次被击中便掉落，不必等四次击毁；每辆只掉一次。新道具车入场撤掉上一个未领取道具。掉落位置从原版 4 × 4 位置网格选择，避开钢墙、水域。道具按原版节奏闪烁，未领取会一直保留，直到下辆道具车进入或关卡切换。星星与手雷各占原版八项随机表的两项，其余各一项。每次领取加 500 分。

| 道具 | 效果 |
| --- | --- |
| 星星 | 提升当前坦克一级，最多三级 |
| 头盔 | 约 10.67 秒护盾 |
| 时钟 | 约 10.67 秒冻结敌车移动与开炮；已发射的炮弹继续移动 |
| 铁锹 | 基地 U 形围墙改为钢墙约 21.33 秒；末尾闪烁，结束重新恢复完整砖墙 |
| 手雷 | 清除场上已出现的敌车，出场动画中的车不受影响；只给道具的 500 分，不追加击杀分与击杀统计 |
| 坦克 | 当前玩家增加一条生命 |

道具时长按原版每 64 帧递减的计时器换算，以 60 Hz 为基准。每位玩家首次达到 20,000 分额外加一条生命，不每 20,000 分重复奖励。

## 自定义战场

准备界面的「设计我的战场」进入 13 × 13 编辑器，可点按 / 拖动绘制空地、砖墙、钢墙、水域、草丛、冰面；敌军入口、玩家出生点、基地及 U 形保护墙由引擎保留。自定义使用整块地形，原版关卡继续保留半块布局。

保存到 `sky-tank-construction-v1`，刷新后恢复，非法值或损坏存储会回退默认地图。自定义战场按第一关敌军配置循环练习；随时可回准备界面切回 35 关经典战役。

## 原版音效与来源

使用 **18 段原版事件录音**，没有 Web Audio 合成乐曲或自编持续背景音乐。开场播放原版关卡短曲，战斗中按静止 / 实际移动切换两种履带声；开炮、砖墙 / 钢墙 / 装甲命中、敌车 / 玩家爆炸、补给出现 / 领取、加命、冰面、暂停、计分、失败分别对应独立录音。受全局声音开关控制；暂停、后台、重开、退出停止当前声音和延迟解码回调，恢复不会叠加发动机。

来源与对应关系：

- [原版 NES 注释反汇编](https://github.com/cyneprepou4uk/NES-Games-Disassembly/tree/main/Battle%20City)：`tbl_DACB_block_data` 地形四象限；`tbl_E4EC_stage_enemies` 出场类型；`tbl_E578_stage_enemies_type_counter` 出场数量；`tbl_E9E2_bonus_pickup_handler` 六种道具；音效编号表及原版定时器。原始 NSF 的初始化例程还在 6502 模拟器中逐曲运行，通过 `$0300–$031B` 事件标志确认音轨与原版编号，映射记录见 `docs/assets/tank/nsf-sound-map.json`；基地爆炸采用 SFX 7 / 0B，独立于玩家爆炸。
- [Battle City Reforged 的具名音频资源](https://github.com/dderevjanik/battle-city-reforged)：事件录音名称，交叉核对原版编号；其来源为 [The Sounds Resource 原版录音](https://www.sounds-resource.com/nes/battlecity/sound/3710/) 和 [Zophar 原版 NSF 录音](https://www.zophar.net/music/nintendo-nes-nsf/battle-city)。不采用没有确认语义的 `unknown-*` 音轨。
- 原版音频权利归 Namco，音频档案可访问不代表资源采用开源许可。此处记录实际来源和校验值，不把原版录音标成原创资产。

`scripts/assets/prepare-tank-data.py` 解析原版 35 份 91 字节地图与类型表，输出 `src/games/tankLevels.json`；音频仅裁掉录音起止静音并转为单声道 22,050 Hz PCM WAV，静止 / 移动取稳定 2 秒循环段。处理不改变旋律、音色与音高。准备输入位于 `tmp/tank/bank_FF.asm`、`tmp/tank/stages/`、`tmp/tank/audio/`，从上述源地址取得。正式运行不加载 ROM、临时文件、Python 或 FFmpeg。

| 事件 | 原版编号 | 运行录音 |
| --- | --- | --- |
| 关卡开始 | 01–03 | intro |
| 开炮 | 0F | fire |
| 砖墙 / 钢墙 / 装甲命中 | 0C / 0D / 0E | brick / steel / armor |
| 敌车 / 玩家爆炸 | 0A / 07 | enemy / player |
| 基地毁坏 | 0B | hq + player（原版同时触发）；终局接 over |
| 道具出现 / 领取 | 09 / 06 | appear / pickup |
| 加命 / 暂停 / 冰面 | 04–05 / 00 / 10 | life / pause / ice |
| 静止 / 玩家移动 | 12 / 11 | idle / move |
| 双人 1,000 分奖励 | 1B | bonus |
| 结算 / 失败 | 13–14 / 18–1A | score / over |

运行文件位于 `public/assets/games/tank/audio/`，`sources.json` 保存原始录音名、事件编号、来源与输入 / 输出 SHA-256；`docs/assets/tank/stage-sources.json` 保存每份地图的校验值与解码表名。

## ImageGen 与 UI

使用内置 ImageGen 生成三套 1536 × 1024 图集：六辆俯视坦克、六种补给徽章、八种地形 / 基地块，共 **20 张独立 WebP** 接入战场和卡片。美术以手绘玩具模型质感重绘，不使用原版精灵。

- 原图：`docs/assets/tank/tanks-atlas-v1.png`、`powers-atlas-v1.png`、`terrain-atlas-v1.png`。
- 完整提示词：`docs/assets/tank/imagegen-prompts.json`。坦克强调严格俯视、统一向上、六种可辨认轮廓；道具要求独立金色徽章与清楚六种功能符号；地形要求方形俯视、可拼接砖 / 钢 / 水 / 草 / 冰 / 地面和鹰徽基地。
- 处理：`scripts/assets/prepare-tank-imagegen.mjs` 仅分格裁剪、根据已有 Alpha 收紧空白、缩放、转 WebP，不程序重画、不消除背景。坐标与输出尺寸保存在 `docs/assets/tank/imagegen-manifest.json`。
- 运行素材：`public/assets/games/tank/*-v1.webp`；地图按原版数据分层绘制，道具和坦克独立旋转，草丛在实体上方，炮弹 / 爆炸 / 护盾以 Canvas 实时绘制。
- UI：米白 / 森绿指挥台、战场外框、敌军剩余数、尚未出动队列、玩家分数 / 生命 / 星级、基地状态和道具手册。深色主题改为墨绿面板与浅色文字。游戏馆卡片保持一行两张，浅色主题使用浅色底。
- Pad 横屏压缩标题和战场并展开横向情报区，减少操作时滚动；竖屏和窄屏按可用空间排列。方向键最小 44 × 44，A / B 48–54 像素，可多点触控；减少动态效果时关闭出生旋转与闪烁特效。
- 游戏按需加载到独立构建分块，入口卡片样式独立，避免新增游戏挤占游戏馆首屏包预算。

## 记录与验收

整局失败，或首次完成经典第 35 关，写入一次 `sky-tank`；`level` 为 1 / 2 对应单人 / 合作。继续后续循环不重复写当前局记录，重开开启新局；中途返回不结算。`stars=0`，不发课程星、金币或课程掌握奖励。每次关卡结算 / 失败刷新最高分，单独保存到 `sky-tank-best-v1`。

- 单元测试 `src/__tests__/tankEngine.test.ts`、`tankAudio.test.ts`：29 项通过，覆盖原版地图 / 出场表、炮弹分层破坏与可通行通道、钢墙升级、真实命中、护盾 / 装甲 / 六种道具、友军规则、基地 / 生命、关卡循环和声音映射 / 延迟取消。
- 本次相关 E2E `e2e/tank.spec.ts`：4 项，覆盖单人移动 / 暂停 / 友军误击基地 / 一次结算、Pad 双人多点触控与失焦、地图编辑保存 / 刷新恢复、18 段原版录音实际解码与非静音检查。
- 视觉验证脚本 `scripts/assets/verify-tank-ui.mjs`：Web 1440 × 1000、Pad 1024 × 768 / 768 × 1024、窄屏 390 × 844，两种主题，准备 / 战斗截图与尺寸报告保存在 `docs/assets/tank/verification/`；检查入口双列、无横向溢出、准备面板完整、操作键 ≥44 像素、20 张美术均加载成功。
- 定向 ESLint、TypeScript、生产构建及资源包预算检查通过；坦克游戏独立分块约 34.2 KiB gzip，游戏馆分块约 140.6 KiB gzip，保持在现有 170 KiB 预算内。音频 18 份输出 SHA-256 复核一致。

### 2026-10-04 单人难度调整

单人采用轻松节奏：同时敌军上限 4 → 3，刷新间隔乘 1.6 且最短 2.5 秒，敌车移动速度降 25%、敌弹速度降 20%、开炮冷却翻倍；敌车出生冷却 2.4 秒，避免出生动画刚结束立即开炮。玩家开局 / 重生 / 下一关出生保护增至 6 秒。此配置覆盖 35 关、后续循环和自定义战场；双人合作保留经典节奏。每关 20 敌、三命、装甲命中、基地胜负与升级规则保持原有配置。准备面板随单人 / 双人选择显示对应节奏。

验证覆盖敌军上限、刷新间隔、下一轮节奏、敌车 / 敌弹速度、玩家炮弹、出生 / 重生保护，以及单人移动、暂停、基地失败和一次性记录。

本轮实际验证：坦克引擎 27 / 27 单测通过；单人移动 / 暂停 / 基地失败 / 一次性记录与 Pad 双人多点触控两项相关 E2E 通过。定向 ESLint、TypeScript、生产构建和包体预算检查通过。
