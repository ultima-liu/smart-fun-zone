# 聪明乐园 · 商业化升级方案

版本：v1.1 ｜ 范围调整：经与需求方澄清——付费、订阅、登录、运营暂不考虑，本方案中涉及商业化模式与运营的内容暂停实施，仅作未来扩展参考；当前升级聚焦**产品质量达到商业化发布水平**，详见《产品质量升级方案.md》。

## 1. Demo 与商业化的差距盘点

| 维度 | Demo 现状 | 商业化要求 | 优先级 |
|---|---|---|---|
| 账号体系 | 浏览器本地档案，无登录 | 家长账号（注册/登录/找回/多端同步/多儿童管理） | 高 |
| 付费体系 | 无 | 订阅/买断 + 支付渠道 + 订单/退款/发票 | 高 |
| 内容运营 | 关卡包打包在前端代码里 | 远程关卡配置、版本化下发、灰度、运营活动 | 高 |
| 数据能力 | 无埋点 | 行为埋点 + 运营看板（注册/留存/时长/付费转化） | 中高 |
| 合规 | 无 | 隐私政策/用户协议/儿童个人信息保护/备案/未成年人保护 | 高（上线前提） |
| 工程化 | 手工构建、无测试 | 自动化测试、CI/CD、监控告警、错误上报、日志 | 中 |
| 安全 | 明文本地存储 | HTTPS、防刷限流、数据加密、最小化收集、访问控制 | 高 |
| 内容素材 | emoji 占位 | 原创插画/配音/音乐（品牌与版权，可分批投入） | 中 |
| 多端 | 仅 H5 | PWA 可安装 → 微信小程序（二期） | 中 |

## 2. 目标形态（v2.0 商业化版）

产品形态：**H5 响应式网站 → PWA 可安装 → 微信小程序（二期）**

核心用户链路：
```
家长注册登录 → 创建儿童档案（可多个） → 免费试玩基础游戏
→ 订阅解锁全部游戏/关卡/报告 → 多端云同步进度 → 家长查看学习报告与订阅管理
```

## 3. 商业化模式（推荐：订阅制）

- **免费层**：基础 3 个游戏 + 每日限局，用于获客与体验
- **订阅（主推）**：解锁全部游戏与关卡、学习报告详情、多设备云同步
  - 月 / 季 / 年三档，年费为主推（参考同业 ¥168–298/年）
  - 首单 7 天免费试用，自动续费可随时取消
- **买断制（备选）**：一次性买断全部内容，适合部分家长的消费偏好
- **明确不做**：广告（幼儿产品红线）、诱导性内购（合规红线）

## 4. 技术架构（商业化版）

```
客户端（H5 / PWA / 小程序）
  ├─ React 前端（现有代码改造：账号态 + 云同步 + 订阅态）
  └─ 埋点 SDK（行为事件上报）

API 网关（HTTPS · 域名 · CDN 前置 · 限流防刷）
  ├─ 认证服务：微信授权 / 手机号验证码（短信）→ JWT
  ├─ 业务服务：家长账号、儿童档案、进度云同步、订阅与订单、支付回调
  ├─ 内容服务：关卡包版本化下发（配置 + CDN 素材）
  └─ 数据服务：行为事件入库 → 运营看板

数据层：PostgreSQL（业务） + Redis（会话/限流） + 对象存储（素材） + 日志/监控
```

技术选型建议：
| 层 | 选型 | 说明 |
|---|---|---|
| 后端框架 | Node.js + NestJS（或 Fastify） | 与前端同语言，类型共享 |
| ORM | Prisma | 类型安全、迁移方便 |
| 数据库 | PostgreSQL 13+ | 业务数据 |
| 缓存 | Redis | 会话、限流、缓存 |
| 部署 | 腾讯云/阿里云轻量应用服务器起步 | 随量升级 |
| CDN | 腾讯云 COS + CDN（或七牛） | 静态资源与素材 |
| 监控 | Sentry（错误上报）+ 云监控告警 | 上线必备 |
| 支付 | 微信支付 + 支付宝（需商户号） | 国内主渠道 |

## 5. 数据模型新增（相对 Demo）

- `User` 家长账号：id、phone、wechatOpenid、passwordHash、status、createdAt
- `Subscription` 订阅：userId、plan、status、expiresAt、provider、orderId
- `Order` 订单：userId、plan、amount、status、provider、paidAt、refundedAt
- `ChildProfile` 增加 userId 归属（云端全局唯一 id）
- `GameRecord` 云端同步（替代纯本地）
- `ContentRelease` 内容发布：gameId、version、configUrl、publishedAt（关卡包远程配置）
- `Event` 行为埋点：childId、type、payload、ts

## 6. 合规清单（上线前必须完成）

- [ ] 隐私政策 + 用户协议 + 儿童个人信息保护规则（含监护人同意机制）
- [ ] ICP 备案 + 公安备案（使用国内服务器/域名）
- [ ] 未成年人保护：家长控制（时长/时段/内容开关）、休息提醒、防沉迷
- [ ] 数据最小化：仅收集必要数据、传输加密、存储加密、支持导出与删除
- [ ] 版权合规：原创或授权素材、字体/音效商用授权
- [ ] 支付合规：微信/支付宝商户号（需营业执照）、订单可追溯、退款与发票能力

## 7. 运营体系

- **内容后台**：关卡包上传 → 审核 → 发布 → 灰度（先 5% 用户再全量）
- **数据看板**：注册数、DAU、次日留存、平均时长、付费转化率、退款率
- **用户反馈**：应用内反馈入口 + 客服邮箱/企业微信
- **运营活动**：节日主题关卡、限时免费、老带新赠订阅

## 8. 路线图与成本预估

| 阶段 | 内容 | 周期 | 成本要点 |
|---|---|---|---|
| A 商业化基座 | 后端 + 家长账号 + 云同步 + 家长中心升级 | 3–4 周 | 服务器起步约 ¥100/月 |
| B 付费体系 | 订阅 + 支付对接 + 订单管理 | 2–3 周 | 商户号（需营业执照） |
| C 运营与合规 | 埋点看板 + 内容后台 + 隐私文档 + 备案 | 2–3 周 | 域名约 ¥60/年、短信约 ¥0.05/条 |
| D 内容与素材 | 12 游戏全量 + 原创插画/配音（分批） | 4–8 周 | 素材外包 ¥5k–50k 视量级 |
| E 多端与增长 | 小程序 / 落地页 / 投放 | 4 周+ | 广告预算另计 |

关键里程碑：
- **M1** 商业化基座上线：家长可注册登录、进度云同步、免费/订阅内容分区（可内测）
- **M2** 付费闭环打通：可真实收款、自动续费、订单与退款管理
- **M3** 合规就绪并正式发布：备案完成、隐私文档上线、监控告警运行

## 9. 待确认决策

1. 商业模式：订阅制（推荐）vs 买断制 vs 混合
2. 登录方式：微信授权 + 手机号验证码（推荐）vs 仅其一
3. 部署目标：国内云（需 ICP 备案）vs 先海外快速上线
4. 首发端：H5 先行（推荐）vs 微信小程序优先
5. 素材策略：先 emoji 占位运营 vs 先采购原创插画/配音
6. 商户主体：是否有营业执照（影响支付与备案进度）
