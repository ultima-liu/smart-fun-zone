# 语文认字与听辨题

## 会认的字与点读卡片

会认的字正文与说明音频不显示、不朗读教材页码。进入和重听只朗读“会认的字。逐个点读，注意字形、拼音和课文中的意思。”；字卡由孩子逐张点击播放，不作为答案选项自动读出。词语点读卡片采用同样的说明与点读分工。点读卡片从通用答案选项扫描中移除，并标记为主动音频入口，点击时取消待播放的开场说明。

## 播放顺序

2026-10-10 确定：这类听音选择题分为两段操作，进入或重听题目时只播报要求，不播放目标音频，也不提前读选项。孩子点击播放后，认字题只播放词语及要找的字，播完即可选择；拼音听辨仍按“真人音节 → 屏幕顺序中的所有选项”串行播放，全部播完才能选择答案。

- 认字抽查的播放按钮为“听词语”，语音只说明词语及要找的字。所有汉字选项保持静音，包括重听；不读出选项来提示答案的读音。课堂与复习使用同一规则。
- 拼音听辨的播放按钮为“听真人音节录音”，目标和每个拼音选项使用已有真人录音；选项编号使用中文，避免将 A/B/C 合成为字母或音节。
- 重听遵循相同顺序，不计提示或作答证据。答错仍按原规则记录需要帮助；听音不能代替答题完成。
- 目标音频失败时不解锁答案；拼音听辨的选项播放失败时也不解锁。认字题可重新播放，不提供 AI 认字检查入口或弹窗；拼音练习保留自己拼读路径。关闭声音、离开题目和换题会重置听音状态；旧播放回调不能解锁新题。

## 完成与推进

课堂认字抽查答完第三题，立即自动进入顺序中的下一个 tab，不显示“认字抽查完成”卡片或“再做一次”按钮，不增加确认步骤。下一个 tab 已完成时也按顺序进入该项。

跳转仅由本轮最后一题答对触发。打开课程、刷新、普通重绘或手动切回已完成 tab 都属于回看，不触发跳转。已完成认字抽查保留最后一道原题供查看及重听，作答锁定，不能再次写证据或触发推进；仍不展示完成卡片或重做按钮。完成记录每轮只通知一次，题目不循环，不自动创建新一轮。复习入口由复习页面保存本轮完成结果。

## 一屏布局

2026-10-10 调整：采用居中的“题目 → 通用音频播放器 → 选字”纵向布局，去掉左右大卡片、步骤标题和选项编号。题号在标题区右侧轻量展示；答案横向等宽排列，以大字、浅色底和清晰边框呈现，周围保留留白。未听完时选项暂不可点，文字仍清楚可见。认字题仅保留选字与答错反馈，不提供 AI 检查；答对直接进入下一题，不显示“这个字找到了”。

通用播放器 `AudioPlayer` 使用 44px 圆形播放键，配音频名称、状态文字与小波形；播放中波形随真实播放状态动画，结束显示“再听一次”，失败显示“重新播放”。不显示虚构时长、进度或暂停能力；减少动态效果设置下关闭波形动画。播放器已由课堂、复习、拼音听辨及音频迁移题的共用组件复用。

只适配 Pad 横屏，一屏显示，不增加分页或滚动。拼音规则页切到听辨练习后，隐藏上一层重复的规则讲解标题，留足当前题目、播放和选项空间；切回规则检查仍展示原标题。复习入口使用同样的分区与清晰背景。

## 全量覆盖范围

两个共用练习组件统一接入 `ChineseListeningChoice`，播报入口设置 `data-chinese-narration-mode="instructions-only"`。全项目语文调用点已核对：

| 入口 | 覆盖范围 |
| --- | --- |
| 教材练习的认字抽查 | 18 节课，`RecognitionCheck` |
| 认字复习小检验 | 30 节课可配置认字复习，包含拼音认读字，复用 `RecognitionCheck` |
| 拼音课堂听辨及拼音复习 | 14 节拼音课、56 道听辨材料，复用 `PinyinListeningPractice` |
| 有目标音频的迁移挑战 | 28 道题，复用 `PinyinListeningPractice` |

普通文字选择题、自己合音拼读题沿用原题目播报；分段顺序针对需要先请求目标音频的听音选择题。

整册资源核对发现 `yǒ`、`tèi` 两个干扰项没有录音；分别替换为已有真人录音的 `huǒ`、`dài`，相应迁移题由同一材料自动同步。目标音节和答案保持原值。
