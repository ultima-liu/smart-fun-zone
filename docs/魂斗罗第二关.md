# 魂斗罗第二关：基地一

更新：2026-10-04。对应用户反馈：场景难以辨认、俯卧仍被普通敌弹打死、击破中间机关后无法开门推进。

## 场景与操作

基地以清楚的钢铁房间呈现：后墙中央是双扇大门，红色机关安装在门上，两侧射击口可见敌兵，前方电网有独立立柱。人物使用 ImageGen 新生成的背向站立/俯卧姿势，朝后墙开火。地板与墙面的透视统一，敌弹从后墙向前景靠近并逐渐变大，不能把远处子弹直接当作玩家面前的横版子弹碰撞。

单人从中央 x=192 开始，直接射击即可对准第一间机关。左右移动可调整射击位置；按住 ↓ 或 Pad 下方向键俯卧，J / B 射击。命中时保留原版命中与击破音效；机关有剩余耐久条，战场下方同步显示剩余耐久与当前操作提示。

1. **战斗**：机关尚有耐久，电网开启、门关闭，前进按钮禁用。
2. **开启**：全部机关被击破后，立即停止房间攻击并清掉残留敌弹，电网关闭；两扇门在 0.4 秒内向两侧滑开，破坏的机关淡出。
3. **开放**：门内通道、地面前进箭头和绿色「前进 · 下一间」按钮可见。按 ↑ / W 或点击按钮进入，不要求再次射击或猜测隐藏入口。
4. **进入**：0.85 秒的镜头推进和人物缩小动画；禁止射击、固定人物在地面，完成后进入下一间并重置机关与门，保留生命、武器和分数。

共六间房，机关耐久依次为 12、14、16、18、20、22。击破每间机关加 1,000 分；第六间开门后进入关底。关底有三个沿水平线排列的红色弱点，各 32 耐久，位置与独立新素材对齐；左右移动对准弱点、俯卧射击即可攻破。关底击破加 5,000 分，各弱点加 1,000 分，总计第二关 14,000 分。过关后「进入下一关」进入瀑布，不提前结算整场战役。

## 俯卧与弹道规则

原版程序 `bank7.asm` 的室内玩家碰撞分支明确跳过俯卧玩家与普通敌弹的碰撞：参见[原版程序](https://github.com/vermiceli/nes-contra-us/blob/main/src/bank7.asm)的 `@check_player_collision` / `@next_player` 相关分支；房间机关、电网的独立状态也见[原版 RAM 注释](https://github.com/vermiceli/nes-contra-us/blob/main/src/ram.asm)。

本实现据此对基地内 **落地俯卧** 的玩家跳过普通敌弹碰撞；该规则也适用于基地关底普通敌弹。站立仍会受到攻击，跳跃不是俯卧，室外俯卧不获得通用无敌。

基地敌弹记录出发点、目标横向位置和纵深进度，只在抵达前景时检查命中。到达站立身体高度后消失，不继续向地板追踪俯卧人物，也不无限堆积。电网关闭后的残弹立即移除，开门和进入动画期间不会被清场前的弹道击杀。

基地二共享房间结构、纵深敌弹和俯卧/开门规则，但保留八间房、两侧两个机关，必须全部击破后才能开门。

## ImageGen 素材

- `assets/contra/base-room-v2.png`：独立工业基地背景，门洞和射击口清楚；提示词 `base-room-v2-prompt.txt`。
- `assets/contra/base-characters-atlas-v1.png`：透明 2×2 图集，蓝/红人物背向站立和俯卧；提示词 `base-characters-prompt.txt`。
- `assets/contra/base-boss-v2.png`：独立透明基地关底，三个水平弱点；提示词 `base-boss-v2-prompt.txt`。移除旧图集里混入的邻格植物残片及不对应命中点的纵向装饰光点。

裁切/编码脚本 `scripts/assets/prepare-contra-imagegen.mjs` 只做图集拆分、透明边距裁切和 WebP 输出。运行使用 `base1-v2.webp`、`boss2-v2.webp` 及四张 `*-base-*-v1.webp`，旧源图和 v1 保留；全游戏共 41 张解码资产。门、电网、耐久条和提示随真实规则状态绘制。

## 验证

- `npx vitest run src/__tests__/contraEngine.test.ts`：41 项通过。新增覆盖实际敌弹对站立/俯卧的差异、室外不获无敌、纵深到达判定与过期、实际射击开门、未命中不开门、六间连续推进、基地二双机关。
- `npx playwright test e2e/contra.spec.ts --grep 'redesigned base|base prone|Pad base|loss records' --workers=2`：三个短用例通过；六间连战用例首次受共享 40 秒时限影响，增加该用例的总时限后单独重跑通过。
- 六间连战用例扩展为真实键盘打完六间房和三个关底弱点，点击过关按钮进入第三关；无注入机关耐久、武器、生命或关底状态。最终专项重跑 `--grep 'redesigned base' --workers=1` 通过。
- 另三个 E2E 分别验证出生保护结束后连续俯卧 30 秒仍保留三命、松开后站立受伤；Pad 双指俯卧与开火及实际点击前进；失败唯一记录与重开不重复发奖。
- `verify-contra-base-ui.mjs` 检查 1440×1100、1024×768、768×1024、390×844 的明暗准备画面及实际战斗/开门画面：无横向溢出、控制器和前进按钮至少 44px、41 张图解码、无页面异常。结果 `assets/contra/verification/base-layout-report.json`。
- `verify-contra-base-art.mjs` 用生产规则/绘制模块生成站立、俯卧、开启、开放、进入、关底六张独立渲染样例，仅用于核对视觉与动画状态，不作为玩法通关证据。
- 相关 ESLint、TypeScript、生产构建与包预算通过。本轮未修改音频，不重跑音频或其他游戏 E2E。

仍属于当前原生重制关卡，并未声称第二关的房间编排、Boss 攻击和物理已达到原版逐屏/逐帧复刻。总体还原边界见[魂斗罗.md](魂斗罗.md)。
