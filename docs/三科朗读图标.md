# 三科朗读图标

2026-10-10 确定（根据「不需要边框，尺寸小一点」反馈更新）：语文、数学、英语的重听入口只显示同款小喇叭图标，不再显示「再听一遍」文字和大面积按钮色块。UI 只适配 Pad 横屏。

## 统一样式

- 使用共用 `CourseReplayButton` 和专用 `IconCourseSpeaker` SVG，不使用系统喇叭 emoji。
- 重画的图标为蓝紫色圆润喇叭、青色机身与双层声波，带高光。独立重听入口的图形缩小为 24×24px，去掉圆形边框、底色和阴影，只显示彩色喇叭；实际透明触控区保持 44×44px。材料内嵌声音标记沿用同款图形。悬停略放大，按下缩小反馈，仅键盘聚焦时显示辅助轮廓，不可播放时降低透明度。
- `aria-label` 与 `title` 保留具体用途，例如「再听一遍讲解」「再听题目和选项」，只隐藏可见文字。
- 三科、弹窗和学习助手的重听使用相同样式，深色主题也不添加边框或底色。

## 覆盖范围

三科公共提示区、数学知识延伸讲解/纯观察图示、数学检测题、语文小节说明与知识桥、英语问题旁重听，均使用共用图标按钮。数学课程概述/示范、汉字卡、答疑回答、学习助手的朗读入口同步统一。

教材内容上的点读提示、拼音材料、英语词句/歌谣的声音标记也统一为同款 SVG。点读材料本身仍保留词句、完成勾选和任务说明；真实听辨的「正在播放」等状态以及教材原声控件保留。

数学知识延伸图标仍放在当前讲解卡片标题右侧，避免滚动后找不到；此时不在上方重复提供同一内容的入口。自动播放与重听沿用原回调、声音开关、完成推进与历史回看规则。相关规则见[课程纯讲解自动播放](课程纯讲解自动播放.md)。

## 播放状态与防重复点击

2026-10-10 补充确定：音频播放期间，当前重听图标的两道声波交错呼吸，保持彩色；禁用再次点击。合成/加载等待也锁定入口，避免孩子因暂时没出声反复发起请求。同一时间的其他重听入口暂时禁用，防止打断当前音频；它们不显示当前内容的播放动效。

自动朗读通过统一调度器绑定当前图标，手动重听通过图标自身绑定，状态来自真实的 TTS/拼音播放器，不按文字长度或固定时间估算。中英分段、中文与真人拼音的段落交接持续锁定；播放完成、报错、取消或切换活动后恢复。每次播放独立登记和释放，旧请求结束不能解除新请求的锁定。真实听辨的音频卡沿用已有播放状态与防重复点击行为。

不添加边框、底色、进度条或新按钮。保留 24px 图形、44px 透明触控区；辅助阅读提供 `aria-busy` 与「正在播放」提示。系统要求减少动态效果时停用声波动画，禁用逻辑保留。

## 题目旁图标不换行（2026-10-10）

题目、标题或说明旁的语音按钮和文字保持同一横向排版行，禁止把整枚小喇叭挤到下一行。长题干可以在自身文字区域内折行，按钮始终保留 44px 空间；不缩小触控区、不截断文字，不改变播放和防重复点击逻辑。知识桥用一层 `data-tab-audio` 包住按钮时也适用。

修复语文公共标题容器的 `flex-wrap: wrap`，并在共用重听样式中统一约束带按钮的标题和说明。检查三科、汉字卡、答疑和学习助手涉及的 17 个文件、34 处共用组件调用（包含 SpeakChip 转发入口）；原本独立排列的播放器和操作栏继续使用各自布局。

UI 验证：全册语文题目、教材任务、知识桥、园地、配对排序和其他标题共 276 个文本样本，在 1024×768、1180×820 两种 Pad 横屏宽度下均保持图标位于文字右侧，没有独立换行或横向溢出；另检查截图中的“交换角色后”真实挑战页面及三科实际页面。预览保存在 `tmp/course-audio-row`。本次仅修改 CSS，按 AGENTS.md 不运行 E2E。
