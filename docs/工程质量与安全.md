# 工程质量与安全

状态：发布基线（2026-09-28）

## 发布前硬门禁

- `npm run check` 全部通过。
- 前端与服务端 `npm audit --audit-level=moderate` 均无已知漏洞；CI 在安装锁定依赖后重复审计。
- 本次修改涉及的领域 E2E 通过；纯 UI 调整按项目约定不运行 E2E。
- 不存在默认生产 JWT、数据库密码、管理员密码或 mock 短信配置。
- 新增儿童数据接口必须使用统一儿童所有权校验，不能直接信任客户端 `childId`。
- `/api/**` 不得进入 Service Worker、CDN 公共缓存或共享浏览器缓存。

## 身份与权限

- 孩子令牌只能访问令牌内的孩子 ID。
- 家长只能访问所属家庭的孩子。
- 管理员可管理真实存在的孩子，但管理操作写审计日志。
- 停用账号会让新登录和已有令牌同时失效。

## 生产配置

`NODE_ENV=production` 时，服务端启动会校验：至少 32 位 JWT 密钥、非默认数据库密码、至少 12 位管理员密码、真实短信提供商和明确的 `CORS_ORIGINS`。任一条件不满足即拒绝启动。

## 数据与隐私

- 只收集完成学习、同步和家长管理所需的数据。
- 删除孩子档案时同步删除课程、剧情、错题、跟读、计划、积分和物品记录。
- 日志不得记录令牌、密码、验证码、儿童跟读正文或第三方 API 密钥。
- 对登录、验证码、TTS 和学习助手实施限流；生产部署仍应在反向代理层增加全局限流与 HTTPS。

## 性能基线

- 单个 JS 构建产物 gzip 不超过 170 KiB。
- 单个 CSS 构建产物 gzip 不超过 120 KiB。
- 大型视觉资源优先 WebP/AVIF；非首屏图片使用懒加载，首屏主视觉使用异步解码。
