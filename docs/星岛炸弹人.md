# 星岛炸弹人

状态：2026-10-04。云上游戏馆 → 敏捷 → 星岛炸弹人。默认经典难度，适配 Web / Pad，纯娱乐游戏，不发课程星或卷星币。

## 还原依据与范围

核心规则参考 [Hudson 原版说明书](https://www.world-of-nintendo.com/manuals/nes/bomberman.shtml)，50 关怪物表、道具顺序、升级上限、过关加命、原始计时及音效编号核对 [原版 NES 反汇编资料](https://github.com/emu-russia/bomberman-nes) 的 `BMAN.NAS` / `CONSTS.NAS`。只将关卡配置与规则重新实现为 TypeScript，不在应用内分发 ROM 或运行模拟器。

这是保留现有星岛画风和现代操作的重制版。经典模式采用原版 50 关配置；轻松、高手是本项目难度变体。地图软砖位置、角色逐格移动和怪物局部追踪为重制实现，没有宣称逐帧复刻。原版密码、隐藏奖品及特殊连杀倍率尚未实现。第一关火力道具仍固定在出生通道尽头，以便学习操作。

## 画面与图标

31×13 的长迷宫、23 格宽横向跟随镜头，左右边缘停止滚动。主角、地面、石墙、蜂蜜软砖与阶梯出口采用 ImageGen 素材，Canvas 负责场景组合、炸弹和爆风动画，并保留加载失败时的备用绘制。

道具与八类怪物使用内置 ImageGen 生成的透明图集，按原版颜色、功能符号和轮廓重新绘制。30 张 WebP 运行素材位于 `public/assets/games/bomber/`，源图、完整提示词与裁切记录位于 [assets/bomber](assets/bomber/imagegen-prompts.md)。Canvas、游戏馆封面、开场立绘、随身装备和图鉴共用同一组角色及图标，避免图鉴和场内外观不一致。图片未加载时使用原有绘制作为备用。

三岛仅作为视觉分区：薄荷草岛 1–15、晚霞花园 16–30、星光城堡 31–50，地面仍随每五关轮换。得分、生命、关卡与延长后的倒计时在画面上方；方向盘、A 放弹、B 遥控与手册均在画面下方。生命超过五条时显示数量，避免连续加命挤出 HUD。

## 关卡与生命

每个普通关藏一件固定类型的道具与一扇随机暗门，两者不重叠。清除全部怪物后走进已露出的门通关，过关增加一条生命，装备跨关保留。最后第 50 关直接胜利。

经典模式怪物从首关六只逐步增加至十只，逐关配置保存在 `BOMBER_STAGE_ROSTERS`；轻松采用同一怪物表但降低速度，高手增加两只且初始两命。轻松与经典初始三命。敌人速度按类型固定，不再随关卡叠加任意加速。

普通关三档难度统一显示 400 刻，保留每 64 帧减一刻的计时节奏，按 60Hz 换算约 426.67 秒（7 分 7 秒），是此前 200 刻时限的两倍。此项为项目体验调整，经典模式也采用延长后的时限。到零时清除原有怪物并替换为十只 Pontan 旋风怪，仅触发一次，不直接判负。经典最多十只同时在场，高手十二只。

第 5、10、15、20、25、30、35、40、45 关后进入奖励关，倒计时 60 刻（约 64 秒，是此前时限的两倍），没有软砖或暗门，角色免疫怪物与爆风。场上不足十只时补充；奖励怪物依次升级为八类怪物，后期使用旋风怪。结束后进入下一普通关。

接触有效危险时失去一条生命并进入重试面板，所有模拟冻结。重试恢复同种子地图、怪物与本关时间；火力、容量与疾跑能力保留，遥控、穿砖、穿弹、防火和无敌时间丢失。已取得的基础道具不因死亡重复刷出；本关特殊能力丢失后可重新寻找。新开关和重试有 1.8 秒保护。

生命用尽可在当前关续关，恢复所选难度初始生命并保留基础装备和累计分数，开始新的记录计时段。退出页面不保存关卡快照。

## 炸弹与八种道具

初始一颗炸弹、一格火力，移动步距 180ms。普通引线按原版 160 帧计算，约 2.67 秒；爆风画面持续 560ms，最后 120ms 为无伤害淡出。遥控只作用于取得后放下的炸弹，X / B 按放置顺序引爆最早一颗。

| 道具 | 效果 | 关号 |
|---|---|---|
| 火力 | 每次加一格，最多 5 格 | 1、7、15、27、38 |
| 炸弹 | 每次加一颗，最多 10 颗 | 2、5、6、11、12、17、19、23、28、32 |
| 疾跑靴 | 一次速度提升，步距 135ms，不重复叠加 | 4 |
| 遥控 | 新放炸弹等待 B 引爆 | 3、8、13、20、22、24、29、33、37、41、44、48 |
| 穿砖 | 可过软砖，不能穿石墙；砖内不能放弹 | 10、16、31、39、42、46 |
| 穿弹 | 可经过已放置的炸弹 | 9、14、18、21、25、35、43、47 |
| 防火衣 | 爆风免疫，仍怕怪物 | 30、36、49 |
| 无敌 | 约 34 秒内免疫爆风与怪物，暂停不消耗 | 26、34、40、45、50 |

十字爆风遇石墙在墙前停止，第一块软砖被炸开并阻挡本次传播。连锁依据爆炸前地形计算，不穿透刚炸开的砖；命中其他炸弹会立即连锁，包括遥控弹。可以离开脚下炸弹，没有穿弹能力不能重新穿过。

首次揭开门或道具不处罚。再次炸到露出的门或道具释放四只当前关对应的原版类型怪物；道具会消失。援兵存在短暂出现保护，期间不会受到爆风或伤害玩家。

得分按怪物 100 / 200 / 400 / 800 / 1000 / 2000 / 4000 / 8000 计算，道具 1000 分；炸砖不加分。移除原有自定义的炸砖、过关时间与七弹奖励。

## 接触判定（2026-10-04 修正）

绘图与碰撞共用 `bomberActorPosition`：移动格的 110ms 插值期间，按精灵实际显示的位置计算，不能因逻辑坐标先进入下一格而提前死亡。

怪物接触使用双方中心距离小于 25px，排除整格空白、光晕、头盔和手臂。火焰有效范围收进格子中心的 34×34px，再与玩家 10px 身体半径相交；火焰最后 120ms 的淡出尾光完全无伤害，删除的火焰与被炸死怪物不保留碰撞。出现保护期间的半透明援兵也不会伤害玩家。这些容错在 Web 与 Pad 上一致。

## 原版音乐和音效

17 段音频中，16 段来自 [Zophar 原版 Bomberman NSF 录音](https://www.zophar.net/music/nintendo-nes-nsf/bomberman)，爆炸声改为解码 [原版 BOOM.NAS 的 DMC 采样](https://github.com/emu-russia/bomberman-nes/blob/master/BOOM.NAS)。涵盖标题、关卡开场、普通关、拾取升级后、过关、奖励关、防火/无敌、结局、死亡、失败以及七个事件音效。水平/竖直脚步、放弹、爆炸、拾取、接触死亡和暂停音效编号依据原版 APU 调用校准。

循环曲保留原版录音，使用 PCM 裁切和重复波形匹配设置循环边界；短曲保留原版演奏，去除首尾静音。没有添加新旋律。运行音频在 `public/assets/games/bomber/audio/`，来源链接、SHA256、文件大小和循环位置记录于 [audio-manifest.json](assets/bomber/audio-manifest.json)，播放器配置在 `bomberSoundtrack.json`。素材原权利仍属于原游戏权利方，公开下载页不是开源许可声明。

爆炸素材 v1 的有效声音仅约 30 毫秒，表现为发闷的低频脉冲。v2 根据原版寄存器配置，将完整 4081 字节爆炸采样按约 24858 bit/s 解码，恢复约 1.31 秒的原始爆裂和衰减过程；以 44.1 kHz 无损 PCM 保存，保留整体音量配置。连锁爆炸只重启单个爆炸声道，避免叠加失真。处理参数、来源与复现方式见 [爆炸音效修正记录](assets/bomber/blast-audio-v2.md)。

音乐默认开启，没有局内音乐开关，沿用此前约定不受全局音效关闭影响；操作音效遵循全局声音设置。首次用户点按/按键解锁浏览器音频。开始新关播放原版开场后进入主曲；拾取道具、奖励和防火/无敌切换对应音乐；过关、死亡、失败和结局使用原版短曲。暂停、后台及卸载清理播放；继续恢复循环，不重新播开场。异步下载/解码使用代次校验，避免暂停、静音或离开后补播迟到声音。

## 操作、适配与记录

Web：方向键 / WASD 移动，Z / 空格 / 回车放弹，X / B 遥控，P / Esc 暂停。Pad：方向盘长按连走，A / B 大按钮，触点至少 44px；横竖屏与窄屏不横向溢出，手册在画面下方分栏。进入后台或失焦自动暂停并清理持续输入，主动继续。减少动态效果设置关闭周期摆动和闪烁。

完成 50 关或一次生命组耗尽写入一次 `sky-bomber`：level 1–3 对应难度，胜利 correct 1、失败 0，total 1、stars 0。运行时长含重试和奖励关，排除暂停及面板等待；续关开始新的计时段。中途返回或重开不结算，分数和会话最高分仅在页面显示。
