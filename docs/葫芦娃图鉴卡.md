## 收集与交互

- 入口：档案库 `/archive` → 套系「葫芦娃」。全套 11 张，可按原有稀有度筛选。
- 纳入现有全卡池召唤入口。沿用单抽 100 卷星币、十连 900 卷星币和现有稀有度权重算法；底层 `drawCards` 的指定套系参数同样支持 `hulu`。
- 拥有记录仍存入孩子的 `archivedCards`，重复卡不重复增加收集进度；已有套系记录不需迁移。
- 集齐 11 位后可领取一次 500 卷星币，领取状态沿用 `cardRewardClaimed`，刷新后保留。
- 未收集卡保留彩色插画并标注「待收集」；有孩子档案时，可点击或用 Enter / Space 打开详情，未拥有的详情标注「尚未解锁」。详情支持卡牌翻面。
- 游客可浏览套系与全部人物卡面，沿用档案库游客预览流程；抽取、个人收藏和奖励需要孩子档案。

## 界面与适配

独立「七色葫芦山」界面使用米色纸纹、青绿山景、葫芦藤和七色葫芦，人物插画采用怀旧剪纸动画笔触。套系主题样式仅在本套系生效，通用卡牌组件可在抽取结果等位置复用人物卡面。

2026-10-01 卡面调整：按用户反馈提高人物立绘占比，借鉴西游记卡牌的画面主导感，保留本套系剪纸动画、七色细边框和米色纸纹。插画从上半部的小画框改为铺满卡面的画作，取消两侧留白，显示宽度由约 134/200 增至 192/200（约增加 43%）；名称和本领压在底部的柔和纸色渐层上，伙伴关系移入详情，避免独立文字区挤占人物。画作填满显示窗时仅轻微裁切上下边缘。详情卡在 Web 上宽 340px，平板竖屏最大 280px。

Web 大屏每行 5 张；≤1100px 每行 4 张，≤850px 每行 3 张，≤600px 每行 2 张。平板竖屏详情改为纵向可滚动布局；横屏保留并列详情。支持深浅主题、44px 交互按钮、键盘访问及减少动态效果偏好。

## 普通刷新后人物图缺失的缓存修复

2026-10-01：用户反馈强制刷新可显示，后续打开又消失。排查发现图片文件暂不存在时，Vite 会返回 HTTP 200 的 HTML 应用外壳，旧 SW 只判断 `response.ok`，可能将 HTML 作为 WebP 永久缓存。已用真实 Service Worker 回归用例复现旧代码下图片无法解码。

修复在 `public/sw.js`：升级离线缓存至 v5；图片缓存读写均校验 `Content-Type: image/*`，损坏条目自动删除并重新获取，HTML 回退不再入图片缓存。`src/main.tsx` 在开发模式渲染前注销本应用的旧生产 SW 并清理本应用静态缓存；注销后仍有 controller 的页面自动普通重载一次，避免 preview/dev 共用端口导致旧 SW 持续接管。卡牌内容、图片画作与本地收藏数据保持原有保存方式。

相关回归 `e2e/hulu-cache.spec.ts` 的 2 个用例通过，验证错误缓存恢复、HTTP 200 HTML 不入图片缓存、普通刷新与离线解码、开发模式解除 SW 控制，以及 11 位人物连续三次普通刷新显示。原有套系 E2E 的 4 个用例通过，覆盖 Web 与 pad；TypeScript、相关 ESLint、SW 语法检查和生产构建通过。
