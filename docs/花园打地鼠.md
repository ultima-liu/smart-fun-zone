# 花园打地鼠

状态：2026-10-02 新增，入口为空中乐园 → 敏捷 → 花园打地鼠 → 去打地鼠。在 `/lobby` 页内展开，与其他游戏共用返回游戏列表按钮，同时只运行一个游戏。

## 场景与操作

- 温暖的奶油色、草绿色花园，搭配春日山丘、太阳、花朵、木牌与九宫格地洞。地鼠、皇冠金鼠和小兔子采用原创 SVG 角色，Web 和 Pad 缩放保持清晰；敲击显示小木锤与浮动分数反馈。
- 鼠标和触屏在按下时直接命中，支持多个手指；键盘在游戏区域内使用数字键 1–9 对应从左到右、从上到下的地洞，P / Esc 暂停，Tab / Enter 可操作按钮。
- 开局倒数 3 秒，每局有效游玩时间 60 秒；暂停、切换后台或窗口失焦均冻结时间与地鼠停留时间，需主动继续。倒数期间也支持暂停。关闭游戏会清理计时器和监听器。
- 页面在 Web 使用棋盘与手册双栏；Pad 竖屏将手册放在棋盘下方，横屏保留双栏；窄屏保留九宫格与触控按钮。支持减少动态效果设置，声音遵循全局开关。
- 游戏展开时隐藏泡泡与学习助手的悬浮入口，避免遮挡暂停按钮和地洞；返回列表后恢复。

## 玩法

- 普通地鼠基础 +10 分，金色地鼠基础 +30 分；小兔子不能敲，误敲扣 20 分，最低为 0 分。
- 连续命中 5 次起计 2 倍分，10 次起计 3 倍分（最高）；漏掉普通或金色地鼠、敲空洞、误敲兔子均清空当前连击。兔子自然离开不打断连击。
- 一次命中后立即移除角色并显示短暂的分数反馈，同一角色无法重复计分。
- 第一只一定是普通地鼠；后续每次出现概率为普通地鼠 67%、金色地鼠 15%、兔子 18%。

| 难度 | 出现间隔 | 停留时长 | 同时出现上限 | 本局目标 |
| --- | --- | --- | --- | --- |
| 轻松 | 850 ms | 1500 ms | 2 | 200 分 |
| 认真 | 660 ms | 1150 ms | 3 | 350 分 |
| 高手 | 480 ms | 850 ms | 4 | 500 分 |

游戏未开始或结算后可以选难度，倒数、游玩、暂停时锁定难度；暂停面板可重新开局。结算展示本局分数、命中次数、准确率（成功命中 / 实际敲击次数）和最高连击；最佳分数按难度保留于本次游戏挂载会话。
