# 测试策略

状态：当前执行口径（2026-09-28）

## 测试分层

1. 纯规则单测：奖励幂等、课程覆盖、复习调度、内容完整性、权限矩阵。
2. 前端组件与状态测试：存储迁移、课程结算、同步合并和异常数据降级。
3. 服务端测试：密码和令牌、孩子/家长/管理员访问边界、输入限制。
4. E2E：只覆盖跨页面关键路径，不重复验证所有静态内容。

## 常用命令

```bash
npm run lint
npm run test
npm run test:server
npm run build
npm run check
npm audit --audit-level=moderate
npm --prefix server audit --audit-level=moderate
```

## E2E 口径

- 只运行本次功能修改相关用例。
- 只修改 UI 时不运行相关 E2E。
- 课程改动选择对应学科 spec；乐园改动选择 `park-arcade.spec.ts`；账号和云同步优先使用服务端权限测试与对应登录流程。
- `_dbg*.spec.ts` 不属于正式用例，禁止提交到测试目录。
