# 排序题选项打乱

2026-10-10：排序题的待选卡片必须打乱，不能刚好显示正确答案。一轮拖放、点选、反馈和普通重绘期间，卡片顺序保持稳定。界面仍按 Pad 横屏一屏展示。

## 规则与实现

共用 `src/orderingOptions.ts`，用任务和练习轮次生成稳定排列，洗牌后明确排除正确顺序；三项及以上还排除整组倒序，避免只需机械反转。保留全部材料及原正确答案，判题仍按正确答案检查。两个不同材料只有一个有效错序；空材料、单项或全相同材料安全返回。

语文「重新排序」清空空位并变换待选顺序，有其他有效排列时保证与上一轮不同；课内与复习分别使用课时、情境、复习轮次作为种子。拖动已放入的卡片、交换、撤回或提示不会重洗。刷新按同一初始种子展示待选卡片，已填写空位按词语恢复，不依赖待选卡片的位置。

数学 `MathNumberOrder` 共用相同防护，保留错误不推进、完成保留、重做重新洗牌和断点规则。
