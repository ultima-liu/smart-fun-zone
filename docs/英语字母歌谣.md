# 英语字母歌谣

2026-10-10 确定：原“字母歌谣”和“词中声音歌谣”是同一段教材录音的两个部分，不能拆成两个 tab，也不能由普通语音播报朗读录音的文字。

## 内容与播放

- 六单元的“听读原课 → 字母歌谣”统一为一个选学页面，左右完整展示两个部分，分别标注 1、2。全部字母歌谣句子、词中声音歌谣句子和完整词点读入口保留。
- 下方共用一个教材原声播放器，继续使用各单元的 `*-letters-sounds.mp3`；不切割录音，不播放两遍重复播放器。按 2026-10-10 的补充要求，六单元字母歌谣均取消“原声听后任务”入口及其弹窗，只保留播放器。
- 自动进入及公共“再听一遍”只朗读：“点击播放教材原声，边听边看字母歌谣和词中声音歌谣。这是同一段录音的两个部分。”录音的字母、例词、短句与音位不进入自动播报。
- 完整词仅在孩子主动点读时使用英文语音；手动播放优先于自动播报。原声播放仍由孩子操作播放器，不以普通 TTS 替代歌谣。
- 删除两个部分之间的子 tab，旧第二 tab 的选择记录不再隐藏第一部分；外层“字母歌谣”选择及其他必做任务、完成和重复练习规则保留。
