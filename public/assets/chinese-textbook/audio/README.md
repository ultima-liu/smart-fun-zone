# 拼音音节录音

来自 https://github.com/davinfifield/mp3-chinese-pinyin-sound ，下载所依据的仓库树为 `aa25ecce7b7fb02757b2c2b8e3c01aa975812edc`。249 个音节文件以 `pinyin-<音节与数字调号>.mp3` 命名，原文件内容未改动，Unlicense 见 LICENSE。

`src/content/chinesePinyinAudio.ts` 记录界面拼音与文件的对应关系。i、u、ü 等整体读法使用 yi、wu、yu 对应形式。此处提供音节录音，不以带声母的音节替代缺少的纯韵母或声母本音，不声称录音者具有教师资格。
